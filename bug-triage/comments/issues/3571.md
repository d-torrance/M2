Worth adding which line failed, since the log couldn't show it. With nine variables:

| step | |
| --- | --- |
| `T = S/J^5` | 0.33s |
| `I = ideal vars T` | 0.0002s |
| `depth(I,T)` | 0.006s |
| `depth(I,T^1)` | 0.002s |
| `depth T` | **Insufficient memory for the allocation** |

So it was the third assert, not the first. Uncapped, that same `depth T` finishes in 11.8s and
returns 0 — the requirement is somewhere above 400M rather than unbounded. With four variables it is
0.007s.

Which means the cost of `depth` on a nine-variable `J^5` quotient is unchanged; the test simply no
longer asks for it. Anyone reinstating the larger ring should expect to need the headroom.
