Closing: fixed by @mahrud in `bc34e920ad`
([PR #3042](https://github.com/Macaulay2/M2/pull/3042), merged 2023-12-30), twenty days after this
was filed — and it does what @DanGrayson asked for rather than the re-enable-overriding option that
was first offered.

Dan's condition was *"if `Local` can be both an option name and an option value, its documentation
should reflect that."* `Macaulay2Doc/options.m2` now computes

```m2
both := set optionalNames * set optionalValues
scan(optionalValues - both, v -> document { ... })
```

so a symbol on both lists is documented once, and the parent node carries a dedicated
*"Symbols used as an option name or value"* section listing exactly those. `Local` no longer appears
in `options.m2` at all, and the duplicate-documentation error for it cannot arise.
