Closing this, with thanks for the offer and an apology for the eight-year delay in answering it.

The reason is scope rather than merit. Our node
[using Macaulay2 with TeXmacs](https://macaulay2.com/doc/Macaulay2/share/doc/Macaulay2/Macaulay2Doc/html/___Using__Macaulay2_spwith__T__E__Xmacs.html)
is written for users, not for people working on the integration, and from a user's point of view
there is nothing to install or locate: the `macaulay2` plugin ships as part of TeXmacs, so the
instructions the node already gives — Insert → Session → Macaulay2 — are the whole of what a user
needs. A pointer to the plugin's source repository would be aimed at a different reader than the
node is.

For what it is worth, the integration is in good health on our side. M2's TeXmacs mode has been
worked on recently — `b3395c0bd8` (2026-01) switched it to using `html` for hypertext, and
`431da9178e` added `AfterPrint` support — so this is not being closed because the interface has
been abandoned.

@da-liii, if something in TeXmacs' Macaulay2 plugin needs a change on the Macaulay2 side, an
issue describing that specifically would be very welcome; that is the collaboration this thread
was offering and it is easier to act on than a documentation pointer.
