Macaulay2, and it was answered here — @ThomasXielt confirmed on 11 May 2022 that the Markov basis
computation worked.

Recording the two things that resolved it, in case someone lands here with the same error. The
message

```
error: no method for adjacent objects:
       fitnessShape (of class Symbol)
SPACE  "mydata" (of class String)
```

means `fitness.m2` has not actually loaded — `fitnessShape` is still an unassigned symbol. The check
@DanGrayson gave is `class fitnessShape`, which reads `MethodFunction` once the file is in. And the
data file itself is fussy: no line may start with a space, and the first words on each line must all
be the same length.

The remaining question in the thread — which package would quantify the effect of individual
mutations on fitness — is a research question rather than something Macaulay2 can be said to be
missing, and it has had no takers. Worth asking on the mailing list or in a new issue if it is still
live.
