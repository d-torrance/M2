Fixed in 1.26.06 by #4280, which also added a regression test naming this issue:

```m2
try lift(matrix(RR, 1), ZZ) -- #2509 (used to segfault)
```

On 1.26.06 the one-liner now gives a recoverable error rather than a crash:

```m2
i1 : lift( matrix {{1.}}, ZZ)
     error: cannot lift given matrix
```

Worth being precise about what that means, so the close is not read as more than it is: the outcome is
an *error*, not a successful lift. The guard that reports it is old — `m2/enginering.m2` has raised
"cannot lift given matrix" since 2008 — and what #4280 changed is the engine side, so `rawLift`
returns null instead of walking off into `RingZZ::is_zero`. The test above uses `try` rather than
`assert` for exactly that reason.
