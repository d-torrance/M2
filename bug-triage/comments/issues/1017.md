The answers are right, not merely non-erroring. On 1.26.06-40, over `GF(3,2)[x,y]`:

```m2
i1 : R = GF(3,2)[x,y];

i2 : radical ideal(x+y)

o2 = ideal(x + y)

i3 : radical ideal(x^2*y)

o3 = ideal(x*y)

i4 : radical ideal(x^2, y^3)

o4 = ideal (x, y)
```

Worth separating from what is still open: [#4641](https://github.com/Macaulay2/M2/issues/4641)
records that `radical` uses the translated classic Macaulay algorithms, with neither Krick–Logar
for characteristic zero nor Kemper for characteristic *p* implemented. That is about which
algorithm runs, not about which base fields are accepted, and it stays open.
