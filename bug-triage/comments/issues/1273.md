Closing this — @pzinn is right that it can be, and has been since 2023.

Fixed by [#3018](https://github.com/Macaulay2/M2/pull/3018) *"trim PID"*, merged 2023-11-30. The
example from the body:

```m2
i1 : R = ZZ/7[t];

i2 : I = ideal(t^3*(t+1), t*(t-1));

i3 : trim I

o3 = ideal t

i4 : gens gb I

o4 = | t |
```

`trim` and the Gröbner basis now agree, and the answer is principal, which is what a PID should
give.
