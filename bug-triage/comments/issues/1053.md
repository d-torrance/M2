Closing this — it was resolved in the thread, and the screenshot explains why.

The first command in it is `loadPackage " SchurRings"`, with a leading space inside the quotes.
That gives *"package title not alphanumeric"*, so the package never loaded — and every later
failure follows from that. `schurRing(QQ,s,4)` then reports *"no method for adjacent objects:
schurRing (of class Symbol)"*, which is what M2 says when a name has no value: `schurRing` was still
an unbound symbol.

`schurRing(QQ,s,4)` works normally once the package is loaded, which matches @hoyeunglee's own
follow-up — *"i can use now"*.
