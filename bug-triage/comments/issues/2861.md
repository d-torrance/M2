[PR #3003](https://github.com/Macaulay2/M2/pull/3003), *"Dmodules update, new WeylAlgebras
package"*, merged 2023-11-22 — which this issue's timeline already cross-references.

```m2

	"WeylAlgebras",
	"HolonomicSystems",
	"BernsteinSato",
```

further request that each package's documentation mention the other two is satisfied as well — all
three do.
