Closing this: `homomorphism` carries the internal degree now, and the assertion at the
bottom of the example passes.

`Hom(M, N)` stores a `cache.homomorphism` closure, and
[`ae6ae57cfe`](https://github.com/Macaulay2/M2/commit/ae6ae57cfe) — @mahrud, in
[#3042](https://github.com/Macaulay2/M2/pull/3042), merged 2023-12-30 — changed its `Degree`
argument from

```m2
Degree => first degrees source f
```

to

```m2
Degree => first degrees source f + degree f
```

The added term is the internal degree of the input map. The commit message says the patch came
from `Complexes.m2`, which had been carrying a private `Hom(Module, Module)` with the term
already in it; the same commit deletes that copy. The line is now at
`M2/Macaulay2/m2/Hom.m2:41`.

That `ae6ae57cfe` is what did it, rather than something nearby, is checkable by putting the older
definition back — on 1.26.06-40-gd8e86d689d:

```m2
i4 : f1 = map(target B, R^1, B_{2}, Degree => 2);

             1      1
o4 : Matrix R  <-- R

i5 : isHomogeneous homomorphism f1

o5 = true

i6 : H.cache.homomorphism = f -> map(R^1, R^1, adjoint'(f, R^1, R^1), Degree => first degrees source f);

i7 : isHomogeneous homomorphism f1

o7 = false
```
