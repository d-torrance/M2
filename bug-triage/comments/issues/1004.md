Closing this. Of the three things asked for, one has been true since 2005, one is the same thing
seen from the other side, and the third is the one @DanGrayson argued against in this thread — and
there is now a way to get it on demand.

### Sorting by numerical value is not new; it predates this issue by fourteen years

`sort` does not use `<`. It goes through `compare`, which for strings calls `strnumcmp`
(`d/actors3.d:272`), and `system_strnumcmp` (`d/scclib.c:171`) walks the two strings comparing
runs of digits as numbers rather than character by character. Mike Stillman added it in
`323c3fb0ea`, *"numeric ordering for strings"*, on 2005-01-10.

```m2
i1 : sort {"10", "9", "2"}

o1 = {2, 9, 10}

i2 : "10" < "9"

o2 = false
```

The second line is why this can look untrue: `<` on strings is still lexicographic, and only
`sort` and `rsort` go through `compare`.

### Version-number sorting is the same mechanism, so it was never at risk

```m2
i3 : sort {"Macaulay2-1.9", "Macaulay2-1.10", "Macaulay2-1.17", "Macaulay2-1.2"}

o3 = {Macaulay2-1.2, Macaulay2-1.9, Macaulay2-1.10, Macaulay2-1.17}
```

### Minus signs, and the reason to leave them alone

```m2
i4 : sort {"-5", "3", "-2", "10"}

o4 = {-2, -5, 3, 10}
```

The `-` is compared as a character and the digit run after it numerically, so `-2` sorts before
`-5`. Reading it as a sign is exactly what @DanGrayson's 2021-03-07 reply warns against: the same
character appears in `Macaulay2-1.17`, where it is not a sign, and no rule inside `sort` can tell
the two apart.

### The signed ordering is available now, without changing the default

@mahrud's suggestion of an `nsort` was made contingent on #1154. That is closed, and
`sort(List, Function)` exists (`m2/lists.m2:220`):

```m2
i5 : sort({"-5", "3", "-2", "10"}, value)

o5 = {-5, -2, 3, 10}
```

which is the ordering Eisenbud and Schreyer asked for, on the lists where it is what you mean.
`value` being too slow to use as the default — the other half of that 2021 reply — is not an
objection to using it explicitly on a list you know consists of numerals.
