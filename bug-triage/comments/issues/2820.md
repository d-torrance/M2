Still reproduces on 1.26.06-40-gd8e86d689d. `prune` turns out not to be where it goes wrong,
though — pruning its own output a second time gives the answer you wanted:

```m2
i4 : prune M

o4 = cokernel | 1 0 |
              | 0 1 |
              | 0 0 |

                              3
o4 : kk-module, quotient of kk

i5 : prune prune M

       1
o5 = kk

o5 : kk-module, free
```

The path is `prune` → the `isAffineRing R and isHomogeneous M` hook at
`m2/modules2.m2:167-174`, which fires because `degreeLength kk` is 0 and so `M` is
homogeneous for free → `cokernel modulo(complement f, f)` → the `isField` branch of
`complement` at `m2/matrix2.m2:170-172`, which is `transpose syz transpose f`.

`syz` is the one that misbehaves. Take a matrix of rank 2 with entries that actually involve
`a`; the syzygy module of its transpose is a single `kk`-line, but three columns come back:

```m2
i6 : f = matrix{{a^2+1, a},{a, a^2},{1_kk, a+1}};

              3       2
o6 : Matrix kk  <-- kk

i7 : rank f

o7 = 2

i8 : syz transpose f

o8 = | a2-a  -a2+a+1 a2-1    |
     | -2a+1 -2a2+a  a2-2a-2 |
     | 1     a       a2      |

              3       3
o8 : Matrix kk  <-- kk
```

Columns two and three are `a` and `a^2` times column one — the `QQ[a]`-module generators of that
line rather than its single `kk`-generator, i.e. the syzygies were computed over the underlying
polynomial ring instead of over the field. `complement` inherits the shape and hands back a 3x3
whose first two columns are zero, where a 3x1 was wanted:

```m2
i9 : complement f

o9 = | 0 0 -1 |
     | 0 0 0  |
     | 0 0 1  |

              3       3
o9 : Matrix kk  <-- kk
```

and `modulo` carries those two redundant columns into the presentation, which is the extra pair of
generators in `prune M`.

With constant entries it is right:

```m2
i10 : syz transpose matrix{{1_kk,2},{3,4},{5,6}}

o10 = | 1  |
      | -2 |
      | 1  |

               3       1
o10 : Matrix kk  <-- kk
```

which is also why the second `prune` succeeds — by then the presentation is `| 1 0 | 0 1 | 0 0 |`
and there is no `a` left in it for `syz` to expand along.
