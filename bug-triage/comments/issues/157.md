@kschwede's example still behaves as reported on 1.26.06-40, and the "often making things
worse" in the opening is literal rather than rhetorical — `trim` returns *more* generators
than it was given.

```
i1 : R = QQ[y,z]/(1+y^3+z^3);

i2 : J = ideal(y, z+1);

i3 : numgens (J^3)

o3 = 4

i4 : numgens trim (J^3)

o4 = 5

i5 : ideal gens gb (J^3)

o5 = ideal(z + 1)

i6 : J^3 == ideal(z+1)

o6 = true
```

Four generators in, five out, and the ideal is principal. `gb` finds the single generator
immediately, which is the example Dan asked for in this thread and which answers "Could you
provide an example where gb does better?" — it does better by four generators here.

### Why `trim` cannot currently notice

`trim` routes through `mingens`
([`m2/matrix2.m2`](https://github.com/Macaulay2/M2/blob/development/M2/Macaulay2/m2/matrix2.m2),
six call sites), and `mingens` takes its non-`Complement` path whenever the module is not
homogeneous — the guard is `opts.Strategy === Complement and isHomogeneous M and
isAffineRing ring M`, so inhomogeneous input skips the fast path automatically. What that
path can promise is documented, and it is little: *"There is no guarantee that the
generating set is small, or that no subset also generates. The only thing known is that the
entries do generate the ideal."*

That is not an implementation shortfall so much as a mathematical one. Over a graded ring,
or over a local ring, minimal generators are well defined by Nakayama. For a general
inhomogeneous ideal there is no such statement, so nothing certifies minimality even when it
has been reached — and, as here, nothing notices when the result got worse.

The suggestion in this thread — compute the Gröbner basis that is being computed anyway and
keep it if it looks simpler — remains the obvious cheap move, and this example gives it a
concrete measure to beat: 5 against 1.

Related, and open: #105, on `mingens` returning silently for inhomogeneous input, where the
same `mingens`/`trim` coupling is written up in more detail — including that
`Strategy => Inhomogeneous` is inert for `mingens` and is a real branch only in `trim`.
