Still reproduces on 1.26.06, and the hypothesis relayed in your report is correct — the code does
assume the b-function's roots are rational. The line is findable, and it is not in `Drestriction`
but one level down.

`WeylClosure I` here computes the b-function `s^3-s^2-s`, which factors as `s * (s^2-s-1)`.
`factorBFunction` factors it over `ZZ` and then requires every irreducible factor to be linear
([`bFunction.ideal.m2:227-229`](https://github.com/Macaulay2/M2/blob/development/M2/Macaulay2/packages/BernsteinSato/bFunction.ideal.m2#L227-L229)):

```m2
result := apply(f, u->(
          if first degree u#0 != 1 then error "internal error: incorrect b-function";
```

`s^2-s-1` is irreducible over `QQ` — its roots are the golden ratio and its conjugate — so it has
degree 2 and this raises. Everything that reaches `getIntRoots` or `bFunctionRoots` goes through
`factorBFunction`, which is why the failure surfaces from several different entry points.

**#4083 was the same defect and has been closed into this one.** @antonleykin reported it against
`Dintegration` with a different module; instrumenting `factorBFunction` shows both issues hand it
the *same* polynomial, `s^3-s^2-s`, and both die on the same line. His example is worth keeping in
view here since this issue is now the surviving record:

```m2
W = QQ[x, dx, a, Da, WeylAlgebra => {{x, dx}, {a, Da}}]
M = cokernel matrix {{-x*a+1, x^2*a^4*Da^2-2*x^2*dx*a^2*Da+2*x^2*a^3*Da+x^2*dx^2+2*x*a^2*Da-2*x*dx+1}}
Dintegration(0,M,{0,1})
```

**One line makes both symptoms go away**, which is useful for confirming the diagnosis even though
it is not necessarily the right fix. Replacing that `error` with `continue`, so non-linear factors
are skipped:

```
WeylClosure I    -->  ideal(x^2*dx^2-2*x*dx+1, -x^2*dx^2+2*x*dx-1, 2*x^2*dx^3-2*dx)
Dintegration...  -->  cokernel matrix {{x^2*dx^2+2*x*dx-1}}
```

Skipping is at least defensible for `getIntRoots`, which is selecting integer roots and would find
none in a factor that has no rational roots at all.

**The open question is whether those answers are right, and I have not checked.** @antonleykin
raised exactly this on #4083 as "or something else": if a b-function with irrational roots means
the algorithm's hypotheses have failed, then returning a value silently is worse than the current
error, and the fix is a clearer diagnostic rather than a skip. That needs someone who knows the
D-module theory — @lorinczandras, @christineBerkesch, @michaelPerlman, @mahrud were all drawn into
the other thread.
