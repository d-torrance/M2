This is broader than the unit ideal, and it is a wrong answer rather than a non-minimal one.

**`trim` returns a strictly smaller ideal.** On the example in the report:

```m2
i2 : I = ideal(x^2+x+1, x^4+x^3+x^2+x+1);

i3 : T = trim I

o3 = ideal(x + 1)

i4 : T == I

o4 = false

i5 : 1_R % T

o5 = 1
```

So it is not that `trim` returned an awkward presentation of the same ideal — `x^2+x+1` is not in
the result at all.

**It happens on proper ideals too**, which means the unit ideal is not the special thing here:

```m2
i2 : J = ideal(x^2+1, x^3+1);

i3 : trim J

o3 = ideal(x - 1)

i4 : K = ideal(x^2+1, x^3+1);

i5 : gens gb K

o5 = | 2 x+1 |

i6 : trim K

o6 = ideal (2, x + 1)
```

`J` and `K` are the same ideal, `ideal(2, x+1)`, and it is proper. Trimmed straight away it comes
back as `ideal(x-1)` — the constant `2` dropped and a different linear form — and `x^2+1` is not
in that. Trimmed after the basis has been computed it is right. Note the two ideals have to be
constructed separately: `trim` caches, so trimming first and then checking poisons the comparison.

**@pzinn's observation generalises, and the operative step is the Gröbner basis.** Asking `== 1`
first is one way to compute one; asking for it directly is another, and they agree — on the
original example, each starting from a freshly constructed ideal:

```
trim                        -->  ideal(x+1)
I == 1     then trim        -->  ideal 1
gens gb I  then trim        -->  ideal 1
```

So the correct answer is reachable, and `trim` is working from the given generators when a basis
has not already been computed.

**Scope.** `ZZ[x,y]` behaves the same way. `QQ[x]` does not.

**On the two related issues.** #3622 is a different failure: there `trim` returns a mathematically
correct ideal that is merely not minimal, and applying `trim` twice reaches a fixed point. Here
the first answer is already wrong, so a second `trim` cannot recover it. And #1273 does not cover
this: its example is `ZZ/7[t]`, a PID, its text says "when working over a PID", and that case is
fixed — `trim ideal(t^3*(t+1), t*(t-1))` now gives `ideal t`. `ZZ[x]` has Krull dimension 2 and is
not a PID, so that fix does not reach it.
