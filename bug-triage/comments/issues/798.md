The default path already does what @DanGrayson asks for; it is the strategy path that does not.

That is visible in `M2/Macaulay2/m2/gb.m2:409-425`. `groebnerBasis Ideal` forwards to the
generator matrix, and when a strategy is given the branch goes straight to the engine:

```m2
	if gbTrace > 0 then << "-- computing mgb " << opts.Strategy << " " << mgbopts << endl;
	-- use engineMGB
	generators forceGB engineMGB(x, mgbopts))
```

`engineMGB` is called unconditionally and its result is `forceGB`'d, with nothing between the
strategy test and the call that looks for a basis already attached to `x`. When `Strategy` is
`null` the function falls through to `gb`, which is where the cache is consulted — hence the
asymmetry above.

So @mikestillman's *"Yes, if the computation is complete"* would be a check in that branch:
before calling `engineMGB`, see whether `x` already carries a finished Gröbner basis, and return
its generators if so. There is an unrelated `-- TODO: hookify this` immediately above the method,
which would presumably subsume this.
