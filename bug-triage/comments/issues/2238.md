The function is `fmpz_is_probabprime`. The chain, for whoever writes this up: `isPseudoprime ZZ`
(`m2/integers.m2:85`) calls `rawZZisProbablePrime`, which is `d/interface.dd:4533` into
`e/interface/flint.cpp`, which calls `fmpz_is_probabprime`. So the doc can name the function, which
it currently does not — it says only that it "calls a function in the FLINT library".

The version half of this request is probably not worth doing, though. Documentation is built once and
mostly read on the website, so a version written into the node would record the flint on the build
machine rather than the reader's. `version#"flint version"` is the right home for that and already
has it.

On the algorithm: flint declares `fmpz_is_probabprime_lucas` and `fmpz_is_probabprime_BPSW` alongside
the general entry point, so BPSW and Lucas are the pieces. Which one `fmpz_is_probabprime` dispatches
to at a given size is worth reading out of flint's own documentation rather than taking from this
comment — the header only shows that they are neighbours.

Two adjacent things in the same node, while someone is in there:

- The sentence "there are no known numbers which are composite, and for which this function returns
  true, although it is expected that there are an infinite number of such primes"
  (`isPrime-doc.m2:27-29`) ends on "such primes" where it means such composites.
- The contrast with `isPrime` is undocumented and is one line: `isPrime` calls `fmpz_is_prime`, which
  is a proof, while this calls `fmpz_is_probabprime`. That difference is the reason both functions
  exist.
