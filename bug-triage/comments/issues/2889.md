Closing this one: a lark grammar is not something that belongs in this repository, so it is out of
scope here rather than a thing waiting to be done. But the request underneath it — *"a formal
definition of the language"* — does have an answer now, and @fchapoton and @pqcfox in particular
should know where it is.

The Macaulay2 wiki carries an EBNF grammar for the language, derived from the interpreter's parser:

- [Macaulay2 language grammar](https://github.com/Macaulay2/M2/wiki/Macaulay2-language-grammar)
- [SimpleDoc language grammar](https://github.com/Macaulay2/M2/wiki/SimpleDoc-language-grammar)
- [D language grammar](https://github.com/Macaulay2/M2/wiki/D-language-grammar)

That is the *"official description of the Macaulay2 grammar using EBNF"* asked for above, and it is
the right starting point for a lark grammar, a tree-sitter grammar, or an editor mode — those are
welcome, just as their own projects.
[tree-sitter-macaulay2](https://github.com/d-torrance/tree-sitter-macaulay2) is an existing example.

The one bullet none of that covers is the second — automatically checking every `.m2` file for
correctness. If that is still wanted, it is worth its own issue, since it is a question about
tooling in this repository rather than about the grammar.
