Closing as not planned, together with #2242. Neither architecture in the title is release-relevant
any more: mipsel has been dropped from Debian, and ppc64 still builds but is not a release
architecture.

Two things worth recording rather than losing.

The failure was never observed on a release architecture — a SIGSEGV inside libblas on mipsel and a
truncated trace on ppc64, both from Debian experimental builds of 1.16.99.

And the test is currently skipped everywhere, not just on those two: the Debian packaging carries
`-- no-check-flag #1746` in `DeterminantalRepresentations.m2`, and that marker is honoured on every
architecture, so `check_0 "DeterminantalRepresentations"` reports `-- skipping` even on amd64. With
this closed, that skip is pinned to a closed issue, so it is worth deciding separately whether to
keep it or restore the test on the architectures where it was never seen to fail.

Not to be confused with #1745, a different test (`check_12`), a different symptom — an assertion on
an `eps` tolerance rather than a segfault — on different architectures, fixed in #4304 by loosening
`eps` from `1e-15` to `1e-14`.
