```m2
VirtualTally == VirtualTally := (x,y) -> (x ? y) === symbol ==
```

in `d55d94a7b2`, part of [#2918](https://github.com/Macaulay2/M2/pull/2918)
*"VirtualTally improvements, minor expressions fixes"*, merged 2023-08-30. That is the method
`Set == Set` resolves to today — `m2/set.m2:61`. Tallies got it in the same stroke:

