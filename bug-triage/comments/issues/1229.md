@foschreyer — this is available now, through the
[`Probability`](https://macaulay2.com/doc/Macaulay2/share/doc/Macaulay2/Probability/html/) package,
which ships with Macaulay2. It lets you define whatever distribution you want and draw from it.

Your stated first choice in the thread above was *"integers in bounded range equidistributed (with
zero median)"*, and *"I do not see any reason to use denominators"*. That is one line:

```m2
i1 : needsPackage "Probability";

i2 : X = discreteProbabilityDistribution(k -> 1/11, Support => (-5,5));

i3 : apply(10, i -> random X)

o3 = {-5, -1, 1, 1, 4, 4, -3, 1, -5, 0}
```

Over 2000 draws that gives min `-5`, max `5` and mean `-0.111` — bounded, equidistributed, zero
median, no denominators, and negative half the time.

`discreteProbabilityDistribution` and `continuousProbabilityDistribution` take an arbitrary density,
so any distribution you like is expressible; the package also ships fourteen named ones.

### One thing to know: `random(d, R)` does not take a distribution

There is no option for handing `X` to `random`, so polynomial coefficients are drawn explicitly:

```m2
i4 : R = QQ[x,y];

i5 : sum(flatten entries basis(2,R), m -> (random X) * m)

      2         2
o5 = 3x  + x*y + 2y
```

That is the idiom for the projective-geometry case you described — integer coefficients, both signs,
no denominators.

Closing, since the capability asked for exists. If the missing piece — passing a distribution
directly to `random(ZZ, Ring)` and friends — is worth having on its own, that would be clearer as a
new issue about that specific plumbing.
