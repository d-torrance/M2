linked library"* (merged 2024-06-29), which took 4ti2 out of this code path entirely.

`computedHilbertBasis` property, which goes through `rawHilbertBasis` and linked Normaliz. So the
`Using 32 bit integers` limitation that produced your error cannot be reached from `hilbertBasis`
any more.
