Fixed in 1.24.05. The old code read the heap size through a C `int`:

```
"heap size" => toExpr(Ccode(int,"GC_get_heap_size()")),
```

so 10G wrapped round to `INT_MIN`, which is the `-2147483648` above. `73cf611836` rewrote `GCstats`
around `GC_get_prof_stats`, and the value now comes from `Ccode(long, "stats.heapsize_full -
stats.unmapped_bytes")`. It went in with #3186.

Starting 1.26.06 the same way you did:

```m2
i1 : (GCstats())#"heapSize"

o1 = 10737614848
```

One thing worth knowing if anything of yours reads that table: the same commit renamed the keys, so
`"heap size"` is now `"heapSize"`.
