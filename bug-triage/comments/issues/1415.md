Both of these are in place now.

**Setting `OptionalComponentsPresent`** was already done when this was written. On 2020-07-16 the
package header read

```m2
bertiniPresent := run ("type bertini >/dev/null 2>&1") === 0
...
  OptionalComponentsPresent => bertiniPresent
```

so item 1 needed nothing — worth saying, since otherwise a reader comparing this issue against the
source would wonder what changed.

**Derandomizing under `--no-randomize`** landed in
[`1d11b502ab`](https://github.com/Macaulay2/M2/commit/1d11b502ab) (2024-01-30), part of
[#3121](https://github.com/Macaulay2/M2/pull/3121) *"Fixing bertini refine solutions"*:

```m2
BERTINIderandomize = member("--no-randomize",commandLine)     -- Bertini.m2:208
...
if BERTINIderandomize then f << "RANDOMSEED: 12345;\n";        -- :661 and :1588
```

which is the same shape as `PHCpack.m2:105`, and writes the seed into the Bertini input file rather
than onto the command line because that is how Bertini takes it.

Since documentation examples run with `--no-randomize` by default (`ArgNoRandomize` is in
`defaultMode`, `m2/run.m2:86`), Bertini example output is now seeded the same way PHCpack's is.
