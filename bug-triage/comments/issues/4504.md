Closing this as a duplicate of [#1013](https://github.com/Macaulay2/M2/issues/1013), which asks for
the same thing seven years earlier — @eisenbud, 2019: *"this can return an ideal in a different ring.
Maybe call this something other than `minimalPresentation`."*

Both halves still hold on 1.26.06-40-gd8e86d689d. The rename was never done —
`isGlobalSymbol "minimizePresentation"` is `false` — and the behaviour that motivates it is
unchanged:

```m2
i1 : R = QQ[x,y,z]/(x-y);

i2 : ring minimalPresentation ideal(x*z,y^2)

o2 = QQ[y..z]
```

which is not `R`.

**Carrying the proposal across, since it is the part #1013 does not have.** Dan's file asks for two
steps, and the second is the point of the first: rename `minimalPresentation` to
`minimizePresentation` — a verb, for the operation — and then use the freed name
`minimalPresentation` for *the presentation that operation produces*, a noun for the object. #1013
records the confusion; this file records a way out of it.

The scale is unchanged too: `minimalPresentation` is exported, documented, used across distributed
packages and called by users, so this is an interface break needing a deprecation period rather than
a rename — the same shape as `random(List)` → `shuffle(List)` in
[#4224](https://github.com/Macaulay2/M2/pull/4224), which took a warning period and a scheduled flip.
