Closing as fixed — the refactor this issue was opened to shepherd landed, and every question
in the opening post has either been answered here, resolved since, or moved into the
package's own `TODO`.

### The refactor

`Polyhedra` is now a directory rather than a single file — `core/`, `engine/`, `extended/`,
`interfaces/`, `documentation/`, at version 1.10 — with @lkastner's commits through 2018.

### The questions in the opening post

**"The name `intersection` is used multiple times... The first two should be constructors
and have better names, something like `coneFromInequalities`."** Adopted, essentially
verbatim: `coneFromInequalities`, `coneFromVData` and `polyhedronFromHData` all exist today.

**"Does `PolyhedralObjects.m2` make sense without `Polyhedra.m2`? Is `Polyhedra2.m2` still
being worked on?"** Both packages are gone from the tree, which is what
`Polyhedra/TODO` listed under "Packages that should go away".

**Tests for the lrs interface, tests that should fail, and whether a pull request could be
sent with incomplete documentation** — all three answered by @DanGrayson in this thread
(`CacheExampleOutput => true`, `try ... catch` with `generateAssertions`, and "the major
requirement for a pull request is that it be error free").

**"Is `Polyhedra2.m2` still being worked on?"** — answered by @JosephineYu here: it was not.

### What is left, and where it lives

The remainder went into
[`Polyhedra/TODO`](https://github.com/Macaulay2/M2/blob/development/M2/Macaulay2/packages/Polyhedra/TODO),
which reads as the direct continuation of this thread and still carries the open items,
several of them in the same words used above:

Two of those are verifiable right now: `saveSession` is still exported from
`Polyhedra/exports.m2`, and `Polyhedra/extended/not_refactored.m2` is still 600 lines —
including the `statePolytope` that #507 concerns.

None of that is what this issue asked, though. It was opened as a place to discuss a merge,
@DanGrayson redirected that discussion to the pull request itself, and the merge happened.
Anyone picking up the leftovers should start from `Polyhedra/TODO` rather than from here.
