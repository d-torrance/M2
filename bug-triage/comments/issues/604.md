Closing as fixed — repeated rows work now, and they work the way this thread concluded they
should.

Verified on 1.26.06-40, starting with the engine-level reproducer from the report:

```
i1 : debug Core

i2 : rawSubmatrix(raw matrix {{1,2},{3,4}}, {0,0,0,1,1,1}, {0,0,0,1,1,1})

o2 = 1 1 1 2 2 2
     1 1 1 2 2 2
     1 1 1 2 2 2
     3 3 3 4 4 4
     3 3 3 4 4 4
     3 3 3 4 4 4
```

which is the correct selection — rows `{0,0,0,1,1,1}` and columns `{0,0,0,1,1,1}` of
`{{1,2},{3,4}}`. Compare the output in the report, which had zero rows interleaved.

At top level, rows and columns are now symmetric:

```

M_{0,0}          | 1 1 |          M^{0,0}          | 1 2 |
                 | 3 3 |                           | 1 2 |

M^{1,1,0}        | 3 4 |          (M^{0,0})_{1,1}  | 2 2 |
                 | 3 4 |                           | 2 2 |
                 | 1 2 |
```

### It went the way the thread preferred

@mikestillman set out the choice here:

> There are two options here: one is to give an error in this case, the other is to rewrite
> it, to allow it. I guess I am leaning to the latter.

with @DanGrayson agreeing that erroring on duplicate rows but not duplicate columns "would
be counterintuitive". The second option is what happened: repeats are allowed rather than
rejected, and there is no repeat-rejecting guard left in the engine's matrix code.

### The fix

`dc300bb1ee0`, "fixed bug in submatrix with repeated rows", in **#2766** (@mahrud, merged
2023-03-11, reported there by @eisenbud). The old `e/matrix.cpp` kept a single destination
slot per source row:

```c++
-  int *trans = newarray_atomic(int, n_rows());
-  for (unsigned j = 0; j < r->len; j++)
-    if (r->array[j] >= 0 && r->array[j] < n_rows()) trans[r->array[j]] = j;
```

so with a repeated row every occurrence but the **last** was overwritten, and the ones that
lost the assignment came back as zero rows — which is exactly the interleaving in the report
above. The fix replaces `trans` with `minrow`/`maxrow`, keeping the full span of each source
row rather than one index, so every repeat is emitted. The PR also added
`tests/normal/submatrix.m2`.
