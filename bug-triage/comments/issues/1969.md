The answer to "we don't know what to do" is in the manual, under **GC garbage collector**. It lists
the messages the collector aborts with, and says that when the problem is heap *sections* rather than
memory as such, starting M2 like this often gets you past it:

```
GC_INITIAL_HEAP_SIZE=20G M2
```

@mikestillman added that in 2017.

For the `.emacs` side of the question: in emacs, `control-u` followed by `f12` lets you edit the M2
command line, and the setting goes in front of `M2` there. That is Mike's recipe from #500, which is
the same collector message reported from a user's end.

Closing, since the information exists. Worth being explicit about what does *not* exist: nothing
points you at any of this at the moment the collector aborts, and `setup()` makes no suggestion about
heap size — that part of this proposal would still have to be built.
