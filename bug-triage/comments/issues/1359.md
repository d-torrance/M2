The mechanism is the one your diff was reaching for, with the seed made conditional.
`PHCpack.m2:105`:

```m2
PHCexe = "phc "|(if member("--no-randomize",commandLine) then "-0123456 " else "")
```

and `ArgNoRandomize` is part of `defaultMode` (`m2/run.m2:86`), so every documentation example is
run with `--no-randomize` and therefore against a fixed `phc` seed — while an interactive session
keeps its randomness.

Related, and closed last week: [#1043](https://github.com/Macaulay2/M2/issues/1043), where
`cascade` used to fail outright. That one turned on the external `phc` version rather than on
anything in `PHCpack.m2`, so the two are separate halves of the same reproducibility question — this
issue is the M2 side, #1043 was the program side.
