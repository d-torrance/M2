### An example where it is not well defined

```
i1 : R = QQ[x,y]/(x^2*y - y^3);

i2 : I = ideal(x^2)
o2 = ideal x^2

i3 : J = ideal(x^2, y^3)
o3 = ideal(x^2, y^3)

i4 : I == J
o4 = true

i5 : I^[3,2]
o5 = ideal x^6

i6 : J^[3,2]
o6 = ideal(x^6, y^6)

i7 : I^[3,2] == J^[3,2]
o7 = false
```

`y^3 == x^2*y` in this ring, so `y^3` is a redundant generator of `J` and the two ideals are
equal — but the one written with the redundant generator comes out strictly larger.

### Where the line is: quotient rings, not polynomial rings

The implementation builds `phi = map(R, R, {x_i^(e_i)})` and returns
`ideal phi generators I`, so the result is the extension of `I` along `phi`. That is
generator-independent **whenever `phi` is a ring endomorphism**: if `h = sum a_i g_i` then
`phi(h) = sum phi(a_i) phi(g_i)`, so any two generating sets give the same extension.

Over a polynomial ring `phi` always *is* an endomorphism, and the operation is well defined.
I looked for a counterexample there and did not find one — 76 pairs of equal ideals in
`QQ`, `ZZ/2` and `ZZ/3`, three variables, four exponent vectors, no disagreement.

Over `R = S/J` it is a different story: `x_i |-> x_i^(e_i)` need not carry `J` into `J`, and
then `map(R, R, ...)` returns something that is not a well-defined endomorphism of `R`.
`M2` does not check this. In the example above,

```
i8 : x^6*y^2 - y^6 == 0
o8 = false
```

— `phi` applied to the defining relation `x^2*y - y^3` is not zero in `R`, which is exactly
the failure. Sweeping the same shapes over quotient rings, **40 of 2274** equal-ideal cases
disagreed, across `x^2-y^3`, `x^2*y-y^3` and `y^2-x^3-x^2` among others, in all three
characteristics.

So the report is right, and the scope is narrower than the title suggests: the operation is
sound on polynomial rings and unsound on quotients.

### Options, since "make it mathematically sensible" leaves the choice open

1. **Reject the input.** Check that `phi` descends — that each generator of the defining
   ideal maps back into it — and error otherwise. Cheap, honest, and it never returns a
   wrong answer; it just declines the cases that currently misbehave.
2. **Define it on a canonical generating set**, e.g. a Gröbner basis of `I`, which makes the
   answer a function of the ideal. It would then be well defined but would still not agree
   with the extension along any ring map, because there is no such map — worth saying out
   loud before choosing it.
3. **Restrict to the case where it is meaningful.** For `e = [p,...,p]` in characteristic
   `p` this is the honest Frobenius power, `phi` is the Frobenius endomorphism, and it
   descends to every quotient. `TestIdeals` already provides `frobeniusPower` for that case.

Nothing needs to change for anyone using this on a polynomial ring, which is presumably why
it has gone unnoticed for eight years.
