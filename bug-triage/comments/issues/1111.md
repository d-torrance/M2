Both things asked for in this thread are done, by two pull requests that never referenced it.

### The Exports section now comes after the menu

When this was filed, `help Symbol` in `m2/document.m2` assembled the page in this order:

```m2
ret := fixup DIV { topheader S, synopsis S, makeDocBody S,
     ... acknowledgement S, contributors S, references S,
     caveat S, seealso S,
     documentationValue(S, value S),      -- this emits "Exports"
     sourcecode S, type S,
     theMenu S                            -- menu last
     };
```

`documentationValue` before `theMenu` — Exports first, which is the complaint. The order was
flipped in [`c39951e928`](https://github.com/Macaulay2/M2/commit/c39951e928) (@mahrud, 2020-08-11),
part of [#1454](https://github.com/Macaulay2/M2/pull/1454). Today `getBody` (`m2/help.m2:502`) reads

```m2
apply(("Synopsis", Description, SourceCode, Acknowledgement, Contributors,
        References, Caveat, SeeAlso, Subnodes, "WaysToUse"),
    section -> if data#?section then data#section)
```

with `Subnodes` ahead of the trailing block that carries the package's Exports. An installed page
confirms it — `Truncations` renders as Description, Contributors, References, See also, **Menu**,
Authors, Version, Citation, **Exports**, For the programmer.

### And @mikestillman's suggestion landed too

*"Another section that has been suggested is an `Acknowledgements` section, (e.g. for thanking
funding sources)"* — `Acknowledgement` is a documentation key now (`m2/document.m2:643`, exported
at `m2/exports.m2:64`), added in [`24ba80c60d`](https://github.com/Macaulay2/M2/commit/24ba80c60d),
part of [#1234](https://github.com/Macaulay2/M2/pull/1234) *"SimpleDoc v1.2"*. It appears in the
`getBody` list above, between `SourceCode` and `Contributors`.
