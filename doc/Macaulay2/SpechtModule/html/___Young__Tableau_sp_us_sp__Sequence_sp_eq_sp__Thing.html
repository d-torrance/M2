YoungTableau _ Sequence = Thing -- changes the entry in cell (a,b) from a Young Tableau

  • Operator: _
  • Usage:
    y_(a,b) = e
  • Inputs:
    • y, an instance of the type YoungTableau,
    • pos, a sequence, the position (a,b) of the cell where a is the row and b the column
    • e, a thing, a number, the new entry of the cell
  • Outputs:
    • an instance of the type YoungTableau, the number in the cell at the position (a,b) of the tableau y

Description

i1 : y = youngTableau(new Partition from {2,2},{0,2,1,3})

o1 = | 0 2 |
     | 1 3 |

o1 : YoungTableau
 
i2 : y_(0,0)=1

o2 = 1
 
i3 : y

o3 = | 1 2 |
     | 1 3 |

o3 : YoungTableau
