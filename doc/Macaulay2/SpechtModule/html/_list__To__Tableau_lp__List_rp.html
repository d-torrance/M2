listToTableau(List) -- constructs a Young Tableau from a doubly nested list of numbers

  • Function: listToTableau
  • Usage:
    listToTableau(l)
  • Inputs:
    • l, a list, a doubly nested list of numbers
  • Outputs:
    • an instance of the type YoungTableau, a Young Tableau, such that the rows corresponds to the elements of l

Description

i1 : l = {{0,1,2},{3,4},{5}}

o1 = {{0, 1, 2}, {3, 4}, {5}}

o1 : List
 
i2 : listToTableau l

o2 = | 0 1 2 |
     | 3 4 |
     | 5 |

o2 : YoungTableau
