semistandardTableaux(Partition,ZZ) -- the list of semistandard tableaux of shape p and filling with the numbers from 0 to n-1.

  • Function: semistandardTableaux
  • Usage:
    standardTableaux(p,n)
  • Inputs:
    • p, an instance of the type Partition, the shape of the tableaux
    • n, an integer, a limit of the range of numbers that appear in the tableaux
  • Outputs:
    • an instance of the type TableauList, the list of semistandard tableaux

Description

The semistandard tableaux are tableaux that are strictly decreasing in rows and weakly decreasing in rows.

i1 : p = new Partition from {3,2}

o1 = Partition{3, 2}
