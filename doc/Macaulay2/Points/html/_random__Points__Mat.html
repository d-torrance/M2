randomPointsMat -- matrix of homogeneous coordinates of random points in projective space

  • Usage:
    m=randomPointsMat(R,n)
  • Inputs:
    • R, a ring, homogeneous coordinate ring of projective space Pm
    • n, an integer, number of points
  • Optional inputs:
    • AllRandom => ..., default value false
  • Outputs:
    • m, a matrix, of ZZ

Description

Produces a random m+1 x n matrix of scalars, with columns representing the coordinates of the point. The first m+1 x m+1 submatrix is the identity.

i1 : R = ZZ/31991[vars(0..3)]

o1 = R

o1 : PolynomialRing
 
i2 : randomPointsMat(R,3)

o2 = | 1 0 0 |
     | 0 1 0 |
     | 0 0 1 |
     | 0 0 0 |

             4      3
o2 : Matrix R  <-- R
