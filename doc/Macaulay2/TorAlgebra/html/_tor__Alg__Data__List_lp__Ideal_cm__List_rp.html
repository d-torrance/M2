torAlgDataList(Ideal,List) -- list invariants of a local ring

  • Function: torAlgDataList
  • Usage:
    torAlgDataList(R,L) or torAlgDataList(I,L)
  • Inputs:
    • I, an ideal, of a polynomial algebra contained in the irrelevant maximal ideal
    • L, a list, of keys from the hash table returned by torAlgData
  • Outputs:
    • a list, of values corresponding to the keys specified in L

Description

Extracts data from the hash table returned by torAlgData.

i1 : Q = QQ[x,y,z];
 
i2 : I = ideal(x*y,y*z,x^3,x^2*z,x*z^2-y^3,z^3);

o2 : Ideal of Q
 
i3 : torAlgDataList( I, {m, n, Class, p, q, r, PoincareSeries, BassSeries} )

                               (1 + T)          2 + 2T - 2T  - T  + T
o3 = {6, 2, G, 0, 1, 3, ----------------------, ----------------------}
                                  2     3    4            2     3    4
                        1 - T - 5T  - 2T  + T   1 - T - 5T  - 2T  + T
