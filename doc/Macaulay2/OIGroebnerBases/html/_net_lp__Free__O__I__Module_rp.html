net(FreeOIModule) -- display a free OI-module

  • Function: net
  • Usage:
    net F
  • Inputs:
    • F, an instance of the type FreeOIModule,
  • Outputs:
    • a net,

Description

Displays the basis symbol, basis element widths, degree shifts, underlying polynomial OI-algebra, and monomial order of a free OI-module.

i1 : P = makePolynomialOIAlgebra(2, x, QQ);
 
i2 : F = makeFreeOIModule(e, {1,2}, P);
 
i3 : net F

o3 = Basis symbol: e
     Basis element widths: {1, 2}
     Degree shifts: {0, 0}
     Polynomial OI-algebra: (2, x, QQ, RowUpColUp)
     Monomial order: Lex
