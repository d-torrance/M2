OIMonomialOrder -- monomial order option for free OI-modules

Description

Used as an optional argument in makeFreeOIModule to specify the desired monomial order.

Permissible values:

  • OIMonomialOrder => Lex for the lexicographic order induced by the monomial order of the underlying polynomial OI-algebra; see [1, Example 3.2]
  • OIMonomialOrder => List for the Schreyer order induced by a list of elements of a free OI-module; see [1, Definition 4.2]

References:

[1] M. Morrow and U. Nagel, Computing Gröbner Bases and Free Resolutions of OI-Modules, Preprint, arXiv:2303.06725, 2023.

Functions with optional argument named OIMonomialOrder:

  • makeFreeOIModule(...,OIMonomialOrder=>...) -- see makeFreeOIModule -- make a FreeOIModule object
