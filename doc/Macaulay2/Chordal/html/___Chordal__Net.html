ChordalNet -- a chordal network

Description

This type describes a chordal network representation of a polynomial ideal. The constructor of this type is chordalNet

Examples

  • chordal networks examples -- a new representation of polynomial ideals

Overview of chordal networks methods

Methods to visualize a chordal network:
  • displayNet -- displays a chordal network using Graphivz
  • net -- print a chordal network
  • digraph(ChordalNet) -- digraph associated to a chordal network
Methods to access properties of a chordal network:
  • nodes -- list of nodes of a chordal network
  • elimTree -- get the underlying elimination tree
  • ring -- get the underlying ring
  • isTriangular -- whether a chordal network is triangular
  • structure -- either "Monomial", "Binomial" or "None"
Elimination routines using chordal structure:
  • chordalElim -- performs elimination on the chordal network
  • chordalTria -- makes a chordal network triangular
Methods for triangular chordal networks:
