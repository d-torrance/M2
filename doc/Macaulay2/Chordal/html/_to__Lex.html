toLex -- change monomial order to lexicographic

  • Usage:
    toLex I
  • Inputs:
    • I, an ideal,
  • Outputs:
    • an ideal,

Description

i1 : R = QQ[x,y,z,MonomialOrder=>GRevLex];
 
i2 : I = ideal (x,y);

o2 : Ideal of R
 
i3 : J = toLex I

o3 = ideal (x, y)

o3 : Ideal of QQ[x..z]
 
i4 : describe ring J

o4 = QQ[x..z, Degrees => {3:1}, Heft => {1}, MonomialOrder => {MonomialSize => 32}]
                                                              {Lex => 3          }
                                                              {Position => Up    }
