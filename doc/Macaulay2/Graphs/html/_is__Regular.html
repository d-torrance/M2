isRegular -- determines whether a graph is regular

  • Usage:
    r = isRegular G
  • Inputs:
    • G, a graph,
  • Outputs:
    • r, a Boolean value, whether the graph G is regular or not.

Description

A graph is regular if all of its vertices have the same degree.

i1 : G = cycleGraph 5;
 
i2 : isRegular G

o2 = true

  • completeGraph -- Constructs a complete graph
  • cycleGraph -- Constructs a cycle graph
