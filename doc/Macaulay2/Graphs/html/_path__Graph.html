pathGraph -- A method that makes a path graph

  • Usage:
    P = pathGraph n
  • Inputs:
    • n, an integer,
  • Outputs:
    • P, a graph, the path grah of n vertices

Description

A path graph on n vertices is a cycle graph of n vertices minus one edge.

i1 : pathGraph 5

o1 = Graph{0 => {1}   }
           1 => {0, 2}
           2 => {1, 3}
           3 => {2, 4}
           4 => {3}
