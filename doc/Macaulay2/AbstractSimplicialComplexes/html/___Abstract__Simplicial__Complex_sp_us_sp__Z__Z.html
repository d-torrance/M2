AbstractSimplicialComplex _ ZZ -- the $k$ faces of a simplicial complex

  • Operator: _
  • Usage:
    K_k
  • Inputs:
    • K, an abstract simplicial complex,
    • k, an integer,
  • Outputs:
    • an abstract simplicial complex, the list of $k$ faces

Description

This method returns the collection of $k$ faces of a given AbstractSimplicialComplex.

i1 : K = abstractSimplicialComplex(3)

o1 = AbstractSimplicialComplex{-1 => {{}}                   }
                               0 => {{1}, {2}, {3}}
                               1 => {{1, 2}, {1, 3}, {2, 3}}
                               2 => {{1, 2, 3}}
