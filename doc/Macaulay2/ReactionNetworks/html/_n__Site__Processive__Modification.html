nSiteProcessiveModification -- A motif for purely processive phosphorylation

Description

This motif creates a network for an N-site processive phosphorylation system.

i1 : nSiteProcessiveModification 5

o1 = X_1+X_3-->X_5
     X_5-->X_1+X_3
     X_5-->X_6
     X_6-->X_5
     X_6-->X_7
     X_7-->X_6
     X_7-->X_8
     X_8-->X_7
     X_8-->X_9
     X_9-->X_8
     X_9-->X_1+X_4
     X_10-->X_2+X_3
     X_10-->X_11
     X_11-->X_10
     X_11-->X_12
     X_12-->X_11
     X_12-->X_13
     X_13-->X_12
     X_13-->X_14
     X_14-->X_13
     X_14-->X_2+X_4
     X_2+X_4-->X_14

o1 : ReactionNetwork

To rename species, use substitute(ReactionNetwork,List).

Ways to use nSiteProcessiveModification:

  • nSiteProcessiveModification(ZZ)

For the programmer

The object nSiteProcessiveModification is a method function.
