CellularResolutions -- A package for cellular resolutions of monomial ideals

Description

This package aims to make working with cellular resolutions of monomial ideals possible. Although the focus is on those constructs needed to work with cellular resolutions, the package additionally provides basic functions to work with cell complexes. For some direct ways to construct common cellular resolutions for monomial ideals, see taylorComplex and hullComplex. Introductions to cellular resolutions can be found in:

  • Ezra Miller and Bernd Sturmfels, Combinatorial commutative algebra, Graduate Texts in Mathematics 227, Springer-Verlag, New York, 2005. ISBN: 0-387-22356-8
  • Dave Bayer, Ireena Peeva and Bernd Sturmfels, Monomial Resolutions, Mathematical Research Letters 5, pp. 31-46 (1998)
  • Dave Bayer and Bernd Sturmfels, Cellular resolutions of monomial modules, Journal für die reine und angewandte Mathematik, vol. 1998, no. 502, 1998, pp. 123-140.

More generally, cell complexes can be constructed by creating cells using newCell or newSimplexCell, and then the maximal cells can be provided to cellComplex to construct a cell complex.

The example below follows Example 1.6 in Cellular resolutions of monomial modules, where two simplicial complexes X and Y are constructed on the same monomial ideal. However, only X supports a resolution.

i1 : S = QQ[a,b,c, Degrees=>{{1,0,0},{0,1,0},{0,0,1}}];
 
i2 : v101 = newCell({},a*c)

o2 = Cell of dimension 0 with label a*c

o2 : Cell
 
i3 : v012 = newCell({},b*c^2); v020 = newCell({},b^2); v210 = newCell({},a^2*b);
 
i6 : e112 = newCell({v101,v012})

                                         2
o6 = Cell of dimension 1 with label a*b*c

o6 : Cell
 
i7 : e022 = newCell({v012,v020}); e220 = newCell({v020,v210}); e211 = newCell({v210,v101});
 
i10 : e121 = newCell({v101,v020});
 
i11 : f122 = newCell({e112,e022,e121})

                                        2 2
o11 = Cell of dimension 2 with label a*b c

o11 : Cell
 
i12 : f221 = newCell({e220,e211,e121});
 
i13 : X = cellComplex(S,{f122,f221})

o13 = X

o13 : CellComplex
 
i14 : e212 = newCell({v210,v012}); f212 = newCell({e112,e211,e212}); f222 = newCell({e022,e220,e212});
 
i17 : Y = cellComplex(S,{f212,f222})

o17 = Y

o17 : CellComplex
 
i18 : prune HH X

o18 = cokernel | ac b2 bc2 a2b |
       
      -1

o18 : Complex
 
i19 : prune HH Y

o19 = cokernel | ac b2 bc2 a2b | <-- cokernel {1, 2, 1} | c a |
                                      
      -1                             0

o19 : Complex
 
i20 : Y121 = subcomplex(Y,a*b^2*c)

o20 = Y121

o20 : CellComplex
 
i21 : prune HH Y121

        1
o21 = QQ
       
      0

o21 : Complex
