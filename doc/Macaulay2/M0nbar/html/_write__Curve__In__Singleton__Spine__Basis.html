writeCurveInSingletonSpineBasis -- write a curve class in the singleton spine basis of curve

  • Usage:
    writeCurveInSingletonSpineBasis(C1)
  • Inputs:
    • C1, an instance of the type CurveClassRepresentativeM0nbar,
  • Outputs:
    • C2, an instance of the type CurveClassRepresentativeM0nbar,

Description

This function writes a curve class in the singleton spine basis of curves.

Recall that the singleton spine basis of curves is only defined on $\bar{M}_{0,n}$ if $n \geq 7$.

i1 : L= { {{1,2},{3,4},{5,6},{7,8}}=>1 };
 
i2 : C=curveClassRepresentativeM0nbar(8,L);
 
i3 : writeCurveInSingletonSpineBasis(C)
