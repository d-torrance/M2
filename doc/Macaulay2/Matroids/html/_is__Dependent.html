isDependent -- whether a subset is dependent

  • Usage:
    isDependent(M, S)
  • Inputs:
    • M, a matroid,
    • S, a set, of indices, or a list of elements in M
  • Outputs:
    • a Boolean value, whether S is dependent in M

Description

This method checks if the given subset of the ground set is dependent, i.e. contains a circuit.

i1 : M = matroid({a,b,c,d},{{a,b},{a,c}})

o1 = a "matroid" of rank 2 on 4 elements

o1 : Matroid
 
i2 : isDependent(M, {a,b})

o2 = false
 
i3 : isDependent(M, {d})

o3 = true

See also

  • independentSets(Matroid) -- independent subsets of a matroid

Ways to use isDependent:

  • isDependent(Matroid,Set)

For the programmer
