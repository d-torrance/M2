findSplitInclusion -- construct a split inclusion of one module into another

  • Usage:
    findSplitInclusion(M, N)
  • Inputs:
    • M, a module,
    • N, a module,
  • Optional inputs:
    • Tries (missing documentation) => ..., default value 50,
  • Outputs:
    • a matrix, a split injection $M \to N$ when one is found
    • when no such map is found

Description

This function performs a randomized search for maps $M \to N$ and $N \to M$ whose composition is an isomorphism of $M$.

See also

  • directSummands -- compute the direct summands of a module or coherent sheaf
  • generalEndomorphism -- construct a generic degree-zero endomorphism

Ways to use findSplitInclusion:

  • findSplitInclusion(Module,Module)

For the programmer

The object findSplitInclusion is a method function with options.
