findProjectors -- construct projectors on a homogeneous module

  • Usage:
    findProjectors M
  • Inputs:
    • M, a module or a coherent sheaf, expected to be homogeneous
  • Optional inputs:
    • Limit (missing documentation) => ..., default value null,
    • Splitting
    • Strategy (missing documentation) => ..., default value 3,
    • Tries (missing documentation) => ..., default value null,
    • Verbose (missing documentation) => ..., default value false,
  • Outputs:
    • a list, of endomorphisms that can be used to split $M$

Description

This routine constructs projectors from a general degree-zero endomorphism and its eigenvalues. It is the main splitting strategy for homogeneous modules.

See also

  • directSummands -- compute the direct summands of a module or coherent sheaf
  • generalEndomorphism -- construct a generic degree-zero endomorphism
  • findIdempotents -- construct idempotent endomorphisms

Ways to use findProjectors:

  • findProjectors(Module)

For the programmer

The object findProjectors is a method function with options.
