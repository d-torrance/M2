isDirectSummand -- test whether one module is a direct summand of another

  • Usage:
    isDirectSummand(L, M)
  • Inputs:
    • L, a module, the candidate summand
    • M, a module, the ambient module
  • Optional inputs:
    • Limit (missing documentation) => ..., default value null,
    • Splitting
    • Strategy (missing documentation) => ..., default value 3,
    • Tries (missing documentation) => ..., default value null,
    • Verbose (missing documentation) => ..., default value false,
  • Outputs:
    • a Boolean value, whether the algorithm finds $L$ as a direct summand of $M$

Description

This function tries to detect whether $L$ is a direct summand of $M$ by searching for maps $L \to M$ and $M \to L$ whose composition is an isomorphism of $L$.

The computation is randomized, so a return value of true certifies that a summand was found, while a return value of false only means that no splitting was found within the allotted number of attempts. The alias isSummand is provided for convenience.

When $L$ is free, the method instead searches for a surjection $M \to L$, which is enough to split off a free summand.
