generalEndomorphism -- construct a generic degree-zero endomorphism

  • Usage:
    generalEndomorphism M
  • Inputs:
    • M, a module or a coherent sheaf,
  • Optional inputs:
    • CoefficientRing (missing documentation) => ..., default value null,
    • Density (missing documentation) => ..., default value 1,
    • Height (missing documentation) => ..., default value 10,
    • MaximalRank (missing documentation) => ..., default value false,
    • UpperTriangular (missing documentation) => ..., default value false,
  • Outputs:
    • a matrix or a morphism of sheaves,

Description

This function forms a random linear combination of generators of the degree-zero endomorphism space of $M$. It is used internally by the splitting algorithms and can also be useful for experimentation.

See also

  • findProjectors -- construct projectors on a homogeneous module
  • findIdempotents -- construct idempotent endomorphisms

Ways to use generalEndomorphism:

  • generalEndomorphism(Matrix,Nothing,Matrix)
  • generalEndomorphism(Module)
  • generalEndomorphism(Module,Matrix)
  • generalEndomorphism(Module,Matrix,Matrix)
  • generalEndomorphism(Module,Matrix,Nothing)
