isomorphismTally -- group isomorphic modules or sheaves in a list

  • Usage:
    isomorphismTally L
  • Inputs:
    • L, a list, of modules or coherent sheaves
  • Optional inputs:
    • Homogeneous (missing documentation) => ..., default value true,
    • Strategy (missing documentation) => ..., default value null,
    • Strict (missing documentation) => ..., default value false,
    • Tries (missing documentation) => ..., default value null,
    • Verbose (missing documentation) => ..., default value false,
  • Outputs:
    • a list, of pairs consisting of a representative and its multiplicity

Description

The list is traversed up to isomorphism, returning one representative from each isomorphism class together with its count.
