doublePuzzle -- Produces a rhombus puzzle

  • Usage:
    doublePuzzle (a,b,c,d)
  • Inputs:
    • a, a string,
    • b, a string,
    • c, a string,
    • d, a string,
  • Optional inputs:
    • Equivariant (missing documentation) => ..., default value true,
    • Generic (missing documentation) => ..., default value true,
    • Ktheory (missing documentation) => ..., default value false,
    • Ktheory' (missing documentation) => ..., default value false,
    • Separation (missing documentation) => ..., default value null,
    • Steps (missing documentation) => ..., default value null,

Description

Given 4 strings, computes the number of pairs of puzzles glued together to form a rhombus with boundaries a,b,c,d in clockwise order.

In WebApp mode, the output is interactive and allows to test associativity of puzzles.

i1 : doublePuzzle("0101","0101","0101","0101",Equivariant=>false)
