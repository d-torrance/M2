pushforwardToPoint -- Push forward classes to a point

  • Usage:
    pushforwardToPoint a
    pushforwardToPointFromCotangent a
  • Inputs:
    • a, a ring element,

Description

This function returns the push forward of a (K-theory or cohomology) class from either the flag variety or its cotangent bundle to a point. The ring of input a must have been previously created with setupCotangent.
