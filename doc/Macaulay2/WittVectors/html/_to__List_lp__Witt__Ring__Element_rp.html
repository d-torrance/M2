toList(WittRingElement) -- Converts a WittRingElement into a List

  • Function: toList
  • Usage:
    toList(w)
  • Inputs:
    • w, an instance of the type WittRingElement,
  • Outputs:
    • a list,

Description

Turns a WittRingElement back into a List.

i1 : R = (ZZ/5)[x,y];
 
i2 : w = witt{x,y, x + y};
 
i3 : toList(w)

o3 = {x, y, x + y}

o3 : List
