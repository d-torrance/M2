wittRingIdeal -- Returns the n-th witt ideal in explicit form.

  • Usage:
    WI = witt(n, I)
  • Inputs:
    • n, an integer,
    • I, an ideal, an ideal in a polynomial ring R of positive characteristic.
  • Outputs:
    • WI, an ideal, the n-th witt of I, in explicit form.

Description

If R is a polynomial ring of positive characteristic, I is an ideal of R, and $n \geq 1$ is an integer, one has an ideal W_n(I) of W_n(R) given as the kernel of $W_n(R) \to W_n(R / I)$. The method wittRingIdeal(n, I) returns the ideal $W_n(I)$ in explicit form. Note that these ideals tend to have many more generators than I.

i1 : R = (ZZ / 3)[x,y,z];
 
i2 : I = ideal(x^2, y^2, z^2);

o2 : Ideal of R
 
i3 : WI = wittRingIdeal(2, I);
