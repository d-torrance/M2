ring(WittRingElement) -- Returns the Witt ring that a WittRingElement belongs to

  • Function: ring
  • Usage:
    R = ring(w)
  • Inputs:
    • w, an instance of the type WittRingElement,
  • Outputs:
    • R, a ring,

Description

Returns the WittPolynomialRing or WittQuotientRing that the input belongs to

i1 : R = (ZZ/5)[x,y]

o1 = R

o1 : PolynomialRing
 
i2 : w = witt{x, x+y}

o2 = {x, x + y}

o2 : WittRingElement
 
i3 : ring(w)

o3 = Witt (R)
         2

o3 : WittPolynomialRing
 
i4 : R = (ZZ/5)[x,y,z] / ideal(x^2 + y^2 + z^2)

o4 = R

o4 : QuotientRing
 
i5 : w = witt{x, y, z}

o5 = {x, y, z}

o5 : WittRingElement
 
i6 : ring(w)

o6 = Witt (R)
         3

o6 : WittQuotientRing
