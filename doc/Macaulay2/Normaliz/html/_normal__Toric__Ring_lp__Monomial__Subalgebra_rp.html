normalToricRing(MonomialSubalgebra) -- normalization of a toric ring

  • Function: normalToricRing
  • Usage:
    normalToricRing S
  • Inputs:
    • a monomial subalgebra, the toric ring
  • Optional inputs:
    • allComputations (missing documentation) => ..., default value false,
    • grading (missing documentation) => ..., default value {},
  • Outputs:
    • a monomial subalgebra, the normalization of the toric ring

Description

The toric ring S is the monomial subalgebra given. The function computes the normalization T of S, which is the integral closure in its field of fractions. 
i1 : R=ZZ/37[x,y,t];
 
i2 : S=createMonomialSubalgebra {x^3, x^2*y, y^3, x*y^2};
 
i3 : normalToricRing S
