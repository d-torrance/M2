sinh(RObject) -- hyperbolic sine of an R object

  • Function: sinh
  • Usage:
    sinh x
  • Inputs:
    • x, a R object,
  • Outputs:
    • a R object, the element-wise hyperbolic sine of x;

Description

Compute the hyperbolic sine of each element of an R numeric vector, calling R's sinh.

i1 : sinh RObject 0

o1 = [1] 0

o1 : RObject of type double
