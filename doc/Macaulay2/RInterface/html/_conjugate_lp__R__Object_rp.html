conjugate(RObject) -- complex conjugate of an R object

  • Function: conjugate
  • Usage:
    conjugate z
  • Inputs:
    • z, a R object,
  • Outputs:
    • a R object, the element-wise complex conjugate of z;

Description

Compute the complex conjugate of each element of an R complex vector, calling R's Conj.

i1 : z = RObject(3 + 2*ii)

o1 = [1] 3+2i

o1 : RObject of type complex
 
i2 : conjugate z

o2 = [1] 3-2i

o2 : RObject of type complex
