sqrt(RObject) -- square root of an R object

  • Function: sqrt
  • Usage:
    sqrt x
  • Inputs:
    • x, a R object,
  • Outputs:
    • a R object, the element-wise square root of x;

Description

Compute the square root of each element of an R numeric vector, calling R's sqrt.

i1 : x = RObject 2

o1 = [1] 2

o1 : RObject of type integer
 
i2 : sqrt x

o2 = [1] 1.414214

o2 : RObject of type double
