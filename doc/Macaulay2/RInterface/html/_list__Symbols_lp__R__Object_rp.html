listSymbols(RObject) -- list symbols in an R environment

  • Function: listSymbols
  • Usage:
    listSymbols x
  • Inputs:
    • x, a R object or a R context, an R environment (type environment) or context;
  • Outputs:
    • an instance of the type TABLE, an HTML table showing each symbol's name, R type, and value;

Description

Returns a table of the symbols defined in an R environment. When given an RContext, the symbols in its associated environment are listed.

i1 : ctx = RContext "x <- 5L; y <- \"hello\""

o1 = ctx

o1 : RContext
 
i2 : listSymbols ctx

o2 = symbol  class      value
     ------  -----      -----      
     x       integer    [1] 5      
     y       character  [1] "hello"
