realPart(RObject) -- real part of an R object

  • Function: realPart
  • Usage:
    realPart z
  • Inputs:
    • z, a R object,
  • Outputs:
    • a R object, the element-wise real part of z;

Description

Extract the real part of each element of an R complex vector, calling R's Re.

i1 : z = RObject(3 + 2*ii)

o1 = [1] 3+2i

o1 : RObject of type complex
 
i2 : realPart z

o2 = [1] 3

o2 : RObject of type double
