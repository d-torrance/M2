RSymbol -- look up an R object by name

  • Usage:
    RSymbol str
  • Inputs:
    • str, a string or a thing,
  • Outputs:
    • a R object, the value of the R object named str;

Description

Look up an R object by name, returning its value. For example, this can be useful for loading datasets.

  • RSymbol(Thing)
