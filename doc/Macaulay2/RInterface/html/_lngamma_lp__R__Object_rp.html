lngamma(RObject) -- log-gamma function of an R object

  • Function: lngamma
  • Usage:
    lngamma x
  • Inputs:
    • x, a R object,
  • Outputs:
    • a R object, the element-wise log of the gamma function of x;

Description

Compute the natural logarithm of the gamma function of each element of an R numeric vector, calling R's lgamma.

i1 : lngamma RObject 2

o1 = [1] 0

o1 : RObject of type double
