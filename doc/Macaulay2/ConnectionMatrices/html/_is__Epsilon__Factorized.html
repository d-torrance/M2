isEpsilonFactorized -- checks whether a system of connection matrices is in $\epsilon$-factorized form

  • Usage:
    isEpsilonFactorized(A,eps)
    isEpsilonFactorized(M,eps)
  • Inputs:
    • A, a list, a system of connection matrices
    • M, a matrix, a connection matrix
    • eps, a ring element, parameter for which the factorization property should be tested
  • Outputs:
    • b, a Boolean value, true or false

Description

This method returns true if the system of connection matrices factors out (a power of) eps, such that the resulting matrices are independent of eps.

i1 : D = makeWeylAlgebra(frac(QQ[ϵ])[x]);
 
i2 : I = ideal(x*(1-x)*dx^2 - ϵ*(1-x)*dx);

o2 : Ideal of D
 
i3 : A = pfaffianSystem(I)

o3 = {| 0 1   |}
      | 0 ϵ/x |

o3 : List
 
i4 : isEpsilonFactorized(A, ϵ)

o4 = false

The property of being epsilon factorizable depends on a choice of basis.

i5 : A = pfaffianSystem(I, {1_D, 1/ϵ*dx})

o5 = {| 0 ϵ   |}
      | 0 ϵ/x |

o5 : List
 
i6 : isEpsilonFactorized(A, ϵ)

o6 = true
