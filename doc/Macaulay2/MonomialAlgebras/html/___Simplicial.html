Simplicial -- Option of randomSemigroup and randomMonomialAlgebra to return a simplicial semigroup.

Description

Option of randomSemigroup and randomMonomialAlgebra to return a set of generators of a simplicial semigroup (with coordinate sum a) such that the standard vectors a*e_i are among the Hilbert basis.

The default value is false.

Functions with optional argument named Simplicial:

  • randomMonomialAlgebra(...,Simplicial=>...)
  • randomSemigroup(...,Simplicial=>...)

For the programmer

The object Simplicial is a symbol.
