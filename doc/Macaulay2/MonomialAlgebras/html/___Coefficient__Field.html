CoefficientField -- Option to set the coefficient field.

Description

This option can be used to set the coefficient field of the polynomial rings created by decomposeMonomialAlgebra, decomposeHomogeneousMA, monomialAlgebra.

The standard option is ZZ/101.

Functions with optional argument named CoefficientField:

  • affineAlgebra(...,CoefficientField=>...)
  • binomialIdeal(...,CoefficientField=>...)
  • decomposeHomogeneousMA(...,CoefficientField=>...)
  • decomposeMonomialAlgebra(...,CoefficientField=>...)
  • monomialAlgebra(...,CoefficientField=>...)
  • regularityMA(...,CoefficientField=>...)

For the programmer

The object CoefficientField is a symbol.
