powerTraces -- Compute the traces of powers of a matrix

Description

This is what you do:

i1 : ea = exteriorExtension(3, 6, QQ);
 
i2 : A = ea.ad(first ea.bases#1);

              55       55
o2 : Matrix QQ   <-- QQ
 
i3 : ea.powerTraces A

     +-----+-----+----+
o3 = |power|trace|rank|
     +-----+-----+----+
     |1    |0    |20  |
     +-----+-----+----+
     |2    |0    |1   |
     +-----+-----+----+

The list outputs the trace of each power until the power ranks stabilize, or until the power is equal to the dimension of the algebra. These are invariants of the element x in ad(x).

i4 : ea = exteriorExtension(3, 9, QQ);
 
i5 : E = ea.appendage

o5 = E

o5 : PolynomialRing, 9 skew commutative variable(s)
 
i6 : A = ea.ad(E_0*E_1*E_2 + E_3*E_4*E_5 + E_6*E_7*E_8);

              248       248
o6 : Matrix QQ    <-- QQ
 
i7 : ea.powerTraces A
