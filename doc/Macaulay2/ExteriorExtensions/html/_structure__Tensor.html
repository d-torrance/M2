structureTensor -- Constructs the structureTensor of the ExteriorExtension

Description

The structure tensor of an algebra is the representative of the bilinear product as a hypermatrix. The matrices constructed by this can get very large, and take a long time to compute. The output can be very large, so we return a hashTable with only the non-zero values.

i1 : printWidth = 450;
 
i2 : ea = exteriorExtension(3, 6, QQ);
 
i3 : B = structureTensor ea
