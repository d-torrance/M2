localResolution -- find a resolution over a local ring

  • Usage:
    localResolution M
  • Inputs:
    • M, a module
    • or
    • an ideal
    • Strategy, see freeResolution(...,Strategy=>...)
    • SyzygyLimit, see freeResolution(...,SyzygyLimit=>...)
    • HardDegreeLimit, see freeResolution(...,HardDegreeLimit=>...)
    • LengthLimit, see freeResolution(...,LengthLimit=>...)
    • StopBeforeComputation, see freeResolution(...,StopBeforeComputation=>...)
    • DegreeLimit, see freeResolution(...,DegreeLimit=>...)
    • ParallelizeByDegree, see freeResolution(...,ParallelizeByDegree=>...)
    • SortStrategy, see freeResolution(...,SortStrategy=>...)
    • PairLimit, see freeResolution(...,PairLimit=>...)
  • Optional inputs:
    • DegreeLimit => ..., default value infinity
    • HardDegreeLimit => ..., default value {}
    • LengthLimit => ..., default value infinity
    • PairLimit => ..., default value infinity
    • ParallelizeByDegree => ..., default value false
    • SortStrategy => ..., default value 0
    • StopBeforeComputation => ..., default value false
    • Strategy => ..., default value null
    • SyzygyLimit => ..., default value infinity
  • Outputs:
    • a complex

Description

This method has option inputs that it inherits from

freeResolution.

This function iterates

localsyz to obtain a resolution over the local ring.
