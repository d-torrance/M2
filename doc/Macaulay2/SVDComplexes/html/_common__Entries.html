commonEntries -- lists of positions, where they coincide up to threshold

  • Usage:
    (P1,P2)=commonEntries(L1,L2)
  • Inputs:
    • L1, a list,
    • L2, a list, descending lists of non-negative real numbers
  • Optional inputs:
    • Threshold (missing documentation) => a real number, default value .0001, relative error allowed for equality
  • Outputs:
    • P1, a list,
    • P2, a list,

Description

Determine the positions, where the non-zero numbers in both lists which coincide up to a threshold. This is needed in the Laplacian method to compute the SVD normal form of a complex
