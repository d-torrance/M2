net(GrMatchingField) -- display a matching field

  • Function: net
  • Usage:
    net L
  • Inputs:
    • L, an instance of the type MatchingField, an instance of the type GrMatchingField, or an instance of the type FlMatchingField,
  • Outputs:
    • a net

Description

The net of a matching field displays size of the tuples of the matching field and the maximum value in a tuple for that matching field. See MatchingField, GrMatchingField, and FlMatchingField.
