matchingFieldFromPermutation -- Matching field parametrised by permutations

  • Usage:
    Lgr = matchingFieldFromPermutation(k, n, S)
    Lfl = matchingFieldFromPermutation(tupleSizeList, n, S)
  • Inputs:
    • k, an integer, positive integer; the size of the tuples of the Grassmannian matching field
    • tupleSizeList, a list, positive integers; the sizes of the tuples of the flag matching field
    • n, an integer, positive integer; the tuples have entries in 1 .. n
    • S, a list, permutation of 1 .. n
  • Optional inputs:
    • RowNum => an integer, default value 2, which row of the digonal weight matrix to permute
    • UsePrimePowers => a Boolean value, default value false, use multiples of prime power used for the entries of the diagonal weight matrix
    • PowerValue => an integer, default value 0, use multiples of powers this value in the diagonal weight matrix
    • ScalingCoefficient => an integer, default value 1, the value by which to scale the permuted row of the diagonal weight matrix
  • Outputs:
    • Lgr, an instance of the type GrMatchingField,
    • Lfl, an instance of the type FlMatchingField,

Description

Let $M_0 \in \RR^{k \times n}$ be a matrix that induces the diagonal matching field. Usually, we take this matrix to be $(m_{i,j})$ with $m_{i,j} = (n-j)n^(i-2)$ if $i > 1$ and $m_{i,j} = 0$ if $i = 1$. Note that this matrix is different to the weight matrix of the matching field produced by the function diagonalMatchingField, however the matching fields are the same. Given a permutation $\sigma \in S_n$, the matching field associated to $\sigma$ has weight matrix $M_\sigma$, which is the same as $M_0$ except for the second row. The second row of $M_\sigma$ is obtained from the second row of $M$ by permuting the entries according to $\sigma$. Explicitly, they are given by $\sigma(1), \sigma(2), \dots, \sigma(n)$. For instance, if $\sigma = (n, n-1, \dots, 1) \in S_n$ is the permutation written in single-line notation, then the matching field induced by $M_\sigma$ is the diagonal matching field.

The optional argument UsePrimePowers is used to modify the original diagonal weight matrix $M_0$. If the option is set to true then we use the matrix with entries $m_{i,j} = (n-j) p^(i-2)$ if $i>1$ and $m_{i,j} = 0$ if $i = 1$, where $p \ge n$ is the smallest prime number greater than or equal to $n$.

The optional argument PowerValue is used to give a specific value to $p$ in the diagonal weight matrix as described above. If the value is not positive, then the argument is ignored. This option should be used carefully. If the power value is set incorrectly (typically by setting a value that is too low) then the weight matrix may not be generic, i.e., it does not define a matching field. However, in such a case, the function produces a matching field without error, as shown in the example $L7$ below. Working with such matching fields may lead to unexpected behaviours.

Any positive integer supplied to the argument PowerValue takes precedence over UsePrimePowers. The optional argument ScalingCoefficient is used to scale the entries of the row that is permuted by the permutation. If UsePrimePowers is set to true, and $p \ge n$ is the smallest prime number less than $n$, then the scaling coefficient can be set to any $c \in \{1, 2, \dots, p-1\}$ and the resulting weight matrix is guaranteed to be generic.

i18 : L8 = matchingFieldFromPermutation(3, 6, {6,1,5,2,3,4}, UsePrimePowers => true, ScalingCoefficient => 3)

o18 = Grassmannian Matching Field for Gr(3, 6)
