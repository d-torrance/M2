canonicalSeries -- Canonical series of the normalization of a plane curve

  • Usage:
    M = canonicalSeries R
  • Inputs:
    • R, a ring, ring of a plane curve
  • Optional inputs:
    • Conductor => ..., default value null
  • Outputs:
    • M, a matrix, a 1 x g matrix representing the canonical series
