negative -- implements the inverse in the group law of a curve of genus 1

  • Usage:
    q = negative(o,p,E)
    qE = negative(oE,pE)
  • Inputs:
    • o, a list,
    • oE, an ideal,
    • p, a list,
    • pE, an ideal,
    • E, a ring,
  • Optional inputs:
    • Conductor => ..., default value null
  • Outputs:
    • q, a list,
    • qE, an ideal,

Description

Implements the additive inverse in the group law on the smooth points of a plane curve E of genus 1, represented by its homogeneous coordinate ring, with chosen zero point o.

i1 : S = QQ[x,y,z]

o1 = S

o1 : PolynomialRing
 
i2 : E = S/ideal"x3+y3+z3"

o2 = E

o2 : QuotientRing
 
i3 : o = {1,-1,0}

o3 = {1, -1, 0}

o4 = {0, 1, -1}
