directImageComplex -- direct image complex

  • Usage:
    directImageComplex F
  • Optional inputs:
    • Regularity => ..., default value null

Description

Forms a minimal free complex representing the direct image complex of $F$ in the derived category, where $F$ is a module, chain complex or map of modules.

Caveat

The option "Regularity" is currently not supported.

Ways to use directImageComplex:

  • directImageComplex(Complex) -- direct image of a chain complex
  • directImageComplex(Matrix) -- map of direct image complexes
  • directImageComplex(Module) -- Complex representing the direct image

For the programmer

The object directImageComplex is a method function with options.
