monjMult -- j-multiplicity of a monomial ideal

  • Usage:
    monjMult I
  • Inputs:
    • I, an ideal,
  • Outputs:
    • an integer, the j-multiplicity of I.

Description

Given a monomial ideal I, this function computes the j-multiplicity of I following the method of Jeffries-Montaño.

i1 : R = QQ[x,y]

o1 = R
