length(PythonObject) -- returns the length of a python object

  • Function: length
  • Usage:
    length x
  • Inputs:
    • x, a python object,
  • Outputs:
    • an integer,

Description

This is equivalent the Python len function.

i1 : length toPython "Hello, world!"

o1 = 13
 
i2 : length pythonValue "[1,2,3,4,5]"

o2 = 5
