acosh(PythonObject) -- inverse hyperbolic cosine of a python object

  • Function: acosh
  • Usage:
    acosh x
  • Inputs:
    • x, a python object,
  • Outputs:
    • a python object,

Description

This calls Python's built-in math.acosh function, which computes the inverse hyperbolic cosine of x.
