pipInstall -- install a Python package

  • Usage:
    pipInstall pkg
  • Inputs:
    • pkg, a string,

Description

This method installs a Python package. It is equivalent to calling pip install pkg on the command line.

You likely want to create a virtual environment first. See setupVirtualEnvironment.

Let's suppose that one exists in applicationDirectory() | "venv".

i1 : loadPackage("Python", Configuration => {
          "executable" => applicationDirectory() | "venv/bin/python3"})

o1 = Python
