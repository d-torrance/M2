abs(PadicNumber) -- p-adic absolute value

  • Function: abs
  • Usage:
    abs x
  • Inputs:
    • x, a p-adic number,
  • Outputs:
    • a rational number,

Description

Returns the $p$-adic absolute value $|x|_p = p^{-\nu_p(x)}$.

i1 : abs QQ_7 49

      1
o1 = --
     49

o1 : QQ
 
i2 : abs QQ_7(1/7)

o2 = 7
 
i3 : abs QQ_7 0

o3 = 0
