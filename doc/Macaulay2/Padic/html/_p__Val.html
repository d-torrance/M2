pVal -- p-adic valuation of a p-adic number

  • Usage:
    pVal x
  • Inputs:
    • x, a p-adic number,
  • Outputs:
    • an integer, or InfiniteNumber if x is zero

Description

Returns the $p$-adic valuation $\nu_p(x)$, i.e., the exponent $\nu$ in the factorization $x = u p^\nu$ where $u$ is a $p$-adic unit.

i1 : pVal QQ_7 49

o1 = 2
 
i2 : pVal QQ_7(1/7)

o2 = -1
 
i3 : pVal QQ_7 0

o3 = infinity

o3 : InfiniteNumber
