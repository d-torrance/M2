PadicNumber << ZZ -- multiply a p-adic number by a power of p

  • Operator: <<
  • Usage:
    x << n
  • Inputs:
    • x, a p-adic number,
    • n, an integer,
  • Outputs:
    • a p-adic number, x times p^n;

Description

Returns $x \cdot p^n$, shifting the $p$-adic expansion left by $n$ places. A negative shift divides by $p^{|n|}$.

i1 : QQ_7 3 << 2

o1 = 3*7^2

o1 : QQ  (of precision 20)
       7
 
i2 : QQ_7 3 << -1

o2 = 3*7^-1

o2 : QQ  (of precision 20)
       7
