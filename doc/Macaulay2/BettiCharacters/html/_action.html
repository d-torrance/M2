action -- define finite group action

Description

Use this function to set up a finite group action on a minimal free resolution or graded module. See the specific use cases for more details.

Menu

  • Action -- the class of all finite group actions
  • action(Complex,List,List,ZZ) -- define finite group action on a resolution
  • action(Module,List,List) -- define finite group action on a graded module
  • Semidirect -- action of semidirect product with torus
  • Sub -- format ring actors as one-row substitution matrices
