isSmooth(Ideal) -- checks smoothness of an ideal or of a Curve

  • Function: isSmooth

Description

The method isSmooth uses Jacobian criterion to check the smoothness of an ideal or a Curve.

Synopsis

    B = isSmooth(I)
  • Inputs:

  • Outputs:
    • B, a Boolean value
