MultidimensionalMatrix * MultidimensionalMatrix -- product of multidimensional matrices

  • Operator: *
  • Usage:
    M * N
  • Inputs:
    • M, a multidimensional matrix, a multidimensional matrix of shape $k_1\times\cdots\times k_r$
    • N, a multidimensional matrix, a multidimensional matrix of shape $l_1\times\cdots\times l_s$ with $k_r = l_1$
  • Outputs:
    • a multidimensional matrix, the convolution (or product) $M * N$, which is a multidimensional matrix of shape $k_1\times\cdots\times k_{r-1}\times l_2\times\cdots\times l_s$
