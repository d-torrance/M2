randomCollectionOfCells -- Random collection of cells up to a given size

  • Usage:
    randomCollectionOfCells m
  • Inputs:
    • m, a positive integer bound on the number of cells
  • Outputs:
    • a randomly generated collection of cells of size at most m

Description

Produces a random collection of cells with a randomly chosen number of cells between $1$ and the given bound $m$.

i1 : Q = randomCollectionOfCells 8

o1 = {{1, 1}, {1, 0}, {1, 2}, {0, 0}}

o1 : CollectionOfCells

See also

  • cellCollection -- Create a collection of cells
  • randomCollectionWithFixedRank -- Random collection of cells with fixed rank
