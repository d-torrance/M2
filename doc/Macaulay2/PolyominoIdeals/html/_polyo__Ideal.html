polyoIdeal -- Ideal of inner 2-minors of a collection of cells

  • Usage:
    polyoIdeal Q
  • Inputs:
    • Q, a collection of cells
  • Optional inputs:
    • Field => ..., default value QQ, optional argument for polyoIdeal and adjacent2MinorIdeal
    • RingChoice => ..., default value 1, optional argument for polyoIdeal
    • TermOrder => ..., default value Lex, optional argument for polyoIdeal and adjacent2MinorIdeal
  • Outputs:
    • the inner 2-minors ideal of the collection of cells encoded by Q

Description

Let $\mathcal{P}$ be a collection of cells. This routine returns the ideal $I_{\mathcal{P}}$ of the inner 2-minors of $\mathcal{P}$.
Moreover, if $\mathcal{P}$ is a polyomino, then it returns the polyomino ideal of $\mathcal{P}$. 

i1 : Q = cellCollection {{1,1}, {2,1}, {2,2}}

o1 = {{1, 1}, {2, 1}, {2, 2}}

o1 : CollectionOfCells
 
i2 : I = polyoIdeal Q

o2 = ideal (x   x    - x   x   , x   x    - x   x   , x   x    - x   x   ,
             3,3 2,2    3,2 2,3   3,2 1,1    3,1 1,2   3,3 2,1    3,1 2,3 
     ------------------------------------------------------------------------
     x   x    - x   x   , x   x    - x   x   )
      3,2 2,1    3,1 2,2   2,2 1,1    2,1 1,2

o2 : Ideal of QQ[x   , x   , x   , x   , x   , x   , x   , x   ]
                  3,3   3,2   3,1   2,3   2,2   2,1   1,2   1,1
