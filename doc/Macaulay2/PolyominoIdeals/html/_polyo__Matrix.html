polyoMatrix -- Matrix attached to a collection of cells

  • Usage:
    polyoMatrix Q
  • Inputs:
    • Q, a collection of cells
  • Outputs:
    • the matrix attached to the collection of cells encoded by Q.

Description

Let $\mathcal{P}$ be a collection of cells and $[(a,b),(c,d)]$ be the smallest interval of $\ZZ^2$ containing $\mathcal{P}$. The matrix $M(\mathcal{P})$ is a matrix having $d-b+1$ rows and $c-a+1$ columns with $M(\mathcal{P})_{i,j}=x_{(i,j)}$ if $(i,j)$ is a vertex of $\mathcal{P}$, otherwise it is zero.
This routine returns the matrix of the collection of cells encoded by Q. In the following example we assume for simplicity that the smallest interval containing $\mathcal{P}$ is $[(1,1),(c,d)]$, with $c,d>1$.

i1 : Q = cellCollection {{1,1}, {2,1}, {2,2}}

o1 = {{1, 1}, {2, 1}, {2, 2}}
