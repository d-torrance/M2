projectiveDegrees(RationalMap) -- projective degrees of a rational map

  • Function: projectiveDegrees
  • Usage:
    projectiveDegrees Phi
  • Inputs:
    • Phi, a rational map
  • Optional inputs:
    • BlowUpStrategy => ..., default value "Eliminate",
    • Certify => ..., default value false, whether to ensure correctness of output
    • NumDegrees => ..., default value infinity,
    • Verbose => ..., default value true,
  • Outputs:
    • a list, the list of projective degrees of Phi

Description

This computation is done through the corresponding method for ring maps. See projectiveDegrees(RingMap) for more details and examples.
