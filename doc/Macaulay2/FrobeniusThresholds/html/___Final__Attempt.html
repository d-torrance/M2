FinalAttempt -- an option for the function fpt to perform a final check attempting find an F-pure threshold

Description

An option for the function fpt, specifying whether the convexity of the $F$-signature function and a secant line argument are to be used as an attempt to refine the interval containing the $F$-pure threshold, or to find its exact value. Takes on Boolean values; default value is false.

Functions with optional argument named FinalAttempt:

  • fpt(...,FinalAttempt=>...) -- see fpt -- attempt to compute the F-pure threshold of a polynomial at the origin or globally

For the programmer

The object FinalAttempt is a symbol.
