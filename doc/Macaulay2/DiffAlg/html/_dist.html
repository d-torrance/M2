dist -- produces a DiffAlgDistribution from a list

  • Usage:
    dist(L)
  • Inputs:
    • L, a list, list of vector fields, see DiffAlgField
  • Outputs:
    • an instance of the type DiffAlgDistribution, generated by the vector fields in the given list.

Description

This command checks that all the elements in the list are vector fields.

i1 : X = newField("3*x_0*ax_0+x_1*ax_1")

o1 = 3x ax  + x ax
       0  0    1  1

o1 : DiffAlgField
 
i2 : Y = radial 3

o2 = x ax  + x ax  + x ax  + x ax
      0  0    1  1    2  2    3  3

o2 : DiffAlgField
 
i3 : dist {X,Y}

o3 = {3x ax  + x ax , x ax  + x ax  + x ax  + x ax }
        0  0    1  1   0  0    1  1    2  2    3  3

o3 : DiffAlgDistribution
