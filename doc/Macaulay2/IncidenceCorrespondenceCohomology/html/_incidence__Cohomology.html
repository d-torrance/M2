incidenceCohomology -- Computes dimension or character of sheaf cohomology of line bundles on the incidence correspondence

  • Usage:
    C = incidenceCohomology(L)
    C = incidenceCohomology(L, R)
  • Inputs:
    • L, a list, List of integers {i,p,a,b,n} List of integers {i,p,a,b,n} where i is the cohomological degree, p is the characteristic of the field, the couple (a,b) indicates the line bundle $\mathcal{O}_X(a,b)$ on the incidence correspondence $X\subseteq \mathbb{P}\times \mathbb{P}^\vee$, and $n$ is the dimension of $\mathbb{P} +1
    • R, a polynomial ring, Laurent polynomial ring, ambient ring for the character of the cohomology group, i.e. ZZ[x_1..x_n,x_1^{-1}..x_n^{-1}] where n-1 is the dimension of projective space
  • Optional inputs:
    • FindCharacter => ..., default value false, An option to compute the character instead of the dimension
  • Outputs:
    • C, an integer, dimension of the cohomology group (with the option to instead have the character)

Description

This function computes the sheaf cohomology $H^i(X, \mathcal{O}_X(a,b))$, of the line bundle $\mathcal{O}_X(a,b)$ on the incidence correspondence $X$. The underlying characteristic of the field is p, prime or zero.

i1 : i = 0; p = 0; a = 7; b = 6; n = 3;
 
i6 : incidenceCohomology({i,p,a,b,n})

o6 = 420
 
i7 : i = 1; p = 3; a = 6; b = -8; n = 3;
 
i12 : incidenceCohomology({i,p,a,b,n})

o12 = 9
 
i13 : i = 1; p = 0; a = 6; b = -8; n = 3;
 
i18 : incidenceCohomology({i,p,a,b,n})

o18 = 0

We could instead ask for the character instead of just the dimension, setting the option FindCharacter to be true.

i19 : i = 3; p = 0; a = -2; b = -6; n = 3;
 
i24 : incidenceCohomology({i,p,a,b,n}, FindCharacter => true)
