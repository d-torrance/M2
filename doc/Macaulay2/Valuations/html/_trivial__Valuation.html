trivialValuation -- The trivial valuation

  • Usage:
    v = trivialValuation
  • Outputs:
    • v, an instance of the type Valuation, the trivial valuation

Description

This valuation returns zero for all nonzero inputs.

i1 : v = trivialValuation;
 
i2 : v (-13)

o2 = 0
 
i3 : v 100000000

o3 = 0
 
i4 : v (14/23)

o4 = 0
 
i5 : v 0

o5 = infinity

o5 : InfiniteNumber
