qqRing -- part of a RandomNicePencil

  • Usage:
    S = rNP.qqRing
  • Outputs:
    • S, a ring, polynomial ring in g x's, g y's, z_1, z_2, and s, t.

Description

The ambient polynomial ring where the quadratic form qq = s*q1 + t*q2 lives.

i1 : setRandomSeed 0
 -- setting random seed to 0

o1 = 0
 
i2 : kk=ZZ/101;
 
i3 : g=1;
 
i4 : rNP=randNicePencil(kk,g);
 
i5 : S=rNP.qqRing

o5 = S

o5 : PolynomialRing
