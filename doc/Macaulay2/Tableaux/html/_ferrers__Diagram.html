ferrersDiagram -- a net of the Ferrers diagram

  • Usage:
    ferrersDiagram(lam, mu)
    ferrersDiagram T
  • Inputs:
    • lam, an instance of the type Partition, the outer shape $\lambda$.
    • mu, an instance of the type Partition, the inner shape $\mu$. If not given, if is assumed to be the $0$ partition.
    • T, an instance of the type YoungTableau, a skew tableau.
  • Outputs:
    • n, a net, a representation of the Ferrers diagram of shape $\lambda/\mu$.
