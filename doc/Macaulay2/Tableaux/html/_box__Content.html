boxContent -- compute the content of a box of a tableau

  • Usage:
    boxContent(i,j)
  • Inputs:
    • i, an integer, the row index of a box.
    • j, an integer, the column index of a box.
  • Outputs:
    • n, an integer, the hook length of box (i,j).

Description

The content of box (i,j) is defined as $j-i$.

i1 : T = youngTableau(new Partition from {6,6,5,3,1}, new Partition from {2,1,1})

i2 : boxContent(1,1)
