YoungTableau _ Sequence -- get the entry at a specific position

  • Operator: _
  • Usage:
    T_seq
    T_(i,j)
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
    • seq, a sequence, a pair (i,j) of integers in ZZ.
  • Outputs:
    • theBox, a thing, the entry of T in position (i,j).

Description

The notations (T^i)#j, (T_j)#i, and T_(i,j) are all equivalent for valid positions (i,j). However, the notation T_(i,j) will raise an error for nonvalid positions, whereas the other two will return null.

i1 : T = youngTableau(new Partition from {4,3,1,0}, new Partition from {1,1}, {1,2,3,4,5,6})

         ┌───┬───┬───┐
o1 =     │ 1 │ 2 │ 3 │
         ├───┼───┼───┘
         │ 4 │ 5 │    
     ┌───┼───┴───┘    
     │ 6 │            
     └───┘            

o1 : YoungTableau
 
i2 : (T^0)#1

o2 = 1
 
i3 : (T_1)#0

o3 = 1
 
i4 : T_(0,1)

o4 = 1
