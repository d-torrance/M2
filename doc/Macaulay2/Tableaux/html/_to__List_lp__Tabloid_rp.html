toList(Tabloid) -- list representation of a tabloid

  • Function: toList
  • Usage:
    toList T
  • Inputs:
    • T, an instance of the type Tabloid, a tabloid.
  • Outputs:
    • l, a bag, a bagged list of all Young tableaux in the equivalence class T.
