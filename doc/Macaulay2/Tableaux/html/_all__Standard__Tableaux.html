allStandardTableaux -- list all standard Young tableaux of a given shape

  • Usage:
    allSemistandardTableaux(lam)
  • Inputs:
    • lam, an instance of the type Partition, the shape, $\lambda$.
  • Outputs:
    • b, a bag, bagged list of all SYT of given shape and entries in $\{1,\ldots,N\}$, where $N$ is the size of $\lambda$.

Description

i1 : theBag = allStandardTableaux(new Partition from {4,3,1})

o1 = -*a bagged sequence of length 70*-
