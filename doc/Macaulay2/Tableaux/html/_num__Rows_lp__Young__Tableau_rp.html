numRows(YoungTableau) -- the number of rows in a tableau

  • Function: numRows
  • Usage:
    numRows T
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
  • Outputs:
    • n, an integer, the number of rows in T.

Description

The number of rows is the same as the length of its shapes, excluding trailing $0$'s.

i1 : T = youngTableau(new Partition from {4,3,1,0}, new Partition from {1,1,3,2,0})
