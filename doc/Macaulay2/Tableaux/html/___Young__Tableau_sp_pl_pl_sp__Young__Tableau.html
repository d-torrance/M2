YoungTableau ++ YoungTableau -- direct sum of tableaux

  • Operator: ++
  • Usage:
    T1 ++ T2
  • Inputs:
    • T1, an instance of the type YoungTableau, a tableau.
    • T2, an instance of the type YoungTableau, a tableau.
  • Outputs:
    • S, an instance of the type YoungTableau, a direct sum of T1 and T2.

Description

The tableaux are combined into the disconnected components (not sharing an edge) of a single tableau.

i1 : T1 = youngTableau(new Partition from {5}, new Partition from {2})

             └───┴───┴───┘

o1 : YoungTableau
