conjugate(YoungTableau) -- conjugate a tableau

  • Function: conjugate
  • Usage:
    conjugate T
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
  • Outputs:
    • S, an instance of the type YoungTableau, the rows and columns have been switched.

Description

This method conjugates the tableau only if the shape has weakly decreasing parts, and no negative parts. Otherwise, it will raise an error.

i1 : T = youngTableau(new Partition from {6,6,5,3,1}, new Partition from {2,1,1}, toList(1..17))
