applyEntries -- apply a function to all entries in the tableau

  • Usage:
    applyEntries(T,f)
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
    • f, a function, acts on the entries of T.
  • Outputs:
    • T', an instance of the type YoungTableau, a tableau with the same shape as T, and entries n -> f n.

Description

i1 : T = youngTableau(new Partition from {6,3,2}, new Partition from {2}, toList(0..8))
