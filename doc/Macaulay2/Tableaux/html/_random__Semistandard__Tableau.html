randomSemistandardTableau -- get a random semistandard Young Tableau

  • Usage:
    randomSemistandardTableau(lam,mu,N)
  • Inputs:
    • lam, an instance of the type Partition, the outer shape, $\lambda$, of T.
    • mu, an instance of the type Partition, the inner shape, $\mu$, of T.
    • N, an integer, the maximum entry.
  • Outputs:
    • T, an instance of the type YoungTableau, a random semistandard Young tableau with entries in $\{1,\ldots,N\}$. If $N$ is not provided, then it is assumed to be the length of $\lambda$. If $\mu$ is not provided, then it is assumed to be $0$.

Description

Note that this does not select a tableau uniformly randomly.

i1 : lam = new Partition from {5,4,3,3,1}

o1 = Partition{5, 4, 3, 3, 1}

o1 : Partition
 
i2 : mu = new Partition from {3,1,1}

o2 = Partition{3, 1, 1}
