shift -- shift a tableau

  • Usage:
    shift T
    shift(T,n)
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
    • n, an integer, an additional amount to shift.
  • Outputs:
    • S, an instance of the type YoungTableau, each row i of T has been shifted by i + n to the right (where n=0 if not provided).
