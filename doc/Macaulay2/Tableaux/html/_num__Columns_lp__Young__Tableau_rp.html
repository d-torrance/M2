numColumns(YoungTableau) -- the number of columns in a tableau

  • Function: numColumns
  • Usage:
    numColumns T
  • Inputs:
    • T, an instance of the type YoungTableau, a tableau.
  • Outputs:
    • n, an integer, the number of columns in T.

Description

The number of rows is the same as largest part in its shape, minus the smallest part in the shape.

i1 : drawInnerShape true 

o1 = true
 
i2 : T = youngTableau(new Partition from {4,3,1}, new Partition from {1,1,1})

         ┌───┬───┬───┐
o2 =   ■ │   │   │   │
         ├───┼───┼───┘
       ■ │   │   │    
         └───┴───┘    
       ■              
                      

o2 : YoungTableau
 
i3 : numColumns T

o3 = 3

Note that, if a shape contains negative parts, then columns may have negative indices.

i4 : T' = youngTableau(new Partition from {4,3,1}, new Partition from {-1,1,1})

     ┌───║───┬───┬───┬───┐
o4 = │   ║   │   │   │   │
     └───║───┼───┼───┼───┘
         ║ ■ │   │   │    
         ║   └───┴───┘    
         ║ ■              
         ║                

o4 : YoungTableau
 
i5 : numColumns T'

o5 = 5
