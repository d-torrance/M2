horizontalNet -- multiple nets concatenated horizontally

  • Usage:
    horizontalNet L
  • Inputs:
    • L, a list, a list or sequence.
  • Outputs:
    • n, a net, a net of objects in L, stacked horizontally and justified at the top.

Description

If L is a list of objects $A_1,A_2,\ldots,A_n$, then this concatenates their nets horizontally.

i1 : T1 = youngTableau(new Partition from {6,6,5,3,1}, new Partition from {2,1,1})
