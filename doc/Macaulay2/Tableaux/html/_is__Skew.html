isSkew -- checks if a Young tableau is skew

  • Usage:
    isSkew T
  • Inputs:
    • T, an instance of the type YoungTableau, a Young tableau of shape $\lambda/\mu$.
  • Outputs:
    • b, a Boolean value, returns true if the inner shape $\mu$ is not $0$, and true if $\mu=0$.

Description

i1 : T = youngTableau(new Partition from {5,3,2}, new Partition from {3,1}, {1,3,2,2,2,3})

                 ┌───┬───┐
o1 =             │ 1 │ 3 │
         ┌───┬───┼───┴───┘
         │ 2 │ 2 │        
     ┌───┼───┼───┘        
     │ 2 │ 3 │            
     └───┴───┘            

o1 : YoungTableau
 
i2 : isSkew T

o2 = true

Ways to use isSkew:

  • isSkew(YoungTableau)

For the programmer

The object isSkew is a method function.
