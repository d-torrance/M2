Tor -- computes Tor of two Cp-Mackey functors

  • Usage:
    Tor_i(M,N)
  • Inputs:
    • i, an integer,
    • M, a C_p Mackey Functor,
    • N, a C_p Mackey Functor,
  • Outputs:
    • a C_p Mackey Functor, the $i$th Tor Cp-Mackey Functor of $M$ and $N$

Description

Given two Cp-Mackey functors $M$ and $N$, we can compute their $i$th Tor.

i1 : RU = makeComplexRepresentationMackeyFunctor(3);
 
i2 : prune Tor_3(RU,RU)

o2 =                   Res : 0
     cokernel | 3 |  -----------> 0  -┐ Conj : 0
                    <-----------     <┘
                       Tr : 0

o2 : CpMackeyFunctor
