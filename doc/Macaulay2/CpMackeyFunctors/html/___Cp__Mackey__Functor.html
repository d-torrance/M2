CpMackeyFunctor -- The type of Cp Mackey functors

Description

This documents the type of $C_p$-Mackey functors. A $C_p$-Mackey functor is encoded as a hash table with keys through which we can pull various parts of the data.

The keys available (internally) in the hash table are as follows, together with their external get methods:

  • .PrimeOrder yields the order of the cyclic group over which we're working. See PrimeOrder
  • .Underlying encodes the module $M(C_p/e)$. See Underlying
  • .Fixed encodes the module $M(C_p/C_p)$. See Fixed
  • .Res encodes the restriction homomorphism $M(C_p/C_p) \to M(C_p/e)$. See Res
  • .Trans encodes the transfer homomorphism $M(C_p/e) \to M(C_p/C_p)$. See Trans
  • .Conj encodes the conjugation homomorphism $M(C_p/e) \to M(C_p/e)$. See Conj

Constructing new Mackey functors: See constructing examples of Mackey functors.

Operations with Mackey functor types: One of the first operations to know about is pruning a $C_p$-Mackey functor. This basically takes the data of a Mackey functor and attempts to simplify it and make it more reader-friendly. Pruning is the only unary operation on $C_p$-Mackey functors that we consider. The unary (Boolean-valued) operations are

  • isTrivialMackeyFunctor checks if a Mackey functor is trivial
  • isCohomological checks if a Mackey functor is cohomological

For binary (and $n$-ary) operations, there are a few, including:

  • equality of two Mackey functors, via M==N
  • the box product of two Mackey functors, via M**N
  • the direct sum of two Mackey functors, as M++N
  • the internal hom of two Mackey functors

Well-definedness: The global variable assertLevel controls whether the methods that construct Mackey functors will check whether the input data is well-defined. If assertLevel is set to 0 or lower, then no checks are made, and the methods will return a Mackey functor (which may be malformed) regardless of the input data. If assertLevel is set to 1 or higher, then the methods will check whether the input data yields a well-defined Mackey functor, and if not, they will throw an error.
