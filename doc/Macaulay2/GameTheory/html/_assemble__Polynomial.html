assemblePolynomial -- compute incentive constraint polynomial for deviation

  • Usage:
    assemblePolynomial(PR, Xi, {i,k,l})
  • Inputs:
    • PR, a ring, Polynomial ring of strategy probabilities.
    • Xi, an instance of the type Tensor, Tensor of strategy probabilities.
    • {i, k, l}, a list, A triple where: - $i$ is the player index, - $k$ is the current strategy, - $l$ is the deviating strategy.
  • Outputs:
    • a ring element, A polynomial representing the incentive constraint for player $i$ deviating from $k$ to $l$.

Description

This function computes a linear inequality encoding the condition for a correlated equilibrium: the expected utility from playing $k$ should be no less than from playing $l$.
