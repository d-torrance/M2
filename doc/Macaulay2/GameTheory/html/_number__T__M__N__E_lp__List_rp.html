numberTMNE(List) -- compute the maximum number of totally mixed Nash equilibria for a generic game

  • Function: numberTMNE
  • Usage:
    numberTMNE d
  • Inputs:
    • d, a list, a list of integers representing the format of the game
  • Outputs:
    • an integer, an integer value, the degree of the top Chern class of a vector bundle on a product of projective spaces, representing the maximum number of totally mixed Nash equilibria of a generic game of format $\mathbf{d}$.

Description

For an $n$-player game where the $i$-th player has $d_i$ pure strategies, the maximum number of isolated totally mixed Nash equilibria is given by the degree $c(\mathbf{d})$ of the top Chern class of the following vector bundle:

\[E := \bigoplus_{i=0}^{n-1} \mathcal{O}_{\mathbb{P}^{\mathbf{d}}}(\mathbf{1}_i)^{\oplus (d_i - 1)},\]

where $\mathbb{P}^{\mathbf{d}}=\prod_{i=0}^{n-1}\mathbb{P}^{d_i-1}$ and $\mathbf{1}_i=(1,\ldots,1,0,1,\ldots,1)$, where the entry $0$ is in the $i$-th component. In particular, this function computes the integer $c(\mathbf{d})$ as the coefficient of the monomial $\prod_{i=0}^{n-1} h_i^{d_i-1}$ in $\prod_{i=0}^{n-1} \hat{h}_i^{d_i-1}$ with $\hat{h}_i\coloneqq \sum_{j\neq i}h_j$, where $h_i$ denotes the pullback of the hyperplane class on the $i$-th factor $\mathbb{P}^{d_i-1}$ of $\mathbb{P}^{\mathbf{d}}$ via the projection map.

i1 : d = {2,2,2};
 
i2 : nTMNE = numberTMNE d

o2 = 2

Alternatively, if you have a tensor $T$, you can compute its maximum number as follows:
