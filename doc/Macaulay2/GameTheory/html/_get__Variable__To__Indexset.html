getVariableToIndexset -- retrieve a polynomial ring variable by its index tuple

  • Usage:
    getVariableToIndexset(R, indexTuple)
  • Inputs:
    • R, a ring, A polynomial ring whose variables are indexed by tuples.
    • indexTuple, a list, A list representing the index of the variable.
  • Outputs:
    • a ring element, The variable from the ring corresponding to the given index.

Description

Given a ring $R = \mathbb{Q}[p_{\{i,j\}}]$, this method retrieves $p_{\{i,j\}}$ when passed the index $\{i,j\}$.

i1 : R = QQ[p_{0,0}, p_{0,1}, p_{1,0}, p_{1,1}]

o1 = R

o1 : PolynomialRing
 
i2 : getVariableToIndexset(R, {1,0})

o2 = p
      {1, 0}

o2 : R
