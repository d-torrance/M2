isARandomFiberSmooth -- Test whether a random fiber is smooth

  • Usage:
    b=isARandomFiberSmooth(I,J1,family)
  • Inputs:
    • I, an ideal, semigroup ideal
    • J1, an ideal, flatness relations among the parameters
    • family, a matrix, a flat family
  • Optional inputs:
    • BaseField
    • Verbose => ..., default value false
  • Outputs:
    • b, a Boolean value, true if a random fiber is smooth, false otherwise

Description

We check whether a random fiber over a random closed point of each component of J1 is smooth. If we find a smooth fiber we return true, else we return false.
