coneRays -- All the rays of the (homogeneous) Kunz cone

  • Usage:
    M = coneRays m
  • Inputs:
    • m, an integer, multiplicity
  • Outputs:
    • M, a matrix, of ZZ -- columns are vectors on the rays of the cone

Description

Uses the Fourier-Motzkin algorithm to compute the rays from the list of supporting hyperplanes, which is given by coneEquations. The number of rays grows rather quickly with m; the actual number is unknown. Use facetRays to determine the rays bounding the face on which a given semigroup lies.

i1 : coneRays 3

o1 = | 1 2 |
     | 2 1 |

              2       2
o1 : Matrix ZZ  <-- ZZ
 
i2 : coneRays 4

o2 = | 1 1 3 1 |
     | 2 0 2 2 |
     | 3 1 1 1 |

              3       4
o2 : Matrix ZZ  <-- ZZ
 
i3 : facetRays {4,5,6}

o3 = | 1 1 |
     | 2 0 |
     | 3 1 |

              3       2
o3 : Matrix ZZ  <-- ZZ

See also

  • coneEquations -- Find the equations of the Kunz cones
  • facetRays -- computes the rays spanning the face in which a semigroup lies

Ways to use coneRays:

  • coneRays(ZZ)

For the programmer

The object coneRays is a method function.
