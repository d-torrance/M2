scoreEquations(...,SaturateOptions=>...) -- use options from "saturate"

  • Usage:
    scoreEquations(R,U,SaturateOptions=>L)
  • Inputs:
    • L, a list, of options to set up saturation. Accepts any option from the function saturate (missing documentation)

Description

Default SaturateOptions in scoreEquations are the default options in saturate (missing documentation) . All optional input in saturate (missing documentation) is allowed.
