psiMaps -- list the maps psi(p): B_1(p) --> A_0(p-1) in a matrixFactorization

  • Usage:
    psmaps = psiMaps mf
  • Inputs:
    • mf, a list, output of a matrixFactorization computation
  • Outputs:
    • psmaps, a list, list matrices $d_p: B_1(p)\to A_0(p-1)$

Description

See the documentation for matrixFactorization for an example.
