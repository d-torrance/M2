equivariantHilbertSeries -- equivariant Hilbert series for a diagonal action

  • Usage:
    equivariantHilbertSeries D
  • Inputs:
    • D, an instance of the type DiagonalAction
  • Optional inputs:
    • Order => an integer, default value infinity, stopping degree of the equivariant Hilbert series
  • Outputs:
    • a divide expression, the equivariant Hilbert series

Description

This function is provided by the package InvariantRing.

For a torus acting on the vector space $V$ this function returns the equivariant Hilbert series of the coordinate ring $K[V]$ as a rational function of $\zeta_0, \ldots, \zeta_{r-1}, T$ where $r$ is the rank of the torus. The series in $T$ which is the coefficient of $\zeta_0^0\cdots \zeta_{r-1}^0$ gives the ordinary Hilbert series of the torus-invariant subring. The option Order => N can be used to compute the series up to the $T$ -degree N-1.

Here is an example of a rank 2 torus acting on a polynomial ring in 3 variables, whose invariant ring is generated by the single element $x_1 x_2 x_3$ .

The constant part in the $\zeta$ variables is the Hilbert series of the invariant ring (up to degree 7).
