isIsomorphic(LeafTree,LeafTree) -- check isomorphism of two tree

  • Function: isIsomorphic
  • Usage:
    isIsomorphic(T,U)
  • Inputs:
    • T, an instance of the type LeafTree,
    • U, an instance of the type LeafTree,
  • Optional inputs:
    • Homogeneous => ..., default value true,
    • Strategy => ..., default value null,
    • Strict => ..., default value false,
    • Tries => ..., default value null,
    • Verbose => ..., default value false,
  • Outputs:
    • a Boolean value, if U and T are isomorphic

Description

This function checks if two objects of class LeafTree are isomorphic to each other as unlabeled graphs. This is in contrast to equality of two objects of class LeafTree, which also checks whether they have the same leaf labeling.

i1 : T = leafTree(4,{{0,1}});
 
i2 : U = leafTree(4,{{1,2}});
 
i3 : isIsomorphic(T,U)

o3 = true
