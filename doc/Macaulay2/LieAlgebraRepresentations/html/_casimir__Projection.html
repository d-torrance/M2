casimirProjection -- projection operator to a specified eigenspace of the Casimir operator

  • Usage:
    casimirProjection(rho,z)
  • Inputs:
    • rho, an instance of the type LieAlgebraRepresentation,
    • z, a rational number,
  • Outputs:
    • M, a matrix,

Description

Let $\rho$ be a LieAlgebraRepresentation, and recall the definition of the Casimir operator from casimirOperator.

This function returns the projection matrix to the eigenspace of the Casimir operator for the input eigenvalue z. This matrix is computed as the product of factors $\operatorname{Cas}-x I$ over all eigenvalues $x \neq z$.
