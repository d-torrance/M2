branchingRule -- A Lie algebra module viewed as a module over a Lie subalgebra

  • Usage:
    branchingRule(V,S)
  • Inputs:
    • V, an instance of the type LieAlgebraModule,
    • S, a string, a list, a matrix, or an instance of the type LieAlgebra,
  • Outputs:
    • V', an instance of the type LieAlgebraModule,

Description

S must be a subset of vertices of the Dynkin diagram of the Lie algebra of V, or a matrix, or a string, see subLieAlgebra; or a sub-Lie algebra. Returns V viewed as a module over the Lie subalgebra determined by S.

i1 : g=simpleLieAlgebra("D",4);
 
i2 : M=adjointModule g;
 
i3 : branchingRule(M,{1,2,3})
