lieAlgebraBasis -- computes an enhanced basis for a simple Lie algebra

  • Usage:
    lieAlgebraBasis("A",2)
  • Inputs:
    • t, a string,
    • m, an integer,
    • Method, a string,
    • Check, a Boolean value,
  • Optional inputs:
    • Check
    • Method
  • Outputs:
    • LAB, an instance of the type LieAlgebraBasis,

Description

See LieAlgebraBasis for more details and references.

The optional argument "Method" may be set to "Lusztig" for the Lusztig canonical basis, or "FH" for the basis described in Fulton-Harris, Representation Theory: A First Course. The default is "FH" for types A, B, C, D, and G.

The optional argument "Check" (default: true) runs a suite of tests on the basis constructed. See the unexported function "checkLieAlgebraBasis" in the package code for more details.

The user may either input the type and rank, or the simple Lie algebra.
