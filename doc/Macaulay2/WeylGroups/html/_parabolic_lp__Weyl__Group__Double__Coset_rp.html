parabolic(WeylGroupDoubleCoset) -- the parabolic associated to a double coset

  • Function: parabolic
  • Usage:
    parabolic(d)
  • Inputs:
    • d, an instance of the type WeylGroupDoubleCoset,
  • Outputs:
    • an instance of the type Parabolic, a standard parabolic subgroup corresponding to the coset d as in Carter, Finite Groups of Lie Type, p. 65, thm 2.7.4.
