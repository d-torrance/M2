DynkinType == DynkinType -- the equality of Dynkin Types

  • Operator: ==
  • Usage:
    T1 == T2
  • Inputs:
    • T1, an instance of the type DynkinType,
    • T2, an instance of the type DynkinType,
  • Outputs:
    • a Boolean value, true if T1 is isomorphic to T2 and false if not
