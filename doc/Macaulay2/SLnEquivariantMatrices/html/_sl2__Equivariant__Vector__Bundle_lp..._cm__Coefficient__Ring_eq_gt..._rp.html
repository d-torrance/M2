sl2EquivariantVectorBundle(...,CoefficientRing=>...) -- name for optional argument

  • Usage:
    W = sl2EquivariantVectorBundle(m,d,CoefficientRing=>C)

Description

This is an option to tell sl2EquivariantVectorBundle to define the vector bundle over a projective space whose coordinate ring has coefficients in the ring C.
