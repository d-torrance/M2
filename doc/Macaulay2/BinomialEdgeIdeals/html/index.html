BinomialEdgeIdeals -- binomial edge ideals

Description

BinomialEdgeIdeals is a package for computations with binomial edge ideals

Literature
  • [HHHTR2010] Binomial edge ideals and conditional independence statements (J. Herzog, T. Hibi, F. Hreinsdottir, T. Kahle, J. Rauh, 2010).
  • [HMMW2014] On the ideal of orthogonal representations of a graph in R^2 (J. Herzog, A. Macchia, S. Madani, V. Welker, 2014).
  • [KSW2015] Parity binomial edge ideals (T. Kahle, C. Sarmiento, T. Windisch, 2015)

Author

  • Tobias Windisch <windisch@ovgu.de>
