getWeights -- retrieve the (Lie theoretic) weight of a monomial

Description

Suppose an algebraic torus acts on a polynomial ring compatibly with the grading. If each variable is a weight vector, then each monomial is also a weight vector. Use this method to obtain the weight of a monomial.

See also

  • setWeights -- attach (Lie theoretic) weights to the variables of a ring

Ways to use getWeights:

  • getWeights(RingElement) -- retrieve the (Lie theoretic) weight of a monomial

For the programmer

The object getWeights is a method function.
