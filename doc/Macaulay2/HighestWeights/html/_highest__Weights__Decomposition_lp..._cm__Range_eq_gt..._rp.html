highestWeightsDecomposition(...,Range=>...) -- decompose only part of a complex

Description

Restrict the range of a complex to be decomposed into highest weight modules. Set this argument to {lo,hi} to restrict to homological dimensions from lo to hi.

Caveat

This argument is not used when decomposing rings, ideals or modules but only with complexes.

See also
