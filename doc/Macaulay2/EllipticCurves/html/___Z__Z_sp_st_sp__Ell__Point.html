ZZ * EllPoint -- a binary operator, usually used for multiplication

  • Operator: *
  • Usage:
    n*P
  • Inputs:
    • n, an integer
    • P, an instance of the type EllPoint
  • Outputs:
    • an instance of the type EllPoint

Description

Computes the multiple of a point using the double and add algorithm.

i1 : E=ellCurve(3,8,GF(13))

o1 = Elliptic Curve defined by Y^2 = X^3 + 3 X + (-5)( over(GF 13 .))

o1 : EllipticCurve
 
i2 : P=ellPoint({1,5,1},E)

o2 = Point ({1, 5, 1}( on the (Elliptic Curve defined by Y^2 = X^3 + 3 X + (-5)( over(GF 13 .)))))

o2 : EllPoint
 
i3 : 4*P

o3 = Point ({-1, 2, 1}( on the (Elliptic Curve defined by Y^2 = X^3 + 3 X + (-5)( over(GF 13 .)))))

o3 : EllPoint
