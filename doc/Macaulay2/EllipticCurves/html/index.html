EllipticCurves -- elliptic curves and a brute-force method for point counting

Description

This package defines classes for elliptic curves, points on elliptic curves, and related methods.

Authors

  • Alessandro Oneto <oneto@math.su.se>
  • Stefano Marseglia <stefanom@math.su.se>

Version

This documentation describes version 0.1 of EllipticCurves, released May 3, 2014.
