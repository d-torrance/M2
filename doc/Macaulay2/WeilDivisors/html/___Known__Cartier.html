KnownCartier -- an option used to specify to certain functions that we know that the divisor is Cartier

Description

If true, then some functions will not check whether or not the divisor is Cartier, they will assume it is and proceed.

Functions with optional argument named KnownCartier:

  • mapToProjectiveSpace(...,KnownCartier=>...) -- see mapToProjectiveSpace -- compute the map to projective space associated with the global sections of a Cartier divisor

For the programmer

The object KnownCartier is a symbol.
