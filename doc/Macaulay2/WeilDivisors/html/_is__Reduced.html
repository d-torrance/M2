isReduced -- whether a divisor is reduced

  • Usage:
    isReduced( D1 )
  • Inputs:
    • D1, an instance of the type WeilDivisor,
  • Outputs:
    • a Boolean value,

Description

This function returns true if the divisor is reduced (all coefficients equal to 1), otherwise it returns false.

i1 : R = QQ[x, y, z];
 
i2 : D1 = divisor(x^2 * y^3 * z)

o2 = 2*Div(x) + 3*Div(y) + Div(z)

o2 : WeilDivisor on R
 
i3 : D2 = divisor(x * y * z)

o3 = Div(x) + Div(y) + Div(z)

o3 : WeilDivisor on R
 
i4 : isReduced( D1 )

o4 = false
 
i5 : isReduced( D2 )

o5 = true

Ways to use isReduced:

  • isReduced(BasicDivisor)

For the programmer

The object isReduced is a method function.
