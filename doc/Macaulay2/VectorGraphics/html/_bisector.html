bisector -- Angle bisector of two lines

  • Usage:
    bisector ( p, p1, p2 )

Description

Returns the location of the intersection of the angle bisectors of (p,p1) and (p,p2) with the line (p1,p2).

i1 : (a,b,c)=apply(([-1,-1],[2,0],[0,2]),coord -> gNode(coord,Circle{Radius=>0.1,"fill"=>"red","stroke"=>"black"},Draggable=>true));
 
i2 : p=bisector(a,b,c); q=bisector(b,c,a); r=bisector(c,a,b); o=crossing(p,a,q,b);
