AutoSubduceOnPartialCompletion -- Subduct subalgebra generators at the end of the sagbi algorithm

Description

During the main loop in sagbi, if no new subalgebra generators are added and the AutoSubduceOnPartialCompletion flag is true then all current subalgebra generators are subducted against each other. The autosubduction can be a significant time investment, but it can speed up subsequent computations by removing redundant generators.
