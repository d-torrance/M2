numgens(SAGBIBasis) -- The number of generators of a SAGBIBasis

  • Function: numgens
  • Usage:
    result = numgens SB
  • Inputs:
    • SB, a SAGBIBasis,
  • Outputs:
    • result, an integer, the number of subalgebra generators of SB

Description

Returns the number of subalgebra generators of a SAGBIBasis.

i1 : R = QQ[x,y,z];
 
i2 : S = subring({x^2, y^2, z^2, x^2+y^2});
 
i3 : SB = sagbi S;
 
i4 : numgens SB

o4 = 3
