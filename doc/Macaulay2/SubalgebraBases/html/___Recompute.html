Recompute -- Flag for restarting a sagbi or isSAGBI computation

Description

If the flag is set to true, then the subalgebra bases computation starts from scratch. This process constructs a SAGBIBasis and uses the computation options from the previous computation.

If the flag is set to false (the typical case), then previous computations are used to speed up subsequent calculations.
