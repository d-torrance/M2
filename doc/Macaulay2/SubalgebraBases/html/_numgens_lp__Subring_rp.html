numgens(Subring) -- The number of generators of a subring

  • Function: numgens
  • Usage:
    result = numgens S
  • Inputs:
    • S, a subring,
  • Outputs:
    • result, an integer, the number of generators of S

Description

Returns the number of generators of a Subring.

i1 : R = QQ[x,y,z];
 
i2 : S = subring({x^2, y^2, z^2, x^2+y^2});
 
i3 : numgens S

o3 = 4
