SCSCP -- SCSCP (Symbolic Computation Software Composability Protocol) support

Description

This package provides an SCSCP (Symbolic Computation Software Composability Protocol) server and client.

Author

  • Dan Roozemond <dan.roozemond@gmail.com>

Version

This documentation describes version 0.2.1 of SCSCP, released March 16, 2011.
