numerator(FirstOrderDeformation) -- The numerator of a deformation as a vector.

  • Function: numerator
  • Usage:
    numerator(f)
  • Inputs:
    • f, a first order deformation,
  • Outputs:
    • a vector,

Description

Returns the numerator of a deformation as a vector.

i1 : R=QQ[x_0..x_4];
 
i2 : addCokerGrading(R);

              5       4

i3 : I=ideal(x_0*x_1,x_1*x_2,x_2*x_3,x_3*x_4,x_4*x_0)

             0 1   1 2   2 3   3 4   0 4

      x
       3

     x x
      0 1

       5
