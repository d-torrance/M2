simplexDim -- The dimension of a face inside the vertex simplex.

  • Usage:
    simplexDim(F)
  • Inputs:
    • F, a face,
  • Outputs:
    • an integer, bigger or equal to -1

Description

The dimension of a face inside the vertex simplex, i.e., the number of vert F minus 1.

i1 : R=QQ[x_0..x_4];
 
i2 : C=simplex R;
 
i3 : F=C.fc_2_0

o3 = x x x
      0 1 2

o3 : face with 3 vertices
 
i4 : simplexDim F

o4 = 2
