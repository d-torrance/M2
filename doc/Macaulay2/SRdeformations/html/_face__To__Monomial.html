faceToMonomial -- The monomial of a face.

  • Usage:
    faceToMonomial(F)
  • Inputs:
    • F, a face,
    • R, a polynomial ring,
  • Outputs:
    • an embedded complex,

Description

Returns the product of the vertices of a face.

i1 : R=QQ[x_0..x_4];
 
i2 : C=simplex R

o2 = 4: x x x x x  
         0 1 2 3 4

o2 : complex of dim 4 embedded in dim 4 (printing facets)
     equidimensional, simplicial, F-vector {1, 5, 10, 10, 5, 1}, Euler = 0
 
i3 : F=C.fc_2_0

o3 = x x x
      0 1 2

o3 : face with 3 vertices
 
i4 : vert F

o4 = {x , x , x }
       0   1   2

o4 : List
 
i5 : faceToMonomial F

o5 = x x x
      0 1 2

o5 : R
