pommaretMultVar -- return table of multiplicative variables for given module elements as determined by Pommaret division

  • Usage:
    pommaretMultVar M
  • Inputs:
    • M, a matrix or a list
  • Outputs:
    • list of sets of variables of the polynomial ring; the i-th set consists of the multiplicative variables for the i-th generator in J

Description

i1 : R = QQ[x1,x2,x3];
 
i2 : M = matrix {{ x1*x2*x3, x2^2*x3, x1*x2*x3^2 }};

             1      3
o2 : Matrix R  <-- R
 
i3 : pommaretMultVar M

o3 = {set {x3}, set {x3}, set {x3}}

o3 : List
