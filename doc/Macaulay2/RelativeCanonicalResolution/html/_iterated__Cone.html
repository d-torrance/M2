iteratedCone -- Computes a (possibly non-minimal) resolution of C in P^{g-1} starting from the relative canonical resolution of C in P(E)

  • Usage:
    resC=iteratedCone(resX,e)
  • Inputs:
    • resX, a complex, the relative canonical resolution
    • e, a list, the type of the scroll $P(E)$
  • Outputs:
    • resC, a complex, the resolution of C obtained by an iterated mapping cone

Description

Given the relative canonical resolution of C on a normalized scroll $P(E)$, this function computes a (possibly non-minimal) free resolution of C in $P^{g-1}$ by an iterated mapping cone construction. For gonality k=3,4 the iterated mapping cone is always minimal. In these cases "iteratedCone" is much faster (for $g >9$) than computing the resolution via the freeResolution command.
