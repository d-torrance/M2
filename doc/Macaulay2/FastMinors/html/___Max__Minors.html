MaxMinors -- an option to control depth of search

Description

This option controls how many minors various functions consider. Increasing it will make certain functions search longer, but may make them give more useful outputs. The functions projDim and regularInCodimension can also take in more complicated inputs. See their documentation for details.

See also

  • regularInCodimension -- attempts to show that the ring is regular in codimension n
  • projDim -- finds an upper bound for the projective dimension of a module
  • isRankAtLeast -- determines if the matrix has rank at least a number
  • getSubmatrixOfRank -- tries to find a submatrix of the given rank

Functions with optional argument named MaxMinors:

  • getSubmatrixOfRank(...,MaxMinors=>...)
  • isRankAtLeast(...,MaxMinors=>...)
  • projDim(...,MaxMinors=>...)
  • regularInCodimension(...,MaxMinors=>...)

For the programmer

The object MaxMinors is a symbol.
