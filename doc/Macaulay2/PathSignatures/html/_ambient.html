ambient -- exported from the NCALgebra package.

Ways to use ambient:

  • ambient(NCPolynomialRing)
  • ambient(GaloisField) -- corresponding quotient ring
  • ambient(Matrix) -- get the map between the ambient free modules
  • ambient(Module) -- ambient free module
  • ambient(NCQuotientRing) -- Ambient ring of an NCQuotientRing
  • ambient(NCRingMap) -- Extends an NCRingMap to the ambient ring of the source.
  • ambient(PolynomialRing) -- see ambient(Ring) -- ambient polynomial ring
  • ambient(QuotientRing) -- see ambient(Ring) -- ambient polynomial ring
  • ambient(Ring) -- ambient polynomial ring

For the programmer

The object ambient is a method function.
