wordString -- a string representing a word in wordFormat

  • Usage:
    w // wordString
  • Inputs:
    • w, an instance of the type NCRingElement,
  • Outputs:
    • s, a string, A string representing the word 2 in word format;

Description

Returns a string representing the word as described in wordFormat.

i1 : R = wordAlgebra(3);
 
i2 : w = [1,2,3]_R + 2 * [3,2,1]_R; w // wordFormat

o3 = 2 [3, 2, 1] + [1, 2, 3]
 
i4 : w // wordString

o4 = 2 [3, 2, 1] + [1, 2, 3]
