pwLinPath -- constructor of a piecewise linear path from a matrix

  • Usage:
    pwLinPath(pwlMatrix)
  • Inputs:
    • pwlMatrix, a matrix, A matrix containing on its columns the articulation points (or increments) of the path;
  • Outputs:
    • X, an instance of the type Path, A piecewise linear path of dimension the number of rows of the input and with the same number of pieces as the columns of the input;

Description

Creates a piecewise linear Path whose increments are the columns of the given matrix.

i1 : M = id_(QQ^3)

o1 = | 1 0 0 |
     | 0 1 0 |
     | 0 0 1 |

              3       3
o1 : Matrix QQ  <-- QQ
 
i2 : pwLinPath(M)

o2 = Path in 3-dimensional space with 3 polynomial segments:

     {{t, 0, 0}, {0, t, 0}, {0, 0, t}}

o2 : Path
