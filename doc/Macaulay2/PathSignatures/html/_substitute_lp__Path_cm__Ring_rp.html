substitute(Path,Ring) -- changes the coefficient ring of a path

  • Function: substitute
  • Usage:
    Y = substitute(X,R)
  • Inputs:
    • X, an instance of the type Path,
    • R, a ring, an algebra over the coefficient ring of the polynomials defining X;
  • Outputs:
    • Y, an instance of the type Path, a path with the same pieces as X but whose coordinate functions are now polynomials with coefficients in R;

Description

Tries to substitute the coefficients of the polynomials defining the given path into the given ring, producing a new path.
