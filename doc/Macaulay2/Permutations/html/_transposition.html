transposition -- constructs a transposition

  • Usage:
    transposition i
  • Inputs:
    • i, an integer,
    • j, an integer,
  • Outputs:
    • a permutation,

Description

This method constructs the transposition $(i,i+1)$.

i1 : transposition 3

o1 = Permutation{1, 2, 4, 3}

o1 : Permutation

When two arguments are passed, this constructs the transposition $(i,j)$.

i2 : transposition(3,5)

o2 = Permutation{1, 2, 5, 4, 3}

o2 : Permutation

Ways to use transposition:

  • transposition(ZZ)
  • transposition(ZZ,ZZ)

For the programmer

The object transposition is a method function.
