symmetricGroupPoset -- constructs the poset of the symmetric group under a partial order

  • Usage:
    symmetricGroupPoset(n,f)
  • Inputs:
    • w, a permutation,
    • f, a function,
  • Outputs:
    • a Boolean value,

Description

Using the Posets package, we can construct the poset on the symmetric group $\mathfrak{S}_n$ under a partial order. See [BB05] for more details on Bruhat order.
