K3Surfaces -- construction of explicit examples of K3 surfaces

Description

This package is for constructing explicit examples of K3 surfaces.

References

  • M. H. and G. S., Explicit constructions of K3 surfaces and unirational Noether-Lefschetz divisors, available at arXiv:2110.15819 (2021).

Authors

  • Michael Hoff <hahn@math.uni-sb.de>
  • Giovanni Staglianò <giovanni.stagliano@unict.it>

This documentation describes version 1.1 of K3Surfaces, released August 13, 2022.
