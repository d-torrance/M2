K3(CubicFourfold) -- K3 surface associated to a cubic or GM fourfold

  • Function: K3
  • Usage:
    K3 X
  • Inputs:
    • X, a cubic fourfold, or a Gushel-Mukai fourfold
  • Optional inputs:
    • CoefficientRing => ..., default value ZZ/65521, make a lattice-polarized K3 surface
    • Singular => ..., default value null, make a lattice-polarized K3 surface
    • Strategy => ..., default value null, make a lattice-polarized K3 surface
    • Verbose => ..., default value false, make a lattice-polarized K3 surface
  • Outputs:
    • a K3 surface associated to $X$

Description

This is a shortcut for the function associatedK3surface.

i1 : X = specialFourfold "tau-quadric";

o1 : ProjectiveVariety, GM fourfold containing a surface of degree 2 and sectional genus 0
 
i2 : K3 X
warning: clearing value of symbol x to allow access to subscripted variables based on it
       : debug with expression   debug 9868   or with command line option   --debug 9868

o2 = surface in PP^6 cut out by 6 hypersurfaces of degree 2

o2 : ProjectiveVariety, K3 surface associated to X

See also

  • associatedK3surface -- K3 surface associated to a rational fourfold
  • K3(ZZ) -- make a general K3 surface
