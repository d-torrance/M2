getTemplateMatrix -- computes template matrix

  • Usage:
    M = getTemplateMatrix(a, B, J)
    M = getTemplateMatrix(sh, mp, J)
    getTemplateMatrix(E)
  • Inputs:
    • a, a ring element, the action polynomial defining a multiplication matrix
    • B, a matrix,
    • E, an instance of the type EliminationTemplate, the elimination template for this problem
    • J, an ideal,
    • mp, an instance of the type MonomialPartition (missing documentation) ,
    • sh, an instance of the type ShiftSet (missing documentation) ,
  • Optional inputs:
    • MonomialOrder (missing documentation) => a thing, default value null, the monomial order used on the ambient ring
    • Strategy (missing documentation) => a thing, default value null, the strategy used to compute H0
    • AdjustParams (missing documentation) => ..., default value true,
  • Outputs:
    • M, a matrix,

Description

This method computes the template matrix corresponding to the inputted elimination template.
