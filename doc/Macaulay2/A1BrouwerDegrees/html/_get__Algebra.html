getAlgebra -- returns the algebra over which a stable or unstable Grothendieck-Witt class is defined

  • Usage:
    getAlgebra(beta)
  • Inputs:
    • beta, a Grothendieck-Witt Class, a Grothendieck-Witt class
    • beta, an Unstable Grothendieck-Witt Class, an unstable Grothendieck-Witt class
  • Outputs:
    • a ring, the algebra over which the Grothendieck-Witt class is defined

Description

Given a GrothendieckWittClass or UnstableGrothendieckWittClass object beta, this method returns the algebra over which the Grothendieck-Witt class is defined. This algebra is either a field or a finite étale algebra over a field.

i1 : R = QQ[x]/(x^2 + 1);
 
i2 : beta = makeGWClass matrix(R, {{1,2},{2,x}});
 
i3 : getAlgebra beta

o3 = R

o3 : QuotientRing

  • UnstableGrothendieckWittClass -- a new type intended to capture an element of the unstable Grothendieck-Witt group of a field or finite étale algebras over a field
  • getBaseField -- returns the base field of a stable or unstable Grothendieck-Witt class
  • getMatrix -- returns the Gram matrix of a stable or unstable Grothendieck-Witt class
  • getScalar -- returns the non-zero scalar of an unstable Grothendieck-Witt class

Ways to use getAlgebra:

  • getAlgebra(GrothendieckWittClass)
  • getAlgebra(UnstableGrothendieckWittClass)
