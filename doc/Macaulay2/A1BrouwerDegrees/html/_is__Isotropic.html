isIsotropic -- determines whether a Grothendieck-Witt class is isotropic

  • Usage:
    isIsotropic beta
  • Inputs:
    • beta, a Grothendieck-Witt Class, denoted by $\beta\in\text{GW}(k)$, where $k$ is $\mathbb{C}$, $\mathbb{R}$, $\mathbb{Q}$, or a finite field of characteristic not 2
  • Outputs:
    • a Boolean value, whether $\beta$ is isotropic

Description

This is the negation of the boolean-valued isAnisotropic. See documentation there.

See also

  • isAnisotropic -- determines whether a Grothendieck-Witt class is anisotropic
  • getWittIndex -- returns the Witt index of a symmetric bilinear form
  • getAnisotropicDimension -- returns the anisotropic dimension of a symmetric bilinear form

Ways to use isIsotropic:

  • isIsotropic(GrothendieckWittClass)
  • isIsotropic(Matrix)

For the programmer

The object isIsotropic is a method function.
