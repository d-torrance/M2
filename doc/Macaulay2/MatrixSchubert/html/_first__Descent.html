firstDescent -- finds the location of the first descent of a permutation

  • Usage:
    firstDescent w
  • Inputs:
    • w, a list,

Description

Given a non-identity permutation in 1-line notation, finds the location of its first descent, i.e., the least $i$ so that $w_{i+1}<w_i$.

i1 : w = {7,2,5,8,1,3,6,4}

o1 = {7, 2, 5, 8, 1, 3, 6, 4}

o1 : List
 
i2 : firstDescent w

o2 = 1
 
i3 : v = {1,6,9,2,4,7,3,5,8}

o3 = {1, 6, 9, 2, 4, 7, 3, 5, 8}

o3 : List
 
i4 : firstDescent v

o4 = 3

Ways to use firstDescent:

  • firstDescent(List)

For the programmer

The object firstDescent is a method function.
