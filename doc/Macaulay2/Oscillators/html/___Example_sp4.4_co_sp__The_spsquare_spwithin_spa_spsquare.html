Example 4.4: The square within a square -- example 4.4 in arXiv 2312.16069

The following is the one graph on 8 vertices with an exotic solution where the Jacobian has some off-diagonal extries negative.

i2 : printingPrecision = 3;

           7 => {2, 5}
