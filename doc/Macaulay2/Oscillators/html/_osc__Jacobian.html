oscJacobian -- create the Jacobian for the oscillator system associated to a graph

  • Usage:
    oscJacobian(G,R)
    oscJacobian(I)
    oscJacobian(G)
  • Inputs:
    • G, a graph, an undirected, connected graph $G$
    • S, a ring, created with oscRing
    • I, an ideal, an ideal, intended to be ideal created by oscSystem
  • Optional inputs:
    • Reduced => a Boolean value, default value false, if true, then the angles are reduced to the first angle being 0. That is, the number of oscillators will be one less than the number of vertices of $G$
  • Outputs:
    • a matrix, the $n \times n$ Jacobian matrix of the system, as a matrix of polynomials involving the cosines and sines of angles $\theta_1, \ldots, \theta_{n-1}$, where we set $\theta_0 = 0$ if $\texttt{Reduced => true}$

Description

The matrix is a symmetric $n \times n$ matrix (with determinant zero).
