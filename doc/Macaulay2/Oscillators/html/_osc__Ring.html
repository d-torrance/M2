oscRing -- create a polynomial ring for a given graph or number of oscillators

  • Usage:
    S = oscRing G
    S = oscRing n
  • Inputs:
    • n, an integer, The number of oscillators
    • G, a graph, The number of oscillators is the number of vertices in the Graph
  • Optional inputs:
    • CoefficientRing => a ring, default value QQ, the coefficient ring to use, for numerical work, CC is a good choice
    • Symbols => a sequence, default value (x,y), a sequence of two symbols. The first refers to the cosine of the given angles and the second refers to the sine of the given angles
    • Reduced => a Boolean value, default value false, if true, then the angles are reduced to the first angle being 0. That is, the number of oscillators will be one less than the number of vertices of $G$
  • Outputs:
    • a ring,

Description

This function returns a polynomial ring in $2n$ variables representing the cosine and the sine of $n$ angles. Inputting a number assumes that the vertices are labeled $0, \ldots, n$.

i1 : oscRing(3, CoefficientRing => CC)

o1 = CC  [x ..x , y ..y ]
       53  0   2   0   2

o1 : PolynomialRing
 
i2 : oscRing(3, CoefficientRing => CC, Symbols=>{c, s})

o2 = CC  [c ..c , s ..s ]
       53  0   2   0   2

o2 : PolynomialRing

If one gives a graph with Reduced => true, then the number of angles considered is one less than the number of vertices of the graph.

i3 : G = graph({0,1,2,3}, {{0,1},{1,2},{2,3},{0,3}})

o3 = Graph{0 => {1, 3}}
           1 => {0, 2}
           2 => {1, 3}
           3 => {0, 2}

o3 : Graph
 
i4 : oscRing G

o4 = QQ[x ..x , y ..y ]
         0   3   0   3

o4 : PolynomialRing
 
i5 : oscRing(G, CoefficientRing => CC, Reduced => true)

o5 = CC  [x ..x , y ..y ]
       53  1   3   1   3

o5 : PolynomialRing
