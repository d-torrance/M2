gradedModuleMap -- make a map of graded modules

  • Usage:
    gradedModuleMap v
  • Inputs:
    • v, a list, a matrix, or a list or sequence of matrices
  • Outputs:
    • the graded module map with the i-th element of v installed as its i-th component

Description

i1 : gradedModuleMap(random(ZZ^3,ZZ^4),random(ZZ^2,ZZ^2))

          3                    4
o1 = 0: ZZ  <--| 8 7 3 8 |-- ZZ  :0
               | 1 8 7 5 |
               | 3 3 8 7 |

          2                2
     1: ZZ  <--| 8 2 |-- ZZ  :1
               | 5 3 |

o1 : GradedModuleMap

Ways to use gradedModuleMap:

  • gradedModuleMap(List)
  • gradedModuleMap(Matrix)
  • gradedModuleMap(Sequence)

For the programmer

The object gradedModuleMap is a method function with a single argument.
