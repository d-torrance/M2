resolution(...,HardDegreeLimit=>...)

Description

HardDegreeLimit -- keyword for an optional argument used with resolution.

The default value is {}.

Information above the specified degree is discarded.

Functions with optional argument named HardDegreeLimit:

  • gb(...,HardDegreeLimit=>...) -- see gb -- compute a Gröbner basis
  • resolution(...,HardDegreeLimit=>...)
  • syz(...,HardDegreeLimit=>...) -- see syz(Matrix) -- compute the syzygy matrix

Further information

  • Default value: {}
  • Function: resolution -- projective resolution
  • Option key: HardDegreeLimit -- an optional argument
