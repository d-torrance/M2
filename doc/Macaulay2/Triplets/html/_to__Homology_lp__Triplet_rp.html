toHomology(Triplet) -- from degree triplet to homology triplet

  • Function: toHomology
  • Usage:
    toHomology T
  • Inputs:
    • T, an instance of the type Triplet, a degree triplet {A,B,C}
  • Outputs:
    • a homology triplet {A, conj(B,n), C}, an instance of the type Triplet

Description

Takes a degree triplet and returns the corresponding homology triplet. 
i1 : T = triplet({1,2,3}, {0,2}, {0,2,3})

o1 = {{1, 2, 3}, {0, 2}, {0, 2, 3}}

o1 : Triplet
 
i2 : toHomology(T)

o2 = {{1, 2, 3}, {1, 3}, {0, 2, 3}}

o2 : Triplet
