triplet(List,List,List) -- make a triplet

  • Function: triplet
  • Usage:
    triplet(A,B,C)
  • Inputs:
    • A, a list, an increasing sequence of integers
    • B, a list, an increasing sequence of integers
    • C, a list, an increasing sequence of integers
  • Outputs:
    • an instance of the type Triplet, the triplet of degree sequences

Description

i1 : T1 = triplet({1,2,3}, {0,2}, {0,2,3})

o1 = {{1, 2, 3}, {0, 2}, {0, 2, 3}}

o1 : Triplet
 
i2 : T2 = triplet({0,3,4}, {0,2,3,4,5}, {1,3,4,5})

o2 = {{0, 3, 4}, {0, 2, 3, 4, 5}, {1, 3, 4, 5}}

o2 : Triplet
 
i3 : T3 = triplet({1,3,4}, {0,2,3}, {0,2,3,4})

o3 = {{1, 3, 4}, {0, 2, 3}, {0, 2, 3, 4}}

o3 : Triplet
