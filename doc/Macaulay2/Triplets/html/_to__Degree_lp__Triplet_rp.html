toDegree(Triplet) -- from homology triplet to degree triplet

  • Function: toDegree
  • Usage:
    toDegree T
  • Inputs:
    • T, an instance of the type Triplet, a homology triplet {B,H,C}
  • Outputs:
    • a degree triplet {B, conj(H,n),C}., an instance of the type Triplet

Description

Takes a homology triplet and returns the corresponding degree triplet. 
i1 : T = triplet({1,2,3}, {1,3}, {0,2,3})

o1 = {{1, 2, 3}, {1, 3}, {0, 2, 3}}

o1 : Triplet
 
i2 : toDegree(T)

o2 = {{1, 2, 3}, {0, 2}, {0, 2, 3}}

o2 : Triplet
