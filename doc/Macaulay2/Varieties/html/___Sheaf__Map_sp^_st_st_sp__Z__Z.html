SheafMap ^** ZZ -- repeatedly tensors a map

  • Operator: ^**
  • Usage:
    f ^** n
  • Inputs:
    • f, a morphism of sheaves, a sheaf map
    • n, an integer, a non-negative integer
  • Outputs:
    • a morphism of sheaves, the sheaf map f tensor n times

Description

This will create a sheaf map g which is the tensor of f with itself.
