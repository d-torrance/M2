sheaf(Variety) -- make a coherent sheaf

  • Function: sheaf
  • Usage:
    sheaf X
  • Inputs:
    • X, a variety
  • Outputs:
    • a sheaf of rings, the structure sheaf of rings on the variety X

Description

i1 : R = QQ[x,y,z]

o1 = R

o1 : PolynomialRing
 
i2 : X = Proj R

o2 = X

o2 : ProjectiveVariety
 
i3 : Y = Spec R

o3 = Y

o3 : AffineVariety
 
i4 : sheaf X

o4 = OO
       X

o4 : SheafOfRings
 
i5 : sheaf Y

o5 = OO
       Y

o5 : SheafOfRings
