agm -- arithmetic-geometric mean

  • Usage:
    agm(x,y)
  • Inputs:
    • x, a number
    • y, a number
  • Outputs:
    • the arithmetic-geometric mean of x and y

Description

i1 : agm(1,2p200)

o1 = 1.456791031046906869186432383265081974973863943221305590794173

o1 : RR (of precision 200)

See Arithmetic-geometric mean.

Ways to use agm:

  • agm(InexactNumber,InexactNumber)

For the programmer

The object agm is a method function.
