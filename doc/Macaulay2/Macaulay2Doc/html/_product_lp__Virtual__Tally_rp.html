product(VirtualTally) -- product of elements

  • Function: product

Description

product v yields the product of the elements in the tally v. 

i1 : a = tally{2,2,2,2,2,3,3,3,5,5}

o1 = Tally{2 => 5}
           3 => 3
           5 => 2

o1 : Tally
 
i2 : product a

o2 = 21600
