nullSpace -- find the null space of a mutable matrix

  • Usage:
    nullSpace m
  • Inputs:
    • m, a mutable matrix, over RR or CC
  • Outputs:
    • a mutable matrix, a mutable matrix whose columns span the null space of m

Description

i1 : m = mutableMatrix {{1.p500,1},{-2,-2}}

o1 = | 1  1  |
     | -2 -2 |

o1 : MutableMatrix
 
i2 : nullSpace m

o2 = | 1  |
     | -1 |

o2 : MutableMatrix
 
i3 : precision oo

o3 = 500

Ways to use nullSpace:

  • nullSpace(MutableMatrix)

For the programmer

The object nullSpace is a method function.
