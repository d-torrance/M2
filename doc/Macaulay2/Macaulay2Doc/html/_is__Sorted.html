isSorted -- whether a list is sorted

  • Usage:
    isSorted L
  • Inputs:
    • L, a visible list,
  • Outputs:
    • a Boolean value, whether the elements of L are in increasing order

Description

i1 : isSorted {1,2,2,3}

o1 = true
 
i2 : isSorted {1,2,3,2}

o2 = false
 
i3 : R = ZZ/2[x,y,z, MonomialOrder => Lex];
 
i4 : isSorted (z^3, y^2, x)

o4 = true
 
i5 : R = ZZ/2[x,y,z, MonomialOrder => GLex];
 
i6 : isSorted (z^3, y^2, x)

o6 = false
