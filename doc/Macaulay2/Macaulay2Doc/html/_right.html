right -- right endpoint of an interval

  • Usage:
    x = right I
  • Inputs:
    • I, a real interval,
  • Outputs:
    • x, a real number,

Description

Returns the right endpoint of the input interval.

i1 : right interval(2,3)

o1 = 3

o1 : RR (of precision 53)
