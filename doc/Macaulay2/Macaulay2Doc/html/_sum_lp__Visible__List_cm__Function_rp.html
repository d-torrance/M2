sum(VisibleList,Function) -- sum results of applying a function

  • Function: sum

Description

sum(v,f) yields the sum of the expressions obtained by applying f to each of the elements of the list or sequence v. 

i1 : sum(1 .. 10, i -> i^2)

o1 = 385
