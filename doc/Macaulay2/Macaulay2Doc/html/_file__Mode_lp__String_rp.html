fileMode(String) -- get file mode

  • Function: fileMode
  • Usage:
    fileMode fn
  • Inputs:
    • fn, a string
  • Outputs:
    • an integer, the mode of the file located at the filename or path fn

Description

i1 : fn = temporaryFileName()

o1 = /tmp/M2-32028-0/0
 
i2 : fn << "hi there" << close

o2 = /tmp/M2-32028-0/0

o2 : File
 
i3 : fileMode fn

o3 = 420
 
i4 : removeFile fn
