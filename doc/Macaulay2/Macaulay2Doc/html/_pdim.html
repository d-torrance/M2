pdim -- compute the projective dimension

  • Usage:
    pdim M

Caveat

For now, the method is to measure the length of a projective resolution.

Ways to use pdim:

  • pdim(BettiTally) -- see BettiTally -- the class of all Betti tallies
  • pdim(Module) -- compute the projective dimension of a module

For the programmer

The object pdim is a method function.
