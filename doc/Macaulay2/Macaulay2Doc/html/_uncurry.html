uncurry -- uncurry a function

Description

uncurry(f, (a,b)) -- computes ((f a) b).
uncurry(f, (a,b,c)) -- computes (((f a) b) c).
uncurry(f, (a,b,c,d)) -- computes ((((f a) b) c) d).
... and so on. 
i1 : f = a -> b -> c -> [a,b,c]

o1 = f

o1 : FunctionClosure
 
i2 : uncurry(f, (1,2,3))

o2 = [1, 2, 3]

o2 : Array

For the programmer

The object uncurry is a compiled function.
