toUpper -- convert to upper case

  • Usage:
    toUpper s
  • Inputs:
    • s, a string
  • Outputs:
    • a string, the string produced from s by converting its characters to lower case

Description

i1 : toUpper "A b C d E f"

o1 = A B C D E F

For the programmer

The object toUpper is a function closure.
