numericInterval -- convert a constant to an interval

  • Usage:
    I = numericInterval(c)
    I = numericInterval(prec,c)
  • Inputs:
    • c, an instance of the type Constant,
    • prec, an integer,
  • Outputs:
    • I, a real interval,

Description

Constructs an interval containing c of either the defaultPrecision or precision prec

See also

  • span(List) -- construct smallest interval
  • span(Sequence) -- construct smallest interval
  • interval -- construct an interval
  • toRRi -- construct an interval

Ways to use numericInterval:

  • numericInterval(Constant)
  • numericInterval(ZZ,Constant)

For the programmer

The object numericInterval is a method function.
