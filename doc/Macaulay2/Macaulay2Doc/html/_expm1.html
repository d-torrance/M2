expm1 -- exponential minus 1

  • Usage:
    expm1 x
    expm1 I
  • Inputs:
    • x, a complex number or a real number,
    • I, a real interval,
  • Outputs:
    • a real number or a complex number, the quantity exp(x)-1
    • a real interval or a complex interval, an interval containing the exponential of the points of I minus one

Description

i1 : expm1 1p100e-10

o1 = 1.000000000050000000001666666667e-10

o1 : RR (of precision 100)
 
i2 : exp(1p100e-10)-1

o2 = 1.000000000050000000009375867883e-10

o2 : RR (of precision 100)
 
i3 : expm1 interval(2,3)

o3 = [6.38905609893065,19.08553692318767]

o3 : RRi (of precision 53)
 
i4 : expm1 interval(1+2*ii,3+4*ii)

o4 = [-21.0855371843716,2.938759218559612]+[-16.52499393455643,
     18.26372732885223]*ii

o4 : CCi (of precision 53)

Ways to use expm1:

For the programmer
