Beta -- Beta function

  • Usage:
    Beta(x, y)
  • Inputs:
    • x, a real number,
    • y, a real number,
  • Outputs:
    • a real number, the beta function of x and y;

Description

This is the beta function \(B(x,y) = \int_0^1 t^{x - 1}(1 - t)^{y - 1}\,dt\).

i1 : Beta(3, 4)

o1 = .01666666666666667

o1 : RR (of precision 53)

See also

  • regularizedBeta -- regularized beta function
  • inverseRegularizedBeta -- inverse of the regularized beta function

Ways to use Beta:

  • Beta(InexactNumber,InexactNumber)

For the programmer

The object Beta is a method function.
