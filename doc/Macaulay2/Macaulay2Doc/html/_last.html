last -- last element of a list

  • Usage:
    last L
  • Inputs:
    • L, a list or sequence
  • Outputs:
    • l, the last element of L

Description

i1 : last {a,b,c,d,e}

o1 = e

o1 : Symbol
 
i2 : last gens(QQ[x,y,z])

o2 = z

o2 : QQ[x..z]
