values -- values in a hash table

  • Usage:
    values t
  • Inputs:
    • t, a hash table,
  • Outputs:
    • a list, the values occurring in the hash table t

Description

i1 : x = new HashTable from {a => 1, b => 2}

o1 = HashTable{a => 1}
               b => 2

o1 : HashTable
 
i2 : values x

o2 = {1, 2}

o2 : List
