isMember(QQ,CCi) -- membership test in an interval

  • Function: isMember
  • Usage:
    isMember(x,I)
  • Inputs:
    • x, a rational number, an integer, a real number, or a complex number,
    • I, a complex interval,
  • Outputs:
    • a Boolean value,

Description

Returns true if the input number is in the interval.

i1 : isMember(1,interval(2,3))

o1 = false
 
i2 : isMember(2,interval(1,3))

o2 = true
 
i3 : isMember(1+2*ii,interval(0,2+3*ii))

o3 = true
