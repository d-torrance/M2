threadLocal -- create a symbol whose value in one thread is not shared with others

  • Usage:
    threadLocal foo
  • Outputs:
    • a new symbol, whose name is "foo", for example, whose values in each thread will be independent of each other, with initial value null

Description

i1 : threadLocal x

o1 = x

o1 : Symbol
 
i2 : x = 1

o2 = 1
 
i3 : t = schedule ( () -> ( x = 2 ; x ) )

o3 = <<task, created>>

o3 : Task
 
i4 : taskResult t

o4 = 2
 
i5 : x

o5 = 1

For the programmer

The object threadLocal is a keyword.
