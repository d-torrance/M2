random(Module,Module) -- get a random map of module

  • Function: random
  • Usage:
    f = random(F, G)
  • Inputs:
    • F, a module,
    • G, a module,
  • Optional inputs:
    • Density => a real number, default value 1, the proportion of entries to set
    • MaximalRank => a Boolean value, default value false, whether to ensure that the resulting map has maximal rank: designed mostly for use with matrices of numbers: for polynomial rings, returns inhomogeneous results
    • UpperTriangular => a Boolean value, default value false, whether to set just entries strictly above the diagonal
    • CoefficientRing (missing documentation) => ..., default value null,
    • Height => ..., default value 10, get a random homogeneous element from a graded ring
  • Outputs:
    • f, a matrix, a random, graded, degree 0 map $f: G \to F$

Description

i1 : R = ZZ/101[x,y];

Caveat

Over a polynomial ring, specifying MaximalRank=>true will yield a non-homogeneous matrix.
