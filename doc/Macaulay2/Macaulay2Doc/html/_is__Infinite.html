isInfinite -- whether a number is infinite

  • Usage:
    isInfinite x
  • Inputs:
    • x, a number
  • Outputs:
    • a Boolean value, whether x is an infinite number

Description

i1 : isInfinite 3.

o1 = false
 
i2 : inf = 1/0.

o2 = infinity

o2 : RR (of precision 53)
 
i3 : isInfinite inf

o3 = true
 
i4 : nan = inf - inf

o4 = NotANumber

o4 : RR (of precision 53)
 
i5 : isInfinite nan

o5 = false
