read(File) -- read from a file

  • Function: read
  • Usage:
    read f
  • Inputs:
    • f, a file, an input file
  • Outputs:
    • a string, a string obtained by reading from f.

Description

i1 : f = openInOut "!cat"

o1 = !cat

o1 : File
 
i2 : isReady f

o2 = false
 
i3 : f << "hi there" << flush;
 
i4 : isReady f

o4 = false
 
i5 : read f

o5 = hi there
 
i6 : isReady f

o6 = false
