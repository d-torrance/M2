cover -- get the covering free module

Description

cover M -- yields the free module whose basis elements correspond to the generators of M.

See also

  • ambient -- ambient free module of a subquotient, or ambient ring
  • super -- get the ambient module

Ways to use cover:

  • cover(Matrix) -- get the map between the covering free modules
  • cover(MutableMatrix) -- see cover(Matrix) -- get the map between the covering free modules
  • cover(Module) -- get the covering free module

For the programmer

The object cover is a method function.
