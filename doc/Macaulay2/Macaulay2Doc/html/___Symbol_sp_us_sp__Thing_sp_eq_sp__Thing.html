Symbol _ Thing = Thing -- assignment to an indexed variable

  • Operator: _
  • Usage:
    x_a = v
  • Inputs:
    • x, a symbol
    • a, a thing
    • v, a thing
  • Outputs:
    • v
  • Consequences:
    • the indexed variable x_a is assigned the value v.
