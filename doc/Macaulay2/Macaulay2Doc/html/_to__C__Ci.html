toCCi -- construct an interval

  • Usage:
    I = toCCi(n)
    I = toCCi(re,im)
    I = toCCi(prec,re,im)
  • Inputs:
    • n, a complex number,
    • re, a real interval,
    • im, a real interval,
    • prec, an integer,
  • Outputs:
    • I, a complex interval,

Description

Returns an interval as small as possible containing n or from l to r. Note that if l is to the right of r, the constructed interval is empty. This is a more low-level function and interval or span should be used instead.

See also

  • span(List) -- construct smallest interval
  • span(Sequence) -- construct smallest interval
  • interval -- construct an interval

For the programmer

The object toCCi is a compiled function.
