acosh -- inverse hyperbolic cosine

  • Usage:
    acosh x
  • Inputs:
    • x
  • Outputs:
    • a number, the inverse hyperbolic cosine of x

Description

i1 : acosh .2

o1 = 1.369438406004566*ii

o1 : CC (of precision 53)
 
i2 : cosh oo

o2 = .1999999999999999

o2 : CC (of precision 53)

See Hyperbolic function.

Ways to use acosh:

  • acosh(Number)

For the programmer

The object acosh is a method function.
