selectVariables -- make a subring of a polynomial ring generated by selected variables

  • Usage:
    (S,F) = selectVariables(v,R)
  • Inputs:
    • v, a sorted list of numbers specifying which variables to select
    • R
  • Outputs:
    • S, a polynomial ring, a polynomial ring generated as a subring of R by the variables whose indices occur in the list v, together with the induced monomial ordering
    • F, a ring map, the inclusion map from S to R

Description

i1 : R = QQ[a..h, Weights => 1..8]

o1 = R

o1 : PolynomialRing
 
i2 : (S,F) = selectVariables({2,4}, R);
