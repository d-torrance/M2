fileMode(ZZ,String) -- set file mode

  • Function: fileMode
  • Usage:
    fileMode(mo,fn)
  • Inputs:
    • mo, an integer
    • fn, a string
  • Consequences:
    • the mode of the file located at the filename or path fn is set to mo

Description

i1 : fn = temporaryFileName()

o1 = /tmp/M2-33125-0/0
 
i2 : fn << "hi there" << close

o2 = /tmp/M2-33125-0/0

o2 : File
 
i3 : m = fileMode fn

o3 = 420
 
i4 : fileMode(m|7,fn)
 
i5 : fileMode fn

o5 = 423
 
i6 : removeFile fn
