characters -- get characters from a string

  • Usage:
    characters s
  • Inputs:
    • s, a string
  • Outputs:
    • a list, of the characters in the string s

Description

The characters are represented by strings. 

i1 : characters "asdf"

o1 = {a, s, d, f}

o1 : List

utf8 characters are correctly treated: 

i2 : characters "π ≈ 3.14159"

o2 = {π,  , ≈,  , 3, ., 1, 4, 1, 5, 9}

o2 : List

To get the one-byte characters of the string, use toList instead.

See also

  • String -- the class of all strings

For the programmer
