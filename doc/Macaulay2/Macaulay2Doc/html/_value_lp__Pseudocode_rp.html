value(Pseudocode) -- execute pseudocode

  • Function: value
  • Usage:
    value p
  • Inputs:
    • p, an instance of the type Pseudocode
  • Outputs:
    • the value returned by evaluation of p

Description

Here is an example of its use in the debugger, to see whether modifying the value of a local variable fixed the problem in the code, by executing just the offending line.

i1 : load "Macaulay2Doc/demos/demo1.m2"
 
i2 : g 2
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:11:(3):[3]: error: division by zero
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:11:(3): entering debugger (enter 'help' to see commands)
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:
10-8:13: --source code:
     b := 1/x;
 
ii3 : value current
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:11:(3): error: division by zero
 
ii4 : x = 11

oo4 = 11
 
ii5 : value current

       1
oo5 = --
      11

oo5 : QQ
