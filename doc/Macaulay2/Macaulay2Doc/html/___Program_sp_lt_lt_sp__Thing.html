Program << Thing -- run program with input redirection

  • Operator: <<
  • Usage:
    prog << x
  • Inputs:
    • prog, an instance of the type Program,
    • x, a thing,
  • Outputs:
    • an instance of the type ProgramRun,

Description

Write x to a temporary file and run prog with this file as input using input redirection (the < operator in a POSIX shell).

i1 : M2 = findProgram "M2"

o1 = M2

o1 : Program
 
i2 : M2 << "2 + 2"

o2 = 0

o2 : ProgramRun
 
i3 : toString oo

o3 = Macaulay2, version 1.26.05
     Type "help" to see useful commands

     i1 : 2 + 2
          
     o1 = 4
