log1p -- logarithm of 1+x

  • Usage:
    log1p x
    log1p I
  • Inputs:
    • x, a real number or a complex number,
    • I, a real interval or a complex interval,
  • Outputs:
    • a real number or a complex number, the logarithm of 1+x
    • a real interval or a complex interval, an interval containing logarithm of 1 plus the points of I

Description

i1 : log1p 1p100e-10

o1 = 9.999999999500000000033333333333e-11

o1 : RR (of precision 100)
 
i2 : log(1 + 1p100e-10)

o2 = 9.999999999500000000059340457244e-11

o2 : RR (of precision 100)
 
i3 : log1p interval(2,3)

o3 = [1.09861228866811,1.386294361119891]

o3 : RRi (of precision 53)
 
i4 : log1p interval(1+2*ii,3+4*ii)

o4 = [1.039720766246319,1.732867954298854]+[.4636476021260023,
     1.107148721814156]*ii

o4 : CCi (of precision 53)

Ways to use log1p:

  • log1p(InexactNumber)

For the programmer

The object log1p is a method function.
