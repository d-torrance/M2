Ring ^ ZZ -- make a free module

  • Operator: ^
  • Usage:
    R^n
  • Inputs:
    • R, a ring
    • n, an integer
  • Outputs:
    • a module, a new free R-module of rank n.

Description

The new free module has basis elements of degree zero. To specify the degrees explicitly, see Ring ^ List. 
i1 : R = ZZ[x,y,z]/(x^2-y*x)

o1 = R

o1 : QuotientRing
 
i2 : F = R^4

      4
o2 = R

o2 : R-module, free
 
i3 : degrees F

o3 = {{0}, {0}, {0}, {0}}

o3 : List
