vars(Monoid) -- list of variables in a monoid

  • Function: vars
  • Usage:
    vars M
  • Inputs:
    • R, a monoid
  • Outputs:
    • a list, a list of the generators of M

Description

The result is the same as that provided by generators(Monoid). 
i1 : M = monoid[x,y,z]

o1 = M

o1 : GeneralOrderedMonoid
 
i2 : vars M

o2 = {x, y, z}

o2 : List
