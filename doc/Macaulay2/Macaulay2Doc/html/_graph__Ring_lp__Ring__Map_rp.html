graphRing(RingMap) -- the coordinate ring of the graph of the regular map corresponding to a ring map

  • Function: graphRing
  • Usage:
    graphRing f
  • Inputs:
    • f, a ring map
  • Optional inputs:
    • MonomialOrder => ..., default value {GRevLex, Position => Up}, a monomial ordering, see monomial orderings
    • MonomialSize => an integer, default value 32, the monomial size, see MonomialSize
    • VariableBaseName => a symbol, default value "p", the variable base name, see VariableBaseName
  • Outputs:
    • a quotient ring, the coordinate ring of the graph of regular map corresponding to f
