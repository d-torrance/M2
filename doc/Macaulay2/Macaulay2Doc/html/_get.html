get -- get the contents of a file

  • Usage:
    get f
  • Inputs:
    • f, a file or a string. If f is a string, then it is opened, as with openIn. Filenames starting with ! or with $ are treated specially, see openInOut.
  • Outputs:
    • a string containing the contents of the file. If the file was already open and partially read, the remainder of the contents of the file are returned.
  • Consequences:
    • In the case where f is a file, its input side is closed.

Description

i1 : "test-file" << "hi there" << close

o1 = test-file

o1 : File
 
i2 : get "test-file"

o2 = hi there
 
i3 : removeFile "test-file"
 
i4 : get "!date"

o4 = Fri Aug  7 01:44:32 UTC 2026
