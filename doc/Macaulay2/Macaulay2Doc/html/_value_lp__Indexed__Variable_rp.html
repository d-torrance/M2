value(IndexedVariable) -- retrieve the value of an indexed variable

  • Function: value
  • Usage:
    value s
  • Inputs:
    • s, an indexed variable
  • Outputs:
    • the value of s

Description

i1 : y = x_3

      3

o1 : IndexedVariable
 
i2 : x_3 = 4

o2 = 4
 
i3 : x_3

o3 = 4
 
i4 : y

      3

o4 : IndexedVariable
