rootURI

  • Usage:
    rootURI
  • Outputs:
    • a string, the path, as seen by an external browser, to the root of the file system seen by Macaulay2

Description

This string may be concatenated with an absolute path to get one understandable by an external browser.

i1 : fn = temporaryFileName()

o1 = /tmp/M2-32644-0/0
 
i2 : rootURI | fn

o2 = file:///tmp/M2-32644-0/0

See also

  • rootPath

For the programmer

The object rootURI is a string.
