monoid(...,MonomialOrder=>...) -- specify the monomial ordering

  • Usage:
    monoid[a,b,c, MonomialOrder => {...}]

Description

The MonomialOrder option specifies the monomial ordering, see MonomialOrder.

This option may also be used when creating a new ring from an existing ring, creating a tensor product ring, or symmetric algebra.
