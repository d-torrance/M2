Symbol ..< Symbol -- sequences of consecutive symbols

  • Operator: ..<
  • Usage:
    s ..< t
  • Inputs:
    • s, a symbol
    • t, a symbol
  • Outputs:
    • the sequence of consecutive symbols useful as variables in polynomial rings, from s to t, not including the endpoint, as determined by the vars(ZZ)

Description

i1 : x ..< z

o1 = (x, y)

o1 : Sequence
 
i2 : x ..< C

o2 = (x, y, z, A, B)

o2 : Sequence
