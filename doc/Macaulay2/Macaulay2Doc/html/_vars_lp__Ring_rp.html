vars(Ring) -- row matrix of the variables

  • Function: vars
  • Usage:
    vars R
  • Inputs:
    • R, a ring
  • Outputs:
    • a matrix, a matrix with one row whose entries are the variables of the ring R

Description

i1 : S = QQ[w,x,y,z];
 
i2 : vars S

o2 = | w x y z |

             1      4
o2 : Matrix S  <-- S
 
i3 : ideal vars S

o3 = ideal (w, x, y, z)

o3 : Ideal of S
 
i4 : coker vars S

o4 = cokernel | w x y z |

                            1
o4 : S-module, quotient of S
 
i5 : res coker vars S

      1      4      6      4      1
o5 = S  <-- S  <-- S  <-- S  <-- S
                                  
     0      1      2      3      4

o5 : Complex
