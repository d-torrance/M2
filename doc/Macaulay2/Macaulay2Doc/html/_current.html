current -- the pseudocode that produced an error

  • Usage:
    current
  • Outputs:
    • an instance of the type PseudocodeClosure, the pseudocode that produced an error, or null, if none

Description

Use value to evaluate the code again, for debugging purposes. 
i1 : load "Macaulay2Doc/demos/demo1.m2"
 
i2 : code g

o2 = /usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.

     g = y -> (
          c := f(y-1);
          d := f(y-2);
          c+d)
 
i3 : g 2
