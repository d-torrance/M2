left shift

  • Usage:
    x << j
    I << j
  • Inputs:
    • x
    • j
    • I, a real interval
  • Outputs:
    • the number obtained from x by shifting its binary representation leftward j places
    • a real interval, an interval containing all shifts of the binary representations elements of I by j places leftward
i1 : 256 << 5

o1 = 8192
 
i2 : 256. << 555

o2 = 3.019169939857233e169

o2 : RR (of precision 53)
