MethodFunctionBinary -- a type of method function

Description

The type of all method functions created with the option Binary set to true, such as gcd.

See also

  • method -- make a new method function

Protected objects of class MethodFunctionBinary:

  • directProduct -- direct product
  • gcd -- greatest common divisor
  • intersect -- compute an intersection
  • lcm -- least common multiple
  • span -- construct smallest interval
  • tensor -- tensor product
  • union -- compute the union

For the programmer

The object MethodFunctionBinary is a type, with ancestor classes FunctionClosure < Function < Thing.
