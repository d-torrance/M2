IndexedVariable ..< IndexedVariable -- sequences of consecutive indexed variables

  • Operator: ..<
  • Usage:
    s ..< t
  • Inputs:
    • s, an indexed variable
    • t, an indexed variable
  • Outputs:
    • a sequence, the sequence of indexed variables with the same base and with consecutive subscripts, not including the endpoint

Description

i1 : x_1

o1 = x
      1

o1 : IndexedVariable
 
i2 : x_(a,1) ..< z_(c,3)

o2 = (x   , x   , x   , x   , y   , y   , y   , y   )
       a,1   a,2   b,1   b,2   a,1   a,2   b,1   b,2

o2 : Sequence
