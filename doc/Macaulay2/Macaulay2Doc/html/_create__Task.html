createTask -- create a task

  • Usage:
    createTask(f,x)
    createTask f
  • Inputs:
    • f, a function,
    • x, a thing,
  • Outputs:
    • a task, which when scheduled, will apply the function f to the argument x. In the second form, where x is not specified, it is take to be ().

Description

i1 : f = x -> 2^x

o1 = f

o1 : FunctionClosure
 
i2 : t = createTask(f,3)

o2 = <<task, created>>

o2 : Task
 
i3 : schedule t

o3 = <<task, created>>

o3 : Task
 
i4 : taskResult t

o4 = 8

Ways to use createTask:

  • createTask(Function)
  • createTask(Function,Thing)

For the programmer

The object createTask is a compiled function.
