addStartTask(Task,Task) -- schedule a task upon completion of another

  • Function: addStartTask
  • Usage:
    addStartTask(t,u)
  • Inputs:
    • t, a task,
    • u, a task,
  • Consequences:
    • After task t finishes, task u will be scheduled for execution.

Description

i1 : f = () -> "f value";
 
i2 : g = () -> "g value";
 
i3 : F = createTask f

o3 = <<task, created>>

o3 : Task
 
i4 : G = createTask g

o4 = <<task, created>>

o4 : Task
 
i5 : addStartTask(F,G)
 
i6 : schedule F

o6 = <<task, created>>

o6 : Task
 
i7 : taskResult F

o7 = f value
 
i8 : taskResult G

o8 = g value
