setIOExclusive -- exclusive I/O for the current thread

  • Usage:
    setIOExclusive()
    setIOExclusive f
  • Inputs:
    • f, a file,
  • Consequences:
    • the current thread becomes the only one permitted to use the file f, or if no file is given, the files stdio and stderr.
