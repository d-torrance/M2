isReady(Task) -- whether a task is finished

  • Function: isReady
  • Usage:
    isReady t
  • Inputs:
    • t, a task,
  • Outputs:
    • a Boolean value, whether the task t has finished executing and a return value is available

Description

The return value can be retrieved with taskResult(Task).

Ways to use this method:

  • isReady(Task) -- whether a task is finished
