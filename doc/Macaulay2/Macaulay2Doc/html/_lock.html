lock -- lock a mutex

  • Usage:
    lock m
  • Inputs:
    • m, a mutex,

Description

Locks a mutex.

i1 : m = new Mutex

o1 = m

o1 : Mutex
 
i2 : lock m

If the mutex is already locked, then the thread blocks until it is unlocked. This is not interruptible.
