throw -- throw and catch exceptions

  • Usage:
    catch c
    throw x
  • Outputs:
    • catch returns the value obtained by evaluating the code c, or, if a throw was executed during the evaluation of c, the argument given to throw.
  • Consequences:
    • throw passes the flow of control to the surrounding catch, and x is returned as its value

Description

i1 : catch scan(0..10, i -> if i == 5 then throw 18 else print i)
0
1
2
3
4

o1 = 18

For the programmer

The object throw is a keyword.
