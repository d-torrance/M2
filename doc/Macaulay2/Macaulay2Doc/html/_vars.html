vars -- variables

Ways to use vars:

  • vars(List) -- a sequence of variables
  • vars(Sequence) -- see vars(List) -- a sequence of variables
  • vars(ZZ) -- see vars(List) -- a sequence of variables
  • vars(Monoid) -- list of variables in a monoid
  • vars(Ring) -- row matrix of the variables

For the programmer

The object vars is a method function with a single argument.
