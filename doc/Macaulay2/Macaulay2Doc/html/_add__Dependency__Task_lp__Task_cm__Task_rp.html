addDependencyTask(Task,Task) -- schedule a task, but ensure that it will not run until another task finishes

  • Function: addDependencyTask
  • Usage:
    addDependencyTask(t,u)
  • Inputs:
    • t, a task,
    • u, a task,
  • Consequences:
    • the task t will be scheduled for execution, but execution will not begin until the task u finishes

Description

i1 : for i to 5 do t_i = createTask(() -> i)
 
i2 : for i from 1 to 5 do addDependencyTask(t_i, t_(i - 1))
 
i3 : schedule t_0

o3 = <<task, created>>

o3 : Task
 
i4 : sleep 1

o4 = 0
 
i5 : taskResult t_5

o5 = 5
