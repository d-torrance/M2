changes, 1.25.11

  • upcoming breaking changes:
    • Beginning in the 1.26.05 release, current routines involving chain complexes and graded modules will be superseded by new functorial homological algebra routines in the Complexes package. Users and package developers are encouraged to preview the upcoming changes by adding HomologicalAlgebraPackage = "Complexes" to their initialization file and reporting any bugs via email or GitHub.
  • packages that have been published and certified:
    • ExteriorExtensions, a package by Luke Oeding for building an algebra extending an exterior algebra, has been published.
    • MatrixSchubert, a package by Ayah Almousa, Sean Grate, Daoji Huang, Patricia Klein, Adam LaClair, Yuyuan Luo, and Joseph McDonough for functions for investigating ASM and matrix Schubert varieties, has been published.
    • MultigradedBGG, a package by Maya Banks, Michael K. Brown, Tara Gomes, Prashanth Sridhar, Eduardo Torres Davila, and Sasha Zotine for the multigraded BGG correspondence and differential modules, has been published.
  • new packages:
    • CpMackeyFunctors, a package by Thomas Brazelton, David Chan, Benjamin Mudrak, Ben Spitz, Chase Vogeli, Chenglu Wang, Michael R. Zeng, and Sasha Zotine for homological algebra with Mackey functors for cyclic groups of prime order, has been added.
    • ExteriorExtensions, a package by Luke Oeding for building an algebra extending an exterior algebra, has been added.
    • JSONRPC, a package by Doug Torrance for implementing JSON-RPC servers, has been added.
    • MatrixFactorizations, a package by David Favero, Sasha Pevzner, Timothy Tribone, and Keller VandeBogert for computing with matrix factorizations of different lengths, has been added.
    • NonPrincipalTestIdeals, a package by Trung Chau, Karl Schwede, and Hunter Simper for singularities of pairs with non-principal ideals, has been added.
    • PathSignatures, a package by Felix Lotter, Oriol Reig, Angelo El Saliby, and Carlos Amendola for working with algebraic path signatures, has been added.
    • Tableaux, a package by John Graf for constructing skew tableaux, has been added.
  • improved packages:
    • A1BrouwerDegrees has been updated to version 2.0, with significant updates.
    • CharacteristicClasses has been updated to version 2.1, with a new method to compute the Euler characteristic of a complex affine variety.
    • ForeignFunctions has been updated to version 0.6.
    • GeometricDecomposability has been updated to version 1.4.3, adding aliases for methods with long names.
    • JSON has been updated to version 0.5.
    • LieAlgebraRepresentations (formerly LieTypes) has been updated to version 1.0 with a major expansion.
    • Msolve has been updated to version 1.24.06, fixing a bug in msolveRUR.
    • MultigradedImplicitization has been updated to version 1.1, with an option to use interpolation to compute polynomials in multigraded components and changes to speed up multidegree and basis computation.
    • PolyominoIdeals has been updated to version 2.0, including some functions that help with computations for collection of cells.
    • Probability has been updated to version 0.6.
    • Python has been updated to version 1.0 with significant updates, including the new PythonContext class and the method pythonRunScript.
    • SCMAlgebras has been updated to version 1.1, adding new methods. It can now compute the unmixed layer of an ideal, check for unmixedness, and check for canonical Cohen-Macaulayness.
    • SRdeformations has been updated to version 0.53, using Polyhedra instead of OldPolyhedra.
    • TerraciniLoci has been updated to version 0.4.
    • ToricHigherDirectImages has been updated to version 1.1, fixing unexpected behavior from the output of HDI.
    • ToricTopology has been updated to version 1.1, adding a new class MomentAngleComplex and associated methods to compute equivariant cohomology, Betti numbers, and Euler characteristic, as well as minor fixes to the rest of the package.
    • VectorGraphics has been updated to version 1.1.1 with a bug fix and assorted minor changes.
    • VersalDeformations has been updated to version 4.0, adding functionality for dealing with deformations of pairs of schemes or modules.
    • Visualize has been updated to version 1.8 with updates to the Javascript code.
    • WhitneyStratifications has been updated to version 2.23, with several new methods to compute Whitney stratifications using polar varieties and to compute the Euler characteristic of the complex link and the local Euler obstruction using Whitney stratification.
  • functionality added or improved:
    • The method set(HashTable) has been added to create a set from the keys of a hash table.
    • The method toList(Tally) has been added as a synonym for elements(Tally).
    • A new IFRAME class has been added for using <iframe> tags in html.
    • Package authors may now add tests as individual files in the tests subdirectory of the package auxiliary directory without the need to use the TEST keyword. See check.
    • A warning message is now displayed when reloading a package reminding users to recreate instances of any types from that package.
    • Negative numbers may now be used when getting matrices entries, creating submatrices, and getting ring variables to count backwards from the end. For example, A_{-1} will return the last column of the matrix A.
    • The method sqrt(ZZ,ZZ) has been added for computing square roots in finite prime fields.
    • The method pfaffian has been added for computing the pfaffian of a skew-symmetric matrix.
    • A new binary operator, @@?, has been added.
  • functionality changed in a way that could break code:
    • The package LieTypes has been renamed as LieAlgebraRepresentations.
    • An error is now raised if a function parameter list contains a duplicate symbol.
    • Examples in package documentation are now generated using capture. This speeds up installation considerably, but unexpected results may occur if, for example, one example sets a global variable that affects the behavior of another example. To restore the old behavior of generating the example is a new M2 process, add the comment -* no-capture-flag *- to the example.
