HH -- general homology and cohomology functor

Description

HH is a ScriptedFunctor which serves as an interface to the methods for homology and cohomology, in the sense that, HH_i(M) is an abbreviation for homology(i,M) HH^i(M) is an abbreviation for cohomology(i,M), and HH(M) is an abbreviation for homology(,M). A second argument and optional arguments may be added.

Menu

  • homology -- general homology functor
  • cohomology -- general cohomology functor

Ways to use HH:

  • HH^ZZ Module -- local cohomology of a module
  • HH_ZZ Sequence (missing documentation)
  • homology(Matrix,Matrix) -- homology of a pair of maps

For the programmer

The object HH is a scripted functor.
