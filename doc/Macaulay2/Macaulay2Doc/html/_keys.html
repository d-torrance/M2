keys -- keys used in a hash table, dictionary, or database

  • Usage:
    keys t
  • Inputs:
    • t, a hash table, a dictionary, or a database,
  • Outputs:
    • a list, the keys occurring in the hash table t

Description

i1 : x = new HashTable from {a => 1, b => 2}

o1 = HashTable{a => 1}
               b => 2

o1 : HashTable
 
i2 : keys x

o2 = {a, b}

o2 : List
