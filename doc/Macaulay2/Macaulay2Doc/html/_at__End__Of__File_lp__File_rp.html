atEndOfFile(File) -- test for end of file

  • Function: atEndOfFile
  • Usage:
    atEndOfFile f
  • Inputs:
    • f, a file
  • Outputs:
    • a Boolean value, whether the input file f is at the end

Description

i1 : f = openInOut "!cat"

o1 = !cat

o1 : File
 
i2 : f << "hi there" << closeOut;
 
i3 : atEndOfFile f

o3 = false
 
i4 : peek read f

o4 = "hi there"
 
i5 : atEndOfFile f

o5 = false
