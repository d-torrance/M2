demark -- insert a string between elements of a list of strings

  • Usage:
    demark(d, L)
  • Inputs:
    • d, a string,
    • L, a list, of strings
  • Outputs:
    • s, a string, the string obtained by concatenating the elements of L, with copies of the string d inserted between each pair

Description

i1 : demark("+", a..f)

o1 = a+b+c+d+e+f
 
i2 : demark(" and ", 6:"more")

o2 = more and more and more and more and more and more

To achieve a similar insertion while keeping the output as a list, see mingle.

i3 : mingle(6: "more", 5: "and")

o3 = {more, and, more, and, more, and, more, and, more, and, more}

o3 : List
