RingElement .. RingElement -- a sequence of consecutive generators of a polynomial ring

  • Operator: ..
  • Usage:
    s .. t
  • Inputs:
    • s, a ring element
    • t, a ring element
  • Outputs:
    • the sequence of consecutive generators of a polynomial ring, from s to t, inclusive

Description

i1 : R = QQ[a..z]

o1 = R

o1 : PolynomialRing
 
i2 : b .. i

o2 = (b, c, d, e, f, g, h, i)

o2 : Sequence
 
i3 : plus oo

o3 = b + c + d + e + f + g + h + i

o3 : R

Warning: former behavior involved making the names of the generators consecutive, so the results in the next example differ from those given before.

i4 : R = QQ[e,d,c,b,a,X_1,y,X_2]

o4 = R

o4 : PolynomialRing
 
i5 : e .. a

o5 = ()

o5 : Sequence
 
i6 : X_1 .. X_2

o6 = (X , X )
       1   2

o6 : Sequence

Warning: since former behavior involved only the names of the generators, there was no requirement that s and t be in the same ring, whereas now there is.
