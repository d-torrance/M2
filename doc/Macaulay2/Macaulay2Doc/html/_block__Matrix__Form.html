blockMatrixForm -- global flag for block printing

  • Usage:
    blockMatrixForm = x
  • Consequences:
    • changes the display of matrices

Description

blockMatrixForm is a global flag that specifies whether to display blocks in matrices.

The default value is false. 
i1 : M = ZZ^1 ++ ZZ^2 ++ ZZ^3

       6
o1 = ZZ

o1 : ZZ-module, free
 
i2 : f = random(M,M)

o2 = | 8 3 8 6 6 2 |
     | 1 7 5 8 9 6 |
     | 3 8 2 6 6 9 |
     | 7 8 3 9 2 3 |
     | 8 5 6 3 6 5 |
     | 3 7 3 7 0 6 |

              6       6
o2 : Matrix ZZ  <-- ZZ
 
i3 : blockMatrixForm = true;
 
i4 : f

     | 3 | 7 3 | 7 0 6 |

              6       6
o4 : Matrix ZZ  <-- ZZ
