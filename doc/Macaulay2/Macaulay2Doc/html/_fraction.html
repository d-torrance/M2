fraction

  • Usage:
    fraction(f, g)
  • Outputs:
    • a ring element, the fraction f/g

Description

The output will be in the fraction field of the ring containing f and g, without reducing it to lowest terms.

See also

  • frac -- construct a fraction field

Ways to use fraction:

  • fraction(RingElement,RingElement)

For the programmer

The object fraction is a method function.
