width -- width of an object

Description

This function is a method function, defined in the core so multiple packages can add methods to it.

Ways to use width:

  • width(File) -- get window width
  • width(Net) -- width of a net
  • width(String) -- see width(Net) -- width of a net

For the programmer

The object width is a method function.
