⊠= -- augmented assignment for ⊠

  • Usage:
    x ⊠= y

Description

In most cases, x ⊠= y is equivalent to x = x ⊠ y, unless a method is installed for the class of x.

See also

  • ⊠ -- a binary operator, usually used for exterior product
  • augmented assignment
  • installing augmented assignment methods

For the programmer

The object ⊠= is a keyword.

This operator may be used as a binary operator in an expression like x⊠=y. The user may install a method for handling such expressions with code such as

         X ⊠= (x,y) -> ...

where X is the class of x.
