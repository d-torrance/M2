++ -- a binary operator, usually used for direct sum

Ways to use symbol ++:

  • BettiTally ++ BettiTally -- see BettiTally -- the class of all Betti tallies
  • Option ++ Option -- see directSum -- direct sum of modules or maps
  • Matrix ++ Matrix -- direct sum of maps
  • Matrix ++ RingElement -- see Matrix ++ Matrix -- direct sum of maps
  • RingElement ++ Matrix -- see Matrix ++ Matrix -- direct sum of maps
  • RingElement ++ RingElement -- see Matrix ++ Matrix -- direct sum of maps
  • Module ++ Module -- direct sum of modules
  • OptionTable ++ List -- see OptionTable ++ OptionTable
  • OptionTable ++ OptionTable

For the programmer

The object ++ is a keyword.

This operator may be used as a binary operator in an expression like x++y. The user may install binary methods for handling such expressions with code such as

         X ++ Y := (x,y) -> ...

where X is the class of x and Y is the class of y.
