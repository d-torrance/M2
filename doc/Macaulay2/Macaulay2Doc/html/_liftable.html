liftable -- whether lifting to another ring is possible

  • Usage:
    liftable(f,R)
  • Inputs:
    • f, a ring element or a matrix
    • R, a ring
  • Outputs:
    • a Boolean value, whether f can be lifted to the ring R

Description

The ring R should be one of the base rings associated with the ring of f. 
i1 : R = ZZ[x]

o1 = R

o1 : PolynomialRing
 
i2 : liftable ((x-1)*(x+1)-x^2, ZZ)

o2 = true
 
i3 : liftable(3/4,ZZ)

o3 = false
 
i4 : liftable((3/4)*4,ZZ)

o4 = true

See also

  • lift -- lift to another ring
  • baseRings -- store the list of base rings of a ring

For the programmer

The object liftable is a method function.
