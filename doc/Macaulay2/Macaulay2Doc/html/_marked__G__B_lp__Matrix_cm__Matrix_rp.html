markedGB(Matrix,Matrix) -- make a marked Gröbner basis

  • Function: markedGB
  • Usage:
    markedGB(lt,m)
  • Inputs:
    • lt, a matrix, the matrix of monomials in (the columns of) m to mark as lead terms, with respect to an unspecified monomial ordering
    • m, a matrix, the matrix whose columns are to form the generators of a Gröbner basis
  • Optional inputs:
    • SyzygyMatrix => a matrix, default value null, the matrix of syzygies
    • MinimalMatrix => a matrix, default value null, the matrix of minimal generators
    • ChangeMatrix => a matrix, default value null, the change-of-basis matrix
  • Outputs:
    • a Gröbner basis, the resulting Gröbner basis

Ways to use this method:

  • markedGB(Matrix,Matrix) -- make a marked Gröbner basis
