disassemble -- disassemble a pseudocode or function

  • Usage:
    disassemble c
  • Inputs:
    • c, a function or an instance of the type Pseudocode
  • Outputs:
    • a string, the disassembled form of c

Description

i1 : disassemble (() -> 1/(1-1))

o1 = (function restargs: false numparms: 0 framesize: 0 frameID: 15555 (2-OP
     / 1 (2-OP - 1 1)))
 
i2 : disassemble functionBody (() -> 1/(1-1))

o2 = (2-OP / 1 (2-OP - 1 1))

It may be useful to disassemble code during debugging, as in the following demonstration.

i3 : load "Macaulay2Doc/demos/demo1.m2"
 
i4 : code g

o4 = /usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.
     m2:11:4-14:9: --source code:
     g = y -> (
          c := f(y-1);
          d := f(y-2);
          c+d)
 
i5 : g 2
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:11:(3):[3]: error: division by zero
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:11:(3): entering debugger (enter 'help' to see commands)
/usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.m2:8:
10-8:13: --source code:
     b := 1/x;
 
ii6 : code current

oo6 = /usr/local/share/Macaulay2/Macaulay2Doc/demos/demo1.
      m2:8:10-8:13: --source code:
           b := 1/x;
 
ii7 : disassemble current

oo7 = (2-OP / 1 (local-fetch 0 0))
 
ii8 : current

oo8 = 2-OP / 1
             local-fetch 0 0

oo8 : PseudocodeClosure
