intersect(RRi) -- intersection of input intervals

  • Function: intersect
  • Usage:
    J = intersect(I,...)
    J = intersect(I,...,Precision => prec)
  • Inputs:
    • I, a real interval,
  • Optional inputs:
    • Precision => an integer, default value -1, specifies the desired precision of the output, a value of -1 uses the minimum precision of the inputs.
  • Outputs:
    • J, a real interval,

Description

Returns the intersection of any number of input intervals.

i1 : intersect(interval(1,3),interval(2,4))

o1 = [2,3]

o1 : RRi (of precision 53)
 
i2 : intersect(interval(1,2+3*ii),interval(2*ii,3+2*ii))

o2 = [1,2]+[2,2]*ii

o2 : CCi (of precision 53)
