homomorphism' -- get the element of Hom from a homomorphism

  • Usage:
    homomorphism' f
  • Inputs:
    • f, a matrix, of the form $M \to N$
  • Optional inputs:
    • DegreeLimit => an integer or a list, default value null, see Hom(...,DegreeLimit=>...)
    • MinimalGenerators => a Boolean value, default value true, see Hom(...,MinimalGenerators=>...)
    • Strategy => a thing, default value null, see Hom(...,Strategy=>...)
  • Outputs:
    • a matrix, the map $R^1 \to \mathrm{Hom}(M,N)$, corresponding to the map $f \in \mathrm{Hom}(M,N)$
