ring(SimplicialModule) -- access the ring of a simplicial module or a simplicial module map

  • Function: ring
  • Usage:
    ring C
  • Inputs:
    • C, a Simplicial Module, or a SimplicialModuleMap
  • Outputs:
    • a ring,

Description

Every simplicial module or simplicial module map has a base ring. This function accesses that information.

i1 : S = ZZ/101[a,b,c,d];
 
i2 : C = simplicialModule freeResolution coker vars S

      1      5      15      35      70
o2 = S  <-- S  <-- S   <-- S   <-- S  <-- ...
                                    
     0      1      2       3       4

o2 : SimplicialModule
 
i3 : ring C

o3 = S

o3 : PolynomialRing
 
i4 : assert(ring C === S)
 
i5 : ring id_C

o5 = S

o5 : PolynomialRing
 
i6 : assert(ring id_C === S)
