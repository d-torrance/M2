simplicialModule(Module,ZZ) -- make a simplicial module associated to a complex concentrated in degree 0

  • Function: simplicialModule
  • Usage:
    simplicialModule(M, d)
  • Inputs:
    • M, a module, or Ideal, or Ring.
    • d, an integer, top degree to compute the simplicial module up to
  • Optional inputs:
    • Base (missing documentation) => ..., default value 0,
    • Degeneracy => ..., default value false, whether to compute degeneracy maps
  • Outputs:
    • a Simplicial Module, returns the complex whose 0-th component is M.

Description

In contrast to simplicialModule(HashTable,HashTable,HashTable,ZZ) or simplicialModule(Complex,ZZ), this constructor provides a convenient method to construct a simplicial module from a single module/ring/ideal.

We illustrate this with a free module.

o1 = S
