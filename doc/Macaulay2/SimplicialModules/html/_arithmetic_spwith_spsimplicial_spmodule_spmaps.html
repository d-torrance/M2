arithmetic with simplicial module maps -- perform arithmetic operations on simplicial module maps

  • Usage:
    f + g
    a + f
    f + a
    -f
    f - g
    a - f
    f - a
    a * f
  • Inputs:
    • f, a Map of Simplicial Modules,
    • g, a Map of Simplicial Modules,
    • a, a ring element, that is, an element in the underlying ring or a number
  • Outputs:
    • a Map of Simplicial Modules,

The set of simplicial module maps forms a module over the underlying ring. These methods implement the basic operations of addition, subtraction, and scalar multiplication.

i9 : isSimplicialMorphism oo

i11 : isSimplicialMorphism oo

o11 = true
 
i12 : -f;
 
i13 : 3*f;
 
i14 : 0*f

o14 : SimplicialModuleMap
 
i15 : a*f;
 
i16 : assert(0*f == 0)
 
i17 : assert(1*f == f)
 
i18 : assert((-1)*f == -f)
 
i19 : assert(-(f-g) == g-f)
 
i20 : assert((a+b)*f == a*f + b*f)
 
i21 : assert(a*(f+g) == a*f + a*g)
 
i22 : assert isSimplicialMorphism (f+g)

Adding or subtracting a scalar is the same as adding or subtracting the scalar multiple of the identity. In particular, the source and target must be equal.
