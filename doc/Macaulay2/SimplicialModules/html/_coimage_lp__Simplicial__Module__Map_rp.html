coimage(SimplicialModuleMap) -- make the coimage of a map of simplicial modules

  • Function: coimage
  • Usage:
    coimage f
  • Inputs:
    • f, a Map of Simplicial Modules,
  • Outputs:
    • a Simplicial Module,

Description

The coimage of a simplicial module map $f : C \to D$ is the simplicial module $E$ whose $i$-th term is $coimage(f_i)$, and whose face/degeneracy map is induced from the face/degeneracy map on the source.

In the following example, we first construct a random simplicial morphism $f : C \to D$.

Caveat

The coimage is more computationally intensive than image(SimplicialModuleMap) because, unlike image, it computes kernels of maps of modules.
