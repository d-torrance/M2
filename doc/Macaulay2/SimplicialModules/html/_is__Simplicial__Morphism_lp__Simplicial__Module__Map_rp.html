isSimplicialMorphism(SimplicialModuleMap) -- whether a simplicial module map is a morphism of simplicial modules

  • Function: isSimplicialMorphism
  • Usage:
    isSimplicialMorphism f
  • Inputs:
    • f, a Map of Simplicial Modules,
  • Outputs:
    • a Boolean value, that is true when $f$ commutes with the face/degeneracy maps and has degree $0$

Description

For a simplicial module map $f : C \to D$ of degree $d$, this method checks whether $d = 0$ and, for all $i$, we have $dd^D_{i+d} * f_i = f_{i-1} * dd^C_i$ and if the simplicial module also has degeneracy maps, it checks that $ss^D_{i} * f_i = f_{i+1} * ss^C_i$.

We first construct a random simplicial module morphism.

i1 : S = ZZ/101[a,b,c];
 
i2 : C = simplicialModule(freeResolution coker vars S, Degeneracy => true)

      1      4      10      20
o2 = S  <-- S  <-- S   <-- S  <-- ...
                            
     0      1      2       3

o2 : SimplicialModule
 
i3 : D = C ** C

      1      16      100      400
o3 = S  <-- S   <-- S    <-- S   <-- ...
                              
     0      1       2        3

o3 : SimplicialModule
 
i4 : f1 = randomSimplicialMap(D, C, Cycle => true, InternalDegree => 1);
 
i5 : isSimplicialMorphism f1

o5 = true
 
i6 : assert(degree f1 == 0)

i8 : isSimplicialMorphism f2

o8 = true
 
i9 : assert(degree f2 == 0)
 
i10 : assert isSimplicialMorphism f2
