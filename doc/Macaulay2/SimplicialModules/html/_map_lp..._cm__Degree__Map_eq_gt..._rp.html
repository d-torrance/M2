map(...,DegreeMap=>...) -- unused option for maps of simplicial modules

Description

This option is inherited from the core map method and is not used for maps of simplicial modules.

Functions with optional argument named DegreeMap:

  • map(...,DegreeMap=>...) -- see map(Ring,Ring,Matrix) -- make a ring map
  • monoid(...,DegreeMap=>...) -- see monoid(...,DegreeLift=>...) -- specify maps between degree groups
  • newRing(...,DegreeMap=>...) -- see newRing -- make a copy of a ring, with some features changed
  • symmetricAlgebra(...,DegreeMap=>...) -- see symmetricAlgebra -- the symmetric algebra of a module
  • tensor(Monoid,Monoid,DegreeMap=>...) -- see tensor(Monoid,Monoid) -- tensor product of monoids
  • tensor(Ring,Ring,DegreeMap=>...) -- see tensor(Monoid,Monoid) -- tensor product of monoids

Further information

  • Default value: null
  • Function: map -- make a map
  • Option key: DegreeMap -- an optional argument
