SimplicialModuleMap _ ZZ -- access individual matrices in a simplicial module map

  • Operator: _
  • Usage:
    f_i
  • Inputs:
    • f, a Map of Simplicial Modules,
    • i, an integer, the degree index or a sequence
  • Outputs:
    • a matrix, the i-th map

Description

A simplicial module map $f : C \to D$ of degree $d$ is a sequence of maps $f_i : C_i \to D_{i+d}$. This method allows one to access the individual $f_i$.

i1 : S = ZZ/101[a..c];
 
i2 : C = simplicialModule(freeResolution coker matrix{{a^2, b^2, c^2}}, Degeneracy => true)

      1      4      10      20
o2 = S  <-- S  <-- S   <-- S  <-- ...
                            
     0      1      2       3
