extPower -- compute the Dold-Puppe extension of the exterior power functor to simplicial modules

  • Usage:
    extPower(d, S, Options => {Degeneracy => false, TopDegree => null})
  • Inputs:
    • d, an integer, An integer representing the degree of the exterior power.
    • S, a Simplicial Module, A simplicial module to which the exterior power functor extension is applied.
  • Optional inputs:
    • Degeneracy => a Boolean value, default value false, Default value is false. Indicates whether to include degeneracy maps in the construction.
    • TopDegree => an integer, default value null, Default is null. If provided, specifies the top degree for the construction of the simplicial module.
  • Outputs:
    • a Simplicial Module, The Dold-Puppe extension of the exterior power functor applied to the simplicial module S.

Description

This function computes the Dold-Puppe extension of the exterior power functor to the category of chain complexes. It can be applied to a simplicial module, a complex, or maps thereof. This method is equivalent to using schurMap for the partition $(1, 1, \dots , 1)$, but is generally much faster.

Caveat

This method may take a very long time to run if the user inputs a large/long complex. Use the option TopDegree => d to only run the computation up to a certain degree.
