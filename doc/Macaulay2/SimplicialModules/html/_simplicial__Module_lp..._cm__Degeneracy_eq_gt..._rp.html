simplicialModule(...,Degeneracy=>...) -- whether to compute degeneracy maps

  • Usage:
    simplicialModule(..., Degeneracy => true)

Description

If Degeneracy => true, the degeneracy maps are also computed alongside the face maps. By default, degeneracy maps are not computed.

See also

  • simplicialModule -- make a simplicial module

Functions with optional argument named Degeneracy:

  • extPower(...,Degeneracy=>...) -- whether to compute degeneracy maps
  • schurMap(...,Degeneracy=>...) -- whether to compute degeneracy maps
  • simplicialModule(...,Degeneracy=>...) -- whether to compute degeneracy maps
  • simplicialTensor(...,Degeneracy=>...) -- whether to compute degeneracy maps

Further information

  • Default value: false
