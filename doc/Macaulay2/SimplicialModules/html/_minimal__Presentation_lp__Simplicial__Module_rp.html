minimalPresentation(SimplicialModule) -- minimal presentation of all terms in a simplicial module

  • Function: minimalPresentation
  • Usage:
    D = minimalPresentation C
    D = prune C
    h = minimalPresentation f
    h = prune f
  • Inputs:
    • C, a Simplicial Module, or $f$ a Map of Simplicial Modules
  • Optional inputs:
    • Exclude => ..., default value {}, unused
  • Outputs:
    • D, a Simplicial Module, isomorphic to the input, where each term is replaced by a minimally presented model, or $h$ a Map of Simplicial Modules where the source and target are minimally presented
  • Consequences:
    • The isomorphism $g : D \to C$ is available as g = D.cache.pruningMap. The inverse isomorphism can be obtained as g^-1

Description

This is frequently useful to make the output of certain operations readable or understandable. This operation is functorial, applying both to simplicial modules and simplicial module maps.

In particular, images/kernels/cokernels of maps need to be pruned to be understood. For instance, this is useful for recognizing when terms given by subquotient modules are actually zero.
