inducedMap(SimplicialModule,SimplicialModule) -- make the map of simplicial modules induced at each term by the identity map

  • Function: inducedMap
  • Usage:
    f = inducedMap(D, C)
  • Inputs:
    • C, a Simplicial Module,
    • D, a Simplicial Module,
  • Optional inputs:
    • Degree => ..., default value null, specify the degree of an induced map of simplicial modules
    • Verify => ..., default value true,
  • Outputs:
    • f, a Map of Simplicial Modules,

Description

Let $d$ be the value of the optional argument Degree, or zero, if not given. For each $i$, the terms $D_{i+d}$ and $C_i$ must be subquotients of the same ambient free module. This method returns the simplicial module map induced by the identity on each of these free modules.

If Verify => true is given, then this method also checks that these identity maps induce well-defined maps. This can be a relatively expensive computation.

We illustrate this method by truncating a free resolution at two distinct internal degrees. We check that the various induced maps compose to give another induced map.
