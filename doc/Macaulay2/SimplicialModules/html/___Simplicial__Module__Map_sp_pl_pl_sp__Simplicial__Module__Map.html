SimplicialModuleMap ++ SimplicialModuleMap -- direct sum of simplicial module maps

  • Operator: ++
  • Usage:
    h = f ++ g
    h = directSum(f,g,...)
    h = directSum(name1 => f, name2 => g, ...)
  • Inputs:
    • f, a Map of Simplicial Modules,
    • g, a Map of Simplicial Modules,
  • Outputs:
    • h, a Map of Simplicial Modules, that is the direct sum of the input simplicial module maps

Description

The direct sum of two simplicial module maps is a simplicial module map from the direct sum of the sources to the direct sum of the targets.

First, we define some non-trivial maps of simplicial modules.

i1 : R = ZZ/101[a..d];
 
i2 : C1 = simplicialModule((freeResolution coker matrix{{a,b,c}})[1], Degeneracy => true)

      3      6      10
o2 = R  <-- R  <-- R  <-- ...
                    
     0      1      2
