SimplicialModule == SimplicialModule -- whether two simplicial modules are equal

  • Operator: ==
  • Usage:
    C == D
    C == 0
  • Inputs:
    • C, a Simplicial Module,
    • D, a Simplicial Module,
  • Outputs:
    • a Boolean value, that is true when C and D are equal
