randomSimplicialMap(SimplicialModule,SimplicialModule) -- a random map of simplicial modules

  • Function: randomSimplicialMap
  • Usage:
    f = randomSimplicialMap(C,D)
  • Inputs:
    • C, a Simplicial Module,
    • D, a Simplicial Module,
  • Optional inputs:
    • Boundary => a Boolean value, default value false, whether the constructed f is a simplicial null homotopy
    • Cycle => a Boolean value, default value false, whether the constructed f commutes with the face/degeneracy maps
    • Degree => an integer, default value 0, the degree of the constructed map of simplicial modules
    • InternalDegree => a list, default value null, or an integer
  • Outputs:
    • f, a Map of Simplicial Modules,

Description

A random simplicial module map $f : C \to D$ is obtained from choosing a random map of the underlying normalizations, which uses the randomComplexMap command.

When the degree of the random element is chosen with a specific degree, the associated map of simplicial modules will be a well-defined degree 0 simplicial morphism mapping to the Dold-Kan image of the shift of the normalization. Thus, even when specifying nonzero degree this constructor will still yield a simplicial morphism.
