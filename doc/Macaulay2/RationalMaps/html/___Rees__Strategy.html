ReesStrategy -- a strategy for determining whether a map is birational and computing its inverse

Description

ReesStrategy is a valid value for the Strategy Option for inverseOfMap, isBirationalMap, and isEmbedding. By choosing Strategy=>ReesStrategy, the ideal of definition of the Rees algebra is computed by the known elimination technique. This technique is described in Proposition 1.5 on page 21 in the book

  • Vasconcelos, Wolmer. Integral closure. Springer Monographs in Mathematics. Springer-Verlag, Berlin,2005. xii+519 pp.
