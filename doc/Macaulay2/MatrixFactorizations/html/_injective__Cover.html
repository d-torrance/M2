injectiveCover -- Constructs the injective hull of a d-fold matrix factorization

  • Usage:
    injectiveCover(C)
  • Inputs:
    • C, a ZZ/d graded factorization, A ZZdFactorization object representing a d-fold matrix factorization
  • Outputs:
    • a map of ZZ/d-graded factorizations,

Description

This method constructs the injective cover of a d-fold matrix factorization. The output is a ZZdFactorizationMap, which is the canonical injection from the original factorization into the injective cover.

In this case, using the cokernel into the injective cover gives a factorization that is directly equal to the shift of a 2-periodic factorization. In general the cokernel of this inclusion natural defines a suspension functor on the category of d-fold factorizations.
