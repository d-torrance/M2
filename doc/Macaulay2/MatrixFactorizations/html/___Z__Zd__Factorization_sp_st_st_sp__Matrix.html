ZZdFactorization ** Matrix -- create the tensor product of a ZZ/d-graded factorization and a map of modules

  • Operator: **
  • Usage:
    h = C ** f
    h = f ** C
  • Inputs:
    • C, a ZZ/d graded factorization, over a ring $R$
    • f, a matrix, defining a homomorphism from the $R$-module $M$ to the $R$-module $N$
  • Outputs:
    • h, a map of ZZ/d-graded factorizations, from $C \otimes M$ to $C \otimes N$

Description

For any ZZ/d-graded factorization map $C$, a map $f \colon M \to N$ of $R$-modules induces a morphism $C \otimes f$ of ZZ/d-graded factorizations from $C \otimes M$ to $C \otimes N$. This method returns this map of factorizations.
