RingMap ZZdFactorizationMap -- apply a ring map to a map of ZZ/d-graded factorizations

  • Operator: SPACE
  • Usage:
    phi f
  • Inputs:
    • phi, a ring map, whose source is a ring $R$, and whose target is a ring $S$
    • f, a map of ZZ/d-graded factorizations, over the ring $R$
  • Outputs:
    • a map of ZZ/d-graded factorizations, over the ring $S$

Description

We illustrate the image of a ZZ/d-graded factorization map along a ring map.

i1 : R = QQ[x,y,z]

o1 = R

o1 : PolynomialRing
 
i2 : S = QQ[s,t]

o2 = S

i3 : phi = map(S, R, {s, s+t, t})

o3 = map (S, R, {s, s + t, t})

o3 : RingMap S <-- R
 
i4 : Rf = R/(x^3+y^3+z^3)

o4 = Rf
