ZZdFactorizationMap _ ZZ -- access individual matrices in a ZZ/d-graded factorization map

  • Operator: _
  • Usage:
    f_i
  • Inputs:
    • f, a map of ZZ/d-graded factorizations,
    • i, an integer, the homological index
  • Outputs:
    • a matrix, the i-th map

Description

A ZZ/d-graded factorization map $f : C \to D$ of degree $d$ is a sequence of maps $f_i : C_i \to D_{i+d}$. This method allows one to access the individual $f_i$.
