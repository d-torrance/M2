isQuasiIsomorphism(ZZdFactorizationMap) -- whether a map of ZZ/d-graded factorizations is a quasi-isomorphism

  • Function: isQuasiIsomorphism
  • Usage:
    isQuasiIsomorphism f
  • Inputs:
    • f, a map of ZZ/d-graded factorizations,
  • Optional inputs:
    • Concentration => ..., default value (-infinity,infinity),
  • Outputs:
    • a Boolean value, that is true when $f$ is a morphism of ZZ/d-graded factorizations such that the induced maps on homology are all isomorphisms

Description

The cone of a map $f \colon C \to D$ is acyclic exactly when $f$ is a quasi-isomorphism.
