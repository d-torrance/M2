mooreMF -- Constructs the matrix factorization of the Moore matrix and its adjoint

  • Usage:
    mooreMF(p)
  • Inputs:
    • p, an integer, The characteristic of the underlying field (p = 0 for rational coefficients)
  • Outputs:
    • a ZZ/d graded factorization, The Moore matrix factorization

Description

This method constructs the Moore matrix factorization corresponding in some characteristic specified by the integer p.
