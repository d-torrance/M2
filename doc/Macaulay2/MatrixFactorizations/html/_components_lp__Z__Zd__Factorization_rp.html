components(ZZdFactorization) -- list the components of a direct sum

  • Function: components
  • Usage:
    components C
  • Inputs:
    • C, a ZZ/d graded factorization,
  • Outputs:
    • a list, the component factorizations of a direct sum (of ZZ/d-graded factorizations)

Description

A ZZ/d-graded factorization which has been constructed as a direct sum stores its component factorizations.

i1 : S = ZZ/101[a,b,c];
 
i2 : f = a^3 + b^3 + c^3;
 
i3 : C1 = randomTailMF(f)

o3 = S  <-- S  <-- S
                    
     0      1      0

o3 : ZZdFactorization

o4 = S   <-- S   <-- S
                      
     0       1       0

o4 : ZZdFactorization
 
i5 : D = C1 ++ C2

      18      18      18

     0       1       0

o5 : ZZdFactorization
 
i6 : L = components D

o6 = {S  <-- S  <-- S , S   <-- S   <-- S  }
                                         
      0      1      0   0       1       0

i7 : L_0 === C1

o7 = true
