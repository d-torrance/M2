dual(ZZdFactorizationMap,RingElement) -- the dual of a map of ZZ/d-graded factorizations

  • Function: dual
  • Usage:
    h = dual(f,t)
  • Inputs:
    • f, a map of ZZ/d-graded factorizations,
    • t, a ring element, optional input specifying the symbol used to represent the distinguished root of unity, required only if the underlying ring does not have a specified root of unity and the period is > 2
  • Outputs:
    • h, a map of ZZ/d-graded factorizations,

Description

The map $f : C \to D$ of ZZ/d-graded factorizations over the ring $S$ induces the map $h = Hom(f, S^1) : Hom(D, S^1) \to Hom(C,S^1)$ defined by $\phi \mapsto \phi f$. If the period of the factorization is >2, then there must be a root of unity adjoined in order for the dual to be defined.

The dual is a factorization of the negative of the potential.
