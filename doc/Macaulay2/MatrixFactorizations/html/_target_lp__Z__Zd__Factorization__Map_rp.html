target(ZZdFactorizationMap) -- get the target of a map of ZZ/d-graded factorizations

  • Function: target
  • Usage:
    C = target f
  • Inputs:
    • f, a map of ZZ/d-graded factorizations,
  • Outputs:
    • C, a ZZ/d graded factorization,

Description

Given a ZZ/d-graded factorization map $f : C \to D$ this method returns the ZZ/d-graded factorization $D$.
