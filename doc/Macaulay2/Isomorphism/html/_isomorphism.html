isomorphism -- retrieve an isomorphism of modules

  • Usage:
    f = isomorphism(N, M)
  • Inputs:
    • M, a module,
    • N, a module,
  • Optional inputs:
    • Homogeneous => a Boolean value, default value true, if false, allow an inhomogeneous isomorphism;
    • Verbose => a Boolean value, default value false, whether to print debugging information;
    • Strict => a Boolean value, default value false, whether to force strict equality of degrees;
    • Tries => an integer, default value null, the number of attempts at generating random map;
    • Strategy (missing documentation) => ..., default value null,
  • Outputs:
    • f, a matrix, an isomorphism $M \to N$;

Description

This method retrieves the isomorphism between the given modules. Note that this isomorphism is already cached if a previous call to isIsomorphic returned true, but otherwise that function is called.
