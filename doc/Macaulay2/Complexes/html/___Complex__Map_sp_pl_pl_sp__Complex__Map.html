ComplexMap ++ ComplexMap -- direct sum of complex maps

  • Operator: ++
  • Usage:
    h = f ++ g
    h = directSum(f,g,...)
    h = directSum(name1 => f, name2 => g, ...)
  • Inputs:
    • f, a map of complexes,
    • g, a map of complexes,
  • Outputs:
    • h, a map of complexes, that is the direct sum of the input chain complex maps

Description

The direct sum of two complex maps is a a complex map from the direct sum of the sources to the direct sum of the targets.

First, we define some non-trivial maps of chain complexes.

i18 : h_[1]^[0] == 0

i19 : h_[0] == h * (C1 ++ C2)_[0]

o19 = true
 
i20 : h_[1] == h * (C1 ++ C2)_[1]

o20 = true
 
i21 : h^[0] == (D1 ++ D2)^[0] * h

i22 : h^[1] == (D1 ++ D2)^[1] * h
