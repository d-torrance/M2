PolynomialSet -- a set of polynomials for an evaluation code

  • Usage:
    C.PolynomialSet
  • Inputs:
    • C, an instance of the type EvaluationCode,
  • Outputs:
    • a set,

Description

This key stores a polynomial set used to construct an EvaluationCode.

This symbol is provided by the package CodingTheory.

i1 : F=GF(4,Variable=>a);
 
i2 : R=F[x,y];
 
i3 : P={{0,0},{1,0},{0,1},{a,a}};
 
i4 : S={x+y,x^2+y^2,a+x*y^2};
 
i5 : C=evaluationCode(F,P,S);
 
i6 : C.PolynomialSet

              2    2     2
o6 = {x + y, x  + y , x*y  + a}
