FlagBundle -- the class of all flag bundles

  • abstractProjectiveSpace -- make a projective space
  • abstractProjectiveSpace' -- make a projective space
  • flagBundle -- make a flag bundle
  • projectiveBundle -- make a projective bundle from an abstract sheaf
  • projectiveBundle' -- make a projective bundle from an abstract sheaf
