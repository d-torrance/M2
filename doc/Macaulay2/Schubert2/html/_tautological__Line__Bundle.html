tautologicalLineBundle -- get the tautological line bundle of a flag bundle or abstract variety

  • Usage:
    tautologicalLineBundle X

Description

Returns the tautological line bundle of the variety $X$. In the case of a FlagBundle, this is the line bundle defining the Pl\"ucker embedding.

Used in AbstractSheaf ZZ.
