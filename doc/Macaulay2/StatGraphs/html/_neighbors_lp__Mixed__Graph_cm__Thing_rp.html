neighbors(MixedGraph,Thing) -- return the neighbors of a vertex of a mixed graph

  • Function: neighbors
  • Usage:
    neighbors (G,v)
    neighbors (G,v)
  • Inputs:
    • G, an instance of the type MixedGraph,
    • v, a thing, a vertex of G
  • Outputs:
    • a set,

Description

The neighbors of v are the all the vertices u such that u,v is an undirected edge in G.

i1 : G = mixedGraph(graph{{3,1}},digraph {{1,2},{2,3}},bigraph {{3,4},{2,4}})

o1 = MixedGraph{Bigraph => Bigraph{2 => {4}   }}
                                   3 => {4}
                                   4 => {3, 2}
                Digraph => Digraph{1 => {2}}
                                   2 => {3}
                                   3 => {}
                Graph => Graph{1 => {3}}
                               3 => {1}

o1 : MixedGraph
 
i2 : neighbors (G,1)

o2 = set {3}

i3 : neighbors (G,2)
