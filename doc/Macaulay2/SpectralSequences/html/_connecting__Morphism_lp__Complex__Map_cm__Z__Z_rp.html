connectingMorphism(ComplexMap,ZZ) -- use spectral sequences to compute connecting morphisms

  • Function: connectingMorphism
  • Usage:
    g = connectingMorphism(f, n)
  • Inputs:
    • f, a map of complexes,
    • n, an integer,
  • Outputs:
    • g, a matrix,

Description

Given a morphism $f: A \rightarrow B$ of chain complexes returns the connecting map $H_{n+1}(coker f) \rightarrow H_n (im f)$.

Ways to use this method:

  • connectingMorphism(ComplexMap,ZZ) -- use spectral sequences to compute connecting morphisms
