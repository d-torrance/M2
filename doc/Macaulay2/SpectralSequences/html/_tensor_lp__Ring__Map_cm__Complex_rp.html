tensor(RingMap,Complex) -- tensor product of a chain complex by a ring map

  • Function: tensor
  • Usage:
    D = tensor(f,C)
  • Inputs:
    • f, a ring map,
    • C, a complex,
  • Outputs:
    • D, a complex,

Description

Given a ring map R -> S and a chain complex over R, returns the tensor product of the given chain complex.

i1 : R = QQ[x];
 
i2 : M = R^1/(x^2);
 
i3 : S = R/(x^4);
 
i4 : C = freeResolution M
