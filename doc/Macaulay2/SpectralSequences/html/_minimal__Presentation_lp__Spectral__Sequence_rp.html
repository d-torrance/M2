minimalPresentation(SpectralSequence) -- a minimal presentation of a spectral sequence

  • Function: minimalPresentation
  • Usage:
    E = minimalPresentation e
  • Inputs:
    • e, a spectral sequence,
  • Optional inputs:
    • Exclude => ..., default value {},
  • Outputs:
    • E, a spectral sequence,

Description

Returns the minimal presentation of a spectral sequence.

If we fail to prune a spectral sequence then the out-put can be highly unintelligible.

As a specific example consider the filtered complex $K$ below, obtained by multiplying the minimal free resolution of the rational quartic space curve by successive powers of the irrelevant ideal.

i1 : B = QQ[a..d];
 
i2 : J = ideal vars B;

o2 : Ideal of B
 
i3 : C = freeResolution monomialCurveIdeal(B,{1,3,4});
 
i4 : K = filteredComplex(J,C,4);

Compare some pages of the non-pruned version of the spectral sequence with that of the pruned version.

i5 : E = prune spectralSequence K;
 
i6 : e = spectralSequence K;
