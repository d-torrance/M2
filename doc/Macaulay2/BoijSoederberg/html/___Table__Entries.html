TableEntries -- Set the convention for what kind of pure Betti diagrams to use in a decomposition.

Description

The possible options are LeastIntegerEntries, HerzogKuhl, and RealizationModules.

See also

  • decomposeBetti -- write a Betti diagram as a positive combination of pure integral diagrams

  • decomposeBetti(...,TableEntries=>...) -- see decomposeBetti -- write a Betti diagram as a positive combination of pure integral diagrams
  • decomposeDegrees(...,TableEntries=>...) (missing documentation)
  • makePureBetti(...,TableEntries=>...) -- see makePureBetti(List) -- list of Betti numbers corresponding to a degree sequence
  • makePureBettiDiagram(...,TableEntries=>...) -- see makePureBettiDiagram -- makes a pure Betti diagram given a list of degrees
