pureBettiDiagram(List) -- pure Betti diagram given a list of degrees

  • Function: pureBettiDiagram
  • Usage:
    pureBettiDiagram L
  • Inputs:
    • L, a list, of strictly increasing integers
  • Outputs:
    • a Betti tally, containing the minimal integral Betti numbers which satisfy the Herzog-Kuhl equations

Description

See pureBetti for a description of the Herzog-Kuhl equations.
