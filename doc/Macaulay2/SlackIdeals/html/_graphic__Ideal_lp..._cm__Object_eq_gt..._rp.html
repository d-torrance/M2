graphicIdeal(...,Object=>...) -- specify combinatorial object

  • Usage:
    slackMatrix(..., Object => "polytope")
    slackMatrix(..., Object => "abstractPolytope")

Description

Indicates whether an input list should be treated as the vertices of a polytope or the facets of an abstract polytope.
