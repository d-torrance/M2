Total -- option for approximation

  • Usage:
    approximation(M, Total =>t)
  • Inputs:
    • M, a module,
    • t, a Boolean value,

Description

If t != true then return only the map from the non-free part of the MCM approximation Otherwise, return the pair of maps that defines the MCM approximation. Default is t ==true.

See also

  • approximation -- returns pair of components of the map from the MCM approximation
  • auslanderInvariant -- measures failure of surjectivity of the essential MCM approximation
  • CoDepth -- Option for syzygyModule(-k,M,CoDepth => m)

Functions with optional argument named Total:

  • approximation(...,Total=>...) -- see approximation -- returns pair of components of the map from the MCM approximation
  • coApproximation(...,Total=>...) -- see coApproximation -- Maximal Cohen-Macaulay co-approximation of M
