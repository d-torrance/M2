isWellDefined(DGSubmodule) -- Check that a DG submodule is d-closed in its ambient DG module

  • Function: isWellDefined
  • Usage:
    b = isWellDefined S
  • Inputs:
    • S, an instance of the type DGSubmodule,
  • Outputs:
    • b, a Boolean value, True when S has all expected structural keys, its ambient is a well-defined DG module, and the column span of S.inclusion.natural in S.ambient.natural is stable under d_{S.ambient}.

Description

After a structural key check, verifies that S.ambient is a well-defined DG module, then checks d-closure: for every column v of the inclusion matrix, d_M(v) lies in the column span of the inclusion matrix modulo further columns. This is the one nontrivial condition that distinguishes a DG submodule from a general A.natural-submodule of M.natural.
