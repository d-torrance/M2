getGenerators(...,Verbosity=>...) -- Option to control progress output from getGenerators

  • Usage:
    getGenerators(...,Verbosity=>n)

Description

Larger values of n print progress messages about the cycle enumeration and independence checks in getGenerators. The default is 0 (no output).
