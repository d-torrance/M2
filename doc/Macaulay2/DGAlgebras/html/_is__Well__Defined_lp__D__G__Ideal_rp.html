isWellDefined(DGIdeal) -- Verify that a DGIdeal has correct structure and is d-closed

  • Function: isWellDefined
  • Usage:
    b = isWellDefined I
  • Inputs:
    • I, an instance of the type DGIdeal,
  • Outputs:
    • b, a Boolean value,

Description

Performs (1) a key-shape check — the expected fields (dgAlgebra, ring, natural, generators, cache) are present and have the correct types — and (2) the semantic d-closure check via isDGIdeal. Set debugLevel > 0 to see a diagnostic message on failure.

i1 : R = ZZ/101[x, y]

o1 = R

o1 : PolynomialRing
 
i2 : A = koszulComplexDGA R

o2 = {Ring => R                          }
      Underlying algebra => R[T   ..T   ]
                               1,1   1,2
      Differential => {x, y}

o2 : DGAlgebra
 
i3 : Anat = A.natural

o3 = Anat

o3 : PolynomialRing, 2 skew commutative variable(s)
 
i4 : I = dgIdeal(A, {x_Anat, y_Anat})

o4 = DGIdeal of Anat
     generators => | y x |

o4 : DGIdeal
 
i5 : isWellDefined I

o5 = true
