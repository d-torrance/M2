RelDegreeLimit -- Option to bound the homological degree searched for algebra relations

  • Usage:
    homologyAlgebra(..., RelDegreeLimit => n)
    torAlgebra(..., RelDegreeLimit => n)

Description

Once generators have been chosen (see GenDegreeLimit), a homology algebra computation must determine relations among them. RelDegreeLimit bounds the homological degree up to which those relations are searched. Typical practice is to set RelDegreeLimit to roughly twice GenDegreeLimit, since relations can be degree-sums of generator pairs.
