killCycles(...,Variable=>...) -- Option to name the DG algebra generators adjoined by killCycles

  • Usage:
    killCycles(..., Variable => "T")

Description

killCycles adjoins new DG generators that become boundaries of previously non-bounding cycles. The Variable option specifies the base name used for these new generators, so that subsequent calls produce readable and non-colliding names.
