DGAlgebraMap * DGAlgebraMap -- Composition of DG algebra maps

  • Operator: *
  • Usage:
    h = g * f
  • Inputs:
    • g, an instance of the type DGAlgebraMap, A map with source = target of f.
    • f, an instance of the type DGAlgebraMap,
  • Outputs:
    • h, an instance of the type DGAlgebraMap, The composite DGAlgebraMap whose underlying RingMap is g.natural * f.natural.
