displayModuleBlockDiff -- Pretty-print the labeled block matrix of a DG module differential

  • Usage:
    tab = displayModuleBlockDiff(M, n)
    entry = displayModuleBlockDiff(M, srcLbl, tgtLbl)
  • Inputs:
    • M, an instance of the type DGModule, A DG module; must be free.
    • n, an integer, A hom-degree.
    • srcLbl, a list, A pair {i, v} identifying a single source block (a generator index and a chunk-degree vector).
    • tgtLbl, a list, A pair {j, w} identifying a single target block.
  • Outputs:
    • tab, a net, A centered table whose first row lists source labels and whose first column lists target labels; inner entries are the corresponding blocks of moduleBlockDiff(M, n).
    • entry, a matrix, In the three-argument form, returns the single block b^[tgtLbl]_[srcLbl] extracted from the labeled block matrix.

Description

The two-argument form lays out moduleBlockDiff as a labeled table, parallel to displayBlockDiff for DG algebras. The three-argument form bypasses the table and returns a single block directly, which is handy for programmatic inspection.
