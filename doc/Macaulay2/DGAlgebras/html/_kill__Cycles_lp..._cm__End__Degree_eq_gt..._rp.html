killCycles(...,EndDegree=>...) -- Last homological degree processed by killCycles

  • Usage:
    killCycles(..., EndDegree => n)

Description

Bounds the search depth of killCycles. By default EndDegree => -1 tells killCycles to stop after processing the first degree with nontrivial homology. See EndDegree.
