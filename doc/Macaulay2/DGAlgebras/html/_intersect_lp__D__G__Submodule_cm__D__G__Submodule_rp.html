intersect(DGSubmodule,DGSubmodule) -- Intersection of two DG submodules of a common ambient

  • Function: intersect
  • Usage:
    U = intersect(S, T)
  • Inputs:
    • S, an instance of the type DGSubmodule,
    • T, an instance of the type DGSubmodule, With S.ambient === T.ambient.
  • Outputs:
    • U, an instance of the type DGSubmodule, The DGSubmodule of S.ambient whose image is image(S.inclusion.natural) \cap image(T.inclusion.natural).

Description

Preserves d-closure directly. Intersecting with the zero submodule yields the zero submodule; intersecting with the same submodule is idempotent (intersect(S, S) == S as submodules).
