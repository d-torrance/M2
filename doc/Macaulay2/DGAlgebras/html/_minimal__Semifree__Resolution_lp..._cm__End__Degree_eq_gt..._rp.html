minimalSemifreeResolution(...,EndDegree=>...) -- Option to specify the last degree at which minimalSemifreeResolution kills cycles

  • Usage:
    minimalSemifreeResolution(..., EndDegree => n)

Description

Controls the last hom-degree at which minimalSemifreeResolution iterates killCycles(DGModule). Homology of the output in the range [StartDegree, EndDegree] vanishes. The default is 3.
