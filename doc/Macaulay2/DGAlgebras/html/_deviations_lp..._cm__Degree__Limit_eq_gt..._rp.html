deviations(...,DegreeLimit=>...) -- Maximum homological degree to which deviations are computed

  • Usage:
    deviations(..., DegreeLimit => n)

Description

Bounds the homological degree of generators reported by deviations. The default value is 3.

See also

  • deviations -- Computes the deviations of the input ring, complex, or power series.
  • deviationsToPoincare -- Computes the power series corresponding to a set of deviations.
