target(DGAlgebraMap) -- The target of a DG algebra map

  • Function: target
  • Usage:
    B = target phi
  • Inputs:
    • phi, an instance of the type DGAlgebraMap,
  • Outputs:
    • B, an instance of the type DGAlgebra, the target DG algebra of phi

Description

Returns the DGAlgebra into which phi maps.
