getBoundaryPreimage(DGModule,List) -- Lift a list of boundaries sharing a hom-degree through the module differential

  • Function: getBoundaryPreimage
  • Usage:
    (lifted, lifts) = getBoundaryPreimage(M, boundaryList)
  • Inputs:
    • M, an instance of the type DGModule, A free DG module over a DGAlgebra.
    • boundaryList, a list, A list of elements of M.natural, each either 0 or homogeneous of a common hom-degree.
  • Outputs:
    • seq, a sequence, A pair (lifted, lifts). If lifted is true, then lifts#i satisfies d_M(lifts#i) = boundaryList#i for every i; otherwise lifts is the list of per-entry residues.

Description

The list form of getBoundaryPreimage(DGModule,Vector) solves multiple preimage problems in a single // call. Zero entries are permitted and contribute zero columns; all nonzero entries must share a hom-degree. When every boundary lifts, the returned list preserves the order of boundaryList.
