getBasis(ZZ,DGModule) -- Basis of the hom-degree-n piece of a DG module

  • Function: getBasis
  • Usage:
    b = getBasis(n, M)
  • Inputs:
    • n, an integer, A homological degree.
    • M, an instance of the type DGModule,
  • Optional inputs:
    • Limit => ..., default value -1, Maximum number of basis elements to return from getBasis
  • Outputs:
    • b, a matrix, A one-row matrix over M.natural whose entries are the basis elements of F_n(M), the hom-degree-n piece of M.natural over A.ring.

Description

getBasis(n, M) delegates to basis on the underlying A.natural-module M.natural, restricting to the variables of A.natural. The result is the piece of M on which moduleDifferential(n, M) acts as its source-side basis.
