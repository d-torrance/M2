StartDegree -- Option to specify the first homological degree processed by an iterative DG construction

  • Usage:
    acyclicClosure(..., StartDegree => n)
    killCycles(..., StartDegree => n)
    getGenerators(..., StartDegree => n)

Description

Several routines in this package build DG algebras one homological degree at a time, starting from degree StartDegree and incrementing up to an appropriate endpoint. Raising StartDegree can be useful when a partial acyclic closure has already been cached and you wish to continue the construction from where it left off. The default value is 1.

See also

  • EndDegree -- Option to specify the last homological degree processed by an iterative DG construction
  • acyclicClosure -- Tate's construction of a semifree acyclic DG algebra extension
  • killCycles -- Adjoin variables to kill non-bounding cycles in the lowest positive degree
  • getGenerators -- Cycles whose classes generate the homology algebra of a DG algebra

Functions with optional argument named StartDegree:

  • acyclicClosure(...,StartDegree=>...) -- Option to specify the degree to start computing the acyclic closure.
  • getGenerators(...,StartDegree=>...) -- First homological degree in which to search for new algebra generators
  • killCycles(...,StartDegree=>...) -- First homological degree from which killCycles begins searching for cycles
  • minimalModel(...,StartDegree=>...) -- see minimalModel -- Build the minimal DG algebra resolution of a quotient ring
  • minimalSemifreeResolution(...,StartDegree=>...) -- Option to specify the degree at which minimalSemifreeResolution starts killing cycles
  • semifreeResolution(...,StartDegree=>...) -- Option to specify the degree at which semifreeResolution starts killing cycles
