getGenerators(...,StartDegree=>...) -- First homological degree in which to search for new algebra generators

  • Usage:
    getGenerators(..., StartDegree => n)

Description

Degrees below n are skipped when walking getGenerators up through the DG algebra. Raising StartDegree is useful when earlier degrees have been inspected separately. See StartDegree.
