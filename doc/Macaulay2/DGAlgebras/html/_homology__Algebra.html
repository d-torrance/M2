homologyAlgebra -- Compute the homology algebra of a DGAlgebra.

  • Usage:
    HA = homologyAlgebra(A)
  • Inputs:
    • A, an instance of the type DGAlgebra,
  • Optional inputs:
    • GenDegreeLimit => ..., default value infinity, Maximum homological degree searched for homology-algebra generators
    • RelDegreeLimit => ..., default value infinity, Maximum homological degree searched for homology-algebra relations
    • Verbosity => ..., default value 0, Option to control progress output from homologyAlgebra
  • Outputs:
    • HA, a ring,

Description

One can check that HA has Poincare duality since R is Gorenstein.

If your DGAlgebra has generators in even degrees, then one must specify the options GenDegreeLimit and RelDegreeLimit.
