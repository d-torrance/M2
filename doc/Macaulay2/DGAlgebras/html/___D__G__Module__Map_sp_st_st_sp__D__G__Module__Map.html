DGModuleMap ** DGModuleMap -- Tensor product of DG module maps

  • Operator: **
  • Usage:
    h = F ** G
  • Inputs:
    • F, an instance of the type DGModuleMap, M -> M'
    • G, an instance of the type DGModuleMap, N -> N'
  • Outputs:
    • h, an instance of the type DGModuleMap, The map M ** N -> M' ** N' acting by F on the first factor and G on the second factor.

Description

Functorial: idM ** idN equals identityDGModuleMap(M ** N), and tensor with a zero map is a zero map.
