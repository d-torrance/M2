HH DGAlgebraMap -- The induced ring map on homology algebras

  • Function: homology
  • Usage:
    homologyPhi = homology phi
    homologyPhi = HH phi
  • Inputs:
    • phi, an instance of the type DGAlgebraMap,
  • Outputs:
    • homologyPhi, a ring map, the induced map HH(source phi) -> HH(target phi)

Description

A DGAlgebraMap phi: A -> B is a chain map, so it descends to a ring map on homology algebras. This function computes that induced map, returning a RingMap from homologyAlgebra of the source to homologyAlgebra of the target. The homology algebras are computed via homologyAlgebra if they have not been cached.
