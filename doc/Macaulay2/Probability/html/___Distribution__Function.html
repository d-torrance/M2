DistributionFunction -- cumulative distribution function

Description

A key in ProbabilityDistribution objects and an option for discreteProbabilityDistribution and continuousProbabilityDistribution for setting the cumulative distribution function to be used by probability.

Menu

  • probability -- cumulative distribution function

Functions with optional argument named DistributionFunction:

  • continuousProbabilityDistribution(...,DistributionFunction=>...) -- see continuousProbabilityDistribution -- construct a continuous probability distribution
  • discreteProbabilityDistribution(...,DistributionFunction=>...) -- see discreteProbabilityDistribution -- construct a discrete probability distribution

For the programmer

The object DistributionFunction is a symbol.
