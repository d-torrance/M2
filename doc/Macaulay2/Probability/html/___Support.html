Support -- support for probability distribution

Description

A key in ProbabilityDistribution objects and an option for discreteProbabilityDistribution and continuousProbabilityDistribution for setting the support of the probability distribution.

Functions with optional argument named Support:

  • continuousProbabilityDistribution(...,Support=>...) -- see continuousProbabilityDistribution -- construct a continuous probability distribution
  • discreteProbabilityDistribution(...,Support=>...) -- see discreteProbabilityDistribution -- construct a discrete probability distribution

For the programmer

The object Support is a symbol.
