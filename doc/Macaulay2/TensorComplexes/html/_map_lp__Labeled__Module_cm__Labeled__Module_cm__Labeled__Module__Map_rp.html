map(LabeledModule,LabeledModule,LabeledModuleMap) -- creates a new LabeledModuleMap from a given LabeledModuleMap

  • Function: map
  • Usage:
    map(F,G,f)
  • Inputs:
    • F, a free module with labeled basis,
    • G, a free module with labeled basis,
    • f, a map of labeled modules,
  • Optional inputs:
    • Degree => ..., default value null,
    • DegreeLift => ..., default value null,
    • DegreeMap => ..., default value null,
  • Outputs:
    • a map of labeled modules,

Description

This function produces has the same output map(F,G,matrix f). This function is most useful when the either source/target of $f$ is isomorphic to $F/G$ as a module with basis, but not as a labeled module.
