CT -- cotangent cohomology

Description

CT is a scripted functor providing an interface for cotangent cohomology calculations. CT^1 is equivalent to cotangentCohomology1 and CT^2 is equivalent to cotangentCohomology2.

For the programmer

The object CT is a scripted functor.
