versalDeformation(NestedDeformation) -- continues calculation of a versal deformation

  • Function: versalDeformation
  • Usage:
    E = versalDeformation(D)
  • Inputs:
    • D, an instance of the type NestedDeformation
  • Optional inputs:
    • DegreeBound => ..., default value 0, determines the degree limit used to compute the tangent cone of obstruction equations
    • HighestOrder => ..., default value 20, sets the order to which we compute
    • PolynomialCheck => ..., default value true, checks if power series solution terminates
    • SanityCheck => ..., default value true, checks if lifting solves deformation equation
    • Verbose => ..., default value 0, control the verbosity of output
  • Outputs:
    • E, an instance of the type NestedDeformation

Description

This method iteratively lifts a NestedDeformation D to higher and higher order.

For example, consider embedded deformations of the fat points in the plane defined by the square and cube of the homogeneous maximal ideal. The following lifts a first order NestedDeformation for this pair to higher order:

i1 : R=QQ[x,y];
 
i2 : F0Y=basis(3,R);

             1      4
o2 : Matrix R  <-- R
 
i3 : F0X=basis(2,R);

             1      3
o3 : Matrix R  <-- R
 
i4 : T1Y=normalMatrix(F0Y);

             4      12
o4 : Matrix R  <-- R
 
i5 : T1X=normalMatrix(F0X);

             3      6

i6 : T2X=CT^2(F0X);

             2      1

             3      3
o7 : Matrix R  <-- R
 
i8 : T2XY=nestedObstruction(F0X,F0Y);

             4      8
o8 : Matrix R  <-- R
 
i9 : D=setupNestedDeformation({F0X,T1X,T2X,F0Y,T1Y,T2Y,T2XY});
 
i10 : E=versalDeformation(D,Verbose=>4);
