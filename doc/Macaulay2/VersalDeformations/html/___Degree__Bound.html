DegreeBound -- determines the degree limit used to compute the tangent cone of obstruction equations

Description

DegreeBound is the name of an optional argument. Its value is an integer or infinity. When lifting a deformation, the tangent cone for the obstruction equations is computed using a local term order. The computation uses the command gb with the option DegreeLimit set to the order to which the deformation has been lifted, plus DegreeBound. Default value is 0. If SanityCheck is set to true and results in an error being returned, this can be corrected by re-running the computation using a higher value of DegreeBound.
