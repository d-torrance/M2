isWeylStandard -- test whether a WeylFilling is Weyl-semistandard

  • Usage:
    isWeylStandard T
  • Inputs:
    • T, an instance of the type WeylFilling, assumed to have rows in sorted (weakly-increasing) order, for example the output of weylNormalize
  • Outputs:
    • null if T is Weyl-standard (columns strictly increasing top-to-bottom), otherwise a pair (i, j) giving the first column violation: T#i#j >= T#(i+1)#j, scanning rows from bottom to top

Description

A WeylFilling is Weyl-standard when, in addition to having sorted rows, every column is strictly increasing top-to-bottom. This is exactly the semistandard condition, phrased for row-wise storage.

i1 : isWeylStandard weyl {{0,1}, {1,2}}
 
i2 : isWeylStandard weyl {{1,2}, {1,3}}   -- column 0: 1 >= 1 violates

o2 = (0, 0)

o2 : Sequence

To straighten a non-standard WeylFilling into a linear combination of standard ones, use towardWeylStandard (single step) or weylStraighten (full reduction).

See also

  • WeylFilling -- a Young tableau stored row-wise for the Weyl-module basis
  • weylNormalize -- sort each row of a WeylFilling into weakly-increasing order
  • towardWeylStandard -- a single Garnir-style straightening step for Weyl fillings
  • weylStraighten -- straighten a Weyl filling into a linear combination of Weyl-semistandard tableaux
  • standardWeylTableaux -- all Weyl-semistandard tableaux of a given shape

Ways to use isWeylStandard:

  • isWeylStandard(WeylFilling)
