toricCycle(ToricDivisor) -- Creates a ToricCycle from a ToricDivisor

  • Function: toricCycle
  • Usage:
    toricCycle(D)
  • Inputs:
    • D, a toric divisor,
  • Outputs:
    • a toric cycle,

Description

This method converts a ToricDivisor into a ToricCycle.

i1 : X = toricProjectiveSpace 3;
 
i2 : toricCycle(X_0)

o2 = X
      {0}

o2 : ToricCycle on X
 
i3 : toricCycle(X_1+X_2)

o3 = X    + X
      {1}    {2}

o3 : ToricCycle on X
