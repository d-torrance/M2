setLogger(LSPServer,Function) -- set up logging for an LSP server

  • Function: setLogger (missing documentation)
  • Usage:
    setLogger(server, f)
  • Inputs:
    • server, a LSP server,
    • f, a function,

Description

Sets a custom logging function for server. The function f should accept a single string. For example, to log to standard error:

i1 : server = new LSPServer

o1 = server

o1 : LSPServer
 
i2 : setLogger(server, printerr)

o2 = printerr

o2 : FunctionClosure
