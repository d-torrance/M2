source(MultirationalMap) -- the source for a multi-rational map

  • Function: source
  • Usage:
    source Phi
  • Inputs:
    • Phi, a multi-rational map
  • Outputs:
    • a multi-projective variety, the source of Phi

Description

Note that, instead, the source of a standard rational map is the coordinate ring of the source variety (this is done mainly for efficiency reasons).
