MultiprojectiveVariety ^ ZZ -- power of a multi-projective variety

  • Operator: ^
  • Usage:
    X^n
  • Inputs:
    • X, a multi-projective variety
    • n, an integer
  • Outputs:
    • a multi-projective variety, the product of $n$ copies of $X$

Description

i1 : X = PP_(ZZ/33331)^(1,3);

o1 : ProjectiveVariety, curve in PP^3
 
i2 : X^2;

o2 : ProjectiveVariety, X x X
 
i3 : X^3;

o3 : ProjectiveVariety, X x X x X
 
i4 : X^5;

o4 : ProjectiveVariety, X x X x X x X x X
 
i5 : assert(X^3 == X^2 ** X)
 
i6 : assert(X^5 == X^3 ** X^2)
