isMorphism(MultirationalMap) -- whether a multi-rational map is a morphism

  • Function: isMorphism
  • Usage:
    isMorphism Phi
  • Inputs:
    • Phi, a multi-rational map
  • Outputs:
    • a Boolean value, whether Phi is a morphism (i.e., everywhere defined)
