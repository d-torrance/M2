MultirationalMap <==> MultirationalMap -- equality of multi-rational maps with checks on internal data

  • Operator: <==>
  • Usage:
    Phi <==> Psi
  • Inputs:
    • Phi, a multi-rational map
    • Psi, a multi-rational map
  • Outputs:
    • a Boolean value, whether Phi and Psi are the same multi-rational map, by throwing an error if an inconsistency of the internal data is detected.

Description

For example, if you have calculated the degree of the two maps before, it will be checked that it is the same for both.
