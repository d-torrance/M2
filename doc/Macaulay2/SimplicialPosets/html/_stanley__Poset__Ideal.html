stanleyPosetIdeal -- Returns ideal that defines the simplicial poset ring of the given simplicial poset.

  • Usage:
    I = stanleyPosetIdeal(P)
  • Inputs:
    • P, an instance of the type Poset, A simplicial poset.
  • Outputs:
    • I, an ideal, An ideal such that ring(I)/I is the simplicial poset ring of P.
