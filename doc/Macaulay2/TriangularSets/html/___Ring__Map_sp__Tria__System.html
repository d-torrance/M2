RingMap TriaSystem -- apply ring map to a triangular system

  • Operator: SPACE
  • Usage:
    f T
  • Inputs:
    • f, a ring map,
    • T, an instance of the type TriaSystem,
  • Outputs:
    • an instance of the type TriaSystem, image of T under the ring map f

Description
