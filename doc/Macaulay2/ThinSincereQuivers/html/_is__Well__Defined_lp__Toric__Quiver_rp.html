isWellDefined(ToricQuiver) -- determine if toric quiver is correctly constructed

  • Function: isWellDefined
  • Usage:
    isWellDefined Q
  • Inputs:
    • Q, a toric quiver,
  • Outputs:
    • a Boolean value, true if the vertices and edges of the toric quiver agree, and if the flow for the quiver is a preimage for the weight. Otherwise, false.

Description

This method checks that the various attributes associated to the given toric quiver are in the correct dimension. It checks that the dimensions of the incidence matrix agree with the number of vertices and edges, as do the flow and weights. It also checks that the weights for the quiver are induced by the flow, and that the vertices and edges are constructed without gaps or missing data.

i1 : isWellDefined bipartiteQuiver(2, 3, Flow => "Random")

o1 = true
