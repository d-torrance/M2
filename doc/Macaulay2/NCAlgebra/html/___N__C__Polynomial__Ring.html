NCPolynomialRing -- Type of a noncommutative polynomial ring

  • Usage:
    A = QQ{x,y}

Description

This is the type of a noncommutative polynomial ring over a commutative ring R (i.e. a tensor algebra over R). It has parent type NCRing.

i1 : A = QQ{x,y}

o1 = A
