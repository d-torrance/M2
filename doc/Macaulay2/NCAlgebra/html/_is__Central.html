isCentral -- Determines if an element is central

  • Usage:
    isCentral x or isCentral(x,ncgb)
  • Inputs:
    • x, an instance of the type NCRingElement,
    • ncgb, an instance of the type NCGroebnerBasis, a Groebner basis for the NCRing to which x belongs.
  • Outputs:
    • a Boolean value,

Description

This method checks to see if a given NCRing element is central.
