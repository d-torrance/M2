monomials(NCRingElement) -- Returns the monomials appearing in the NCRingElement

  • Function: monomials
  • Usage:
    mons = support f
  • Inputs:
    • f, an instance of the type NCRingElement,
  • Optional inputs:
    • Variables => ..., default value null,
  • Outputs:
    • mons, an instance of the type NCMatrix,

Description

Returns the monomials appearing in NCRingElement as an NCMatrix.

i1 : A = QQ{x,y,z,w}

o1 = A

o1 : NCPolynomialRing
 
i2 : f = x^2+y^2+z^3

      3  2  2
o2 = z +y +x

o2 : A
 
i3 : mons = monomials f

o3 = | z^3 y^2 x^2 |

o3 : NCMatrix
