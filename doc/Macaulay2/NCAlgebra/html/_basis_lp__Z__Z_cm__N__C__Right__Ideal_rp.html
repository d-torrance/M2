basis(ZZ,NCRightIdeal) -- Returns a basis of an NCRightIdeal in a particular degree.

  • Function: basis
  • Usage:
    bas = basis(n,I)
  • Inputs:
    • n, an integer,
    • I, an instance of the type NCRightIdeal,
  • Optional inputs:
    • Degree => ..., default value null,
    • Limit => ..., default value infinity,
    • SourceRing => ..., default value null,
    • Strategy => ..., default value null,
    • Truncate => ..., default value false,
    • Variables => ..., default value null,
  • Outputs:
    • bas, an instance of the type NCMatrix,

Description

This command returns a basis (or minimal generating set, if the ground ring is not a field), of a homogeneous right ideal in a noncommutative ring.
