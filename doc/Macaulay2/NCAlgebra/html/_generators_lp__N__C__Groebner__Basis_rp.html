generators(NCGroebnerBasis) -- The list of algebra generators of an NCGroebnerBasis

  • Function: generators
  • Usage:
    gensIgb = generators Igb
  • Inputs:
    • Igb, an instance of the type NCGroebnerBasis,
  • Optional inputs:
    • CoefficientRing => ..., default value null,
  • Outputs:
    • gensIgb, a list,

Description

This function returns the generators of an NCGroebnerBasis as a list. As usual, gens is a synonym for generators.
