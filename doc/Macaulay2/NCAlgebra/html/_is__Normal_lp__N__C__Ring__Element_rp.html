isNormal(NCRingElement) -- Determines if a given NCRingElement is normal

  • Function: isNormal
  • Usage:
    isNormal x
  • Inputs:
    • x, an instance of the type NCRingElement,
  • Outputs:
    • a Boolean value,

Description

Given an element x in an NCRing R, this method returns true if Rx=xR.
