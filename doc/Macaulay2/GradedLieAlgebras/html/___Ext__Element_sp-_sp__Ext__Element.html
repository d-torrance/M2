ExtElement - ExtElement -- subtraction of Ext-algebra elements

  • Operator: -
  • Usage:
    u=x - y
  • Inputs:
    • x, an instance of the type ExtElement, $x$ is of type $E$, where $E$ is of type ExtAlgebra
    • y, an instance of the type ExtElement, $y$ is of type $E$
  • Outputs:
    • u, an instance of the type ExtElement, $u$ is of type $E$, the difference of $x$ and $y$

Description

The symbol - is used as infix notation for the Ext-algebra subtraction. The elements $x$ and $y$ must hade the same weight and sign.
