cycles -- make the subalgebra of cycles

  • Usage:
    C=cycles(L)
  • Inputs:
    • L, an instance of the type LieAlgebra,
  • Outputs:
    • C, an instance of the type LieSubAlgebra, the kernel of the differential

Description

i1 : L=lieAlgebra({a,b},Signs=>{1,0},Weights=>{{2,0},{2,1}},
        Field=>ZZ/3,LastWeightHomological=>true)

o1 = L

o1 : LieAlgebra
 
i2 : D=differentialLieAlgebra({0_L,a})

o2 = D

o2 : LieAlgebra
 
i3 : C=cycles D

o3 = C
