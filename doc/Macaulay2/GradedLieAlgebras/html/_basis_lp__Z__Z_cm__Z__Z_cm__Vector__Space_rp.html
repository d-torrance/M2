basis(ZZ,ZZ,VectorSpace) -- compute a basis

  • Function: basis
  • Usage:
    b=basis(m,n,V)
  • Inputs:
    • m, an integer,
    • n, an integer,
    • V, an instance of the type VectorSpace, an instance of type VectorSpace
  • Optional inputs:
    • Degree => ..., default value null,
    • Limit => ..., default value infinity,
    • SourceRing => ..., default value null,
    • Strategy => ..., default value null,
    • Truncate => ..., default value false,
    • Variables => ..., default value null,
  • Outputs:
    • b, a list, a basis for the part of $V$ of first degree $m$ and homological degree $n$.

Description

The optional inputs given above are not relevant for Lie algebras.
