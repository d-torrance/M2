isMember(LieElement,LieSubSpace) -- whether a Lie element belongs to a Lie subspace

  • Function: isMember
  • Usage:
    b=member(x,S)
  • Inputs:
    • x, an instance of the type LieElement,
    • S, an instance of the type LieSubSpace, an instance of type LieSubSpace
  • Outputs:
    • b, a Boolean value, true if $x$ belongs to $S$ and false otherwise
