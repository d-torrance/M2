LieAlgebra == LieAlgebra -- whether two Lie algebras are defined in the same way

  • Operator: ==
  • Usage:
    L==M
  • Inputs:
    • L, an instance of the type LieAlgebra,
    • M, an instance of the type LieAlgebra,
  • Outputs:
    • b, a Boolean value,

Description

Two objects L and M of type LieAlgebra satisfies L==M if they have the same generators, weights, signs, field, defining ideal, and differential.
