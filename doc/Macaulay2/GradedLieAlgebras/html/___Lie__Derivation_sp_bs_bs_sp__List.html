LieDerivation \\ List -- formal application of a derivation to every element in a list

  • Operator: \\
  • Usage:
    y = d\\x
  • Inputs:
    • d, an instance of the type LieDerivation,
    • x, a list, the elements in $x$ belong to the source of $d$
  • Outputs:
    • y, a list, the elements in $y$ are the formal application of $d$ to the elements in $x$
