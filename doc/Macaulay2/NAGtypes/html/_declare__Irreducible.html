declareIrreducible -- declares a component represented by the witness set irreducible

Description

This is a service method that for a witness set W sets the flag W.cache.IsIrreducible to true.

Ways to use declareIrreducible:

  • declareIrreducible(WitnessSet)

For the programmer

The object declareIrreducible is a method function.
