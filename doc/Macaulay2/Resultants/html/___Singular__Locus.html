SingularLocus -- pass the singular locus of the variety

  • Usage:
    SingularLocus => X

Description

Some methods, like tangentialChowForm and conormalVariety, must calculate the singular locus of the input variety, which can be hard to obtain. Sometimes one knows this locus and this option allows to inform Macaulay2.

Functions with optional argument named SingularLocus:

  • conormalVariety(...,SingularLocus=>...)
  • dualVariety(...,SingularLocus=>...)
  • hurwitzForm(...,SingularLocus=>...)
  • isInCoisotropic(...,SingularLocus=>...)
  • tangentialChowForm(...,SingularLocus=>...)

For the programmer

The object SingularLocus is a symbol.
