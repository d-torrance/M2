JSONRPCServer -- JSONRPC server class

  • Usage:
    new JSONRPCServer

Description

JSONRPCServer is the core class of the package, responsible for handling JSON-RPC requests. It allows you to register methods, process incoming requests (including batches), and send appropriate responses or error messages, all while following the JSON-RPC 2.0 specification. The class also includes basic logging functionality to track incoming requests and responses.
