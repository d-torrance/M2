schurRank -- computes the dimension of the irreducible GL(QQ^n) representation associated to a partition

  • Usage:
    schurRank(n, mu)
  • Inputs:
    • n, an integer, the size of the matrix group $GL(\mathbb{Q}^n)$
    • mu, a list, a partition $(\mu_1, \ldots, \mu_r)$ where $\mu_i$ is the number of boxes in the $i$th row
  • Outputs:
    • an integer, The dimension of the irreducible $GL(\mathbb{Q}^n)$ representation associated to $\mu$

Description

The dimension is computed using the determinantal formula given by the Weyl character formula. 
i1 : schurRank(5, {4,3}) -- should be 560

o1 = 560
