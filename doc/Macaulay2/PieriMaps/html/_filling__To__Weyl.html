fillingToWeyl -- convert a Filling to a sum of WeylFillings (compose pmToWeyl with fillingToPM)

  • Usage:
    fillingToWeyl F
  • Inputs:
    • F, Filling
  • Outputs:
    • a hash table, a HashTable {WeylFilling => coeff}

Description

i1 : needsPackage "SchurFunctors";
 
i2 : F = new Filling from {{0,2},{1}};
 
i3 : fillingToWeyl F

               +-+-+
o3 = HashTable{|0|1| => 1}
               |2| |
               +-+-+
               +-+-+    1
               |0|2| => -
               |1| |    2
               +-+-+

o3 : HashTable

See also

  • pmToWeyl -- convert a PieriMaps row-form tableau to a SchurFunctors WeylFilling
  • fillingToPM -- convert a SchurFunctors column-form Filling to PieriMaps row-form tableaux
  • weylToFilling -- convert a WeylFilling to a SchurFunctors Filling (compose pmToFilling with weylToPM)

For the programmer

The object fillingToWeyl is a function closure.
