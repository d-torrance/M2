weylToFilling -- convert a WeylFilling to a SchurFunctors Filling (compose pmToFilling with weylToPM)

  • Usage:
    weylToFilling W
  • Inputs:
    • W, WeylFilling
  • Outputs:
    • a hash table, image as a sum of standard Fillings after straightening

Description

i1 : needsPackage "SchurFunctors";
 
i2 : W = pmToWeyl {{0,1},{2}};
 
i3 : weylToFilling W

               +-+-+      1
o3 = HashTable{|0|2| => - -}
               |1| |      2
               +-+-+
               +-+-+
               |0|1| => 1
               |2| |
               +-+-+

o3 : HashTable

See also

  • pmToFilling -- convert a PieriMaps row-form tableau to SchurFunctors column-form Fillings
  • weylToPM -- convert a SchurFunctors WeylFilling to a PieriMaps row-form tableau
  • fillingToWeyl -- convert a Filling to a sum of WeylFillings (compose pmToWeyl with fillingToPM)

For the programmer

The object weylToFilling is a function closure.
