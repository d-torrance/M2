isConstant(InputGate) -- whether an input gate is constant

  • Function: isConstant
  • Usage:
    isConstant g
  • Inputs:
    • g, an instance of the type InputGate,
  • Outputs:
    • a Boolean value, whether g is a constant

Description

An input gate is constant if its Name is either a Number or a RingElement.

i1 : declareVariable X

o1 = X

o1 : InputGate
 
i2 : isConstant X

o2 = false
 
i3 : isConstant 3

o3 = true
