size(ForeignType) -- size of a foreign type

  • Function: size
  • Usage:
    size T
  • Inputs:
    • T, a foreign type,
  • Outputs:
    • an integer,

Description

Return the number of bytes needed by the given foreign type, just like the sizeof operator in C.

i1 : size char'

o1 = 1
 
i2 : size voidstar

o2 = 8
