faces(PolyhedralObject) -- Giving the faces of a polyhedral object.

  • Function: faces
  • Usage:
    fk = faces PO
  • Inputs:
    • PO, an instance of the type PolyhedralObject,
  • Outputs:
    • M, a hash table,

Description

Returns a HashTable with the faces of a polyhedral object sorted by codimension. The faces are given as lists containing the indices of the rays/vertices of the original object contained in the face.

i1 : fC = faces hypercube 2

o1 = HashTable{0 => {({0, 1, 2, 3}, {})}                                    }
               1 => {({0, 2}, {}), ({1, 3}, {}), ({0, 1}, {}), ({2, 3}, {})}
               2 => {({0}, {}), ({2}, {}), ({1}, {}), ({3}, {})}
               3 => {}

o1 : HashTable
 
i2 : fC#1

o2 = {({0, 2}, {}), ({1, 3}, {}), ({0, 1}, {}), ({2, 3}, {})}

o2 : List
