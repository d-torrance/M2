isSmooth(Cone) -- checks if a Cone or Fan is smooth

  • Function: isSmooth
  • Usage:
    b = isSmooth C
    b = isSmooth F
  • Inputs:
    • C, a convex rational cone
  • Outputs:
    • b, a Boolean value, true if the Cone/Fan is smooth, false otherwise

Description

isSmooth checks for a Cone if the rays are a subset of a basis of the lattice. For a Fan it checks smoothness for every Cone.
