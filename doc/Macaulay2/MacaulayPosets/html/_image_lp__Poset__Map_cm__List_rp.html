image(PosetMap,List) -- the image of a poset map

  • Function: image
  • Usage:
    image(f, L)
  • Inputs:
    • f, a map of posets,
    • L, a list, a subset of vertices source f
  • Outputs:
    • a list,

Description

The image of the map $[3]\rightarrow[10]$ given by $i\mapsto 2i$ is computed below.

i1 : f = map(chain 10, chain 3, {1=>2, 2=>4, 3=>6})

i2 : image f
