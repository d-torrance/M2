macaulayOrders -- finds all orders with respect to which the poset is Macaulay

  • Usage:
    macaulayOrders P
    macaulayOrders S
    macaulayOrders I
  • Inputs:
    • P, an instance of the type Poset,
    • S, a quotient ring, a homogeneous level linearly independent quotient of a polynomial ring over a field
    • I, an ideal, a homogeneous ideal of a polynomial ring such that the quotient is level linearly independent
  • Optional inputs:
    • TikZ => a Boolean value, default value false, whether to print TikZ code
    • Visual => a Boolean value, default value false, whether to visualize the Macaulay orders
    • AllOrders => a Boolean value, default value true, whether to return all orders instead of at most one order
  • Outputs:
    • a list, whose elements are lists representing orders with respect to which the poset is Macaulay

Description

Given a poset with rank function $r$, this method returns all Macaulay orders $<$ on the poset such that $r(p) < r(q)$ implies $p < q$.

Given a quotient $S$ of a polynomial ring, this method returns Macaulay orders on the monomial poset of $S$.

A total order $<$ on a poset $P$ is represented by a list. It is the permutation of the of the ground set of $P$ that is increasing with respect to $<$.

i1 : macaulayOrders(product(chain 3, chain 3))

o1 = {{{1, 1}, {1, 2}, {2, 1}, {1, 3}, {2, 2}, {3, 1}, {2, 3}, {3, 2}, {3,
     ------------------------------------------------------------------------
     3}}, {{1, 1}, {2, 1}, {1, 2}, {3, 1}, {2, 2}, {1, 3}, {3, 2}, {2, 3},
     ------------------------------------------------------------------------
     {3, 3}}}

o1 : List

Caveat

Given a QuotientRing or an Ideal, this method will not verify level linear independence.
