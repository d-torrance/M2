numericalIrreducibleDecomposition(...,Verbose=>...) -- option to specify whether additional output is wanted

  • Usage:
    numericalIrreducibleDecomposition(...,Verbose=>Boolean)

Description

The value of the Verbose option (by default set to false) is passed to the methods cascade and factorWitnessSet.

The output file of phc contains timings for all stages in the numerical irreducible decomposition.
