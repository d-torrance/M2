polarizedK3surface -- polarized K3 surface associated to a doubly special cubic fourfold

  • Usage:
    E = polarizedK3surface X
  • Inputs:
    • X, a doubly special cubic fourfold, whose defining union of surfaces admits a congruence of curves
  • Optional inputs:
    • FanoMapType => ..., default value null
    • Strategy => ..., default value null
    • Verbose => ..., default value false, request verbose feedback
  • Outputs:
    • E, the polarized K3 surface associated to $X$

Description

At the first call, this function initializes a container object: it computes the underlying projective surface but leaves the lattice polarization data empty to save time.

The full lattice data is computed and stored within the object only upon a second call. Once initialized, polarize can be used as a synonym (using default options).

The following methods can be used to access the construction data of $E$:

  • building E -- returns the four construction objects as in associatedK3surface(CubicFourfold) (the Fano rational map $\mu$, the non-minimal K3 surface $U$, the exceptional curves on $U$ and the morphism $f: U \to E$ contracting them);
  • projectiveVariety E -- returns the underlying projective surface;
  • latticePolarization E -- returns the lattice data induced by the doubly special structure of $X$.

Optional inputs:

  • Strategy -- provides instructions for each step. The first stage handles the construction of the non-minimal K3 surface $U$ by inverting the Fano map restricted to the cubic (via "Inverse" or "Approximate"), while the second computes the lattice data (common options include "MapFromW", "MapFromU", or "SpecialCurve"). Both can be passed at once as a sequence, e.g., Strategy => ("Inverse", "MapFromW"), or provided individually through nested calls.
  • FanoMapType -- sets the Fano map to "Standard" (default) or "P2xP2". Note that switching this type updates the global behavior of $X$ (e.g., affecting methods like mirrorFourfold), though previously computed data is preserved;
  • Verbose -- if set to true, provides feedback during the construction.
